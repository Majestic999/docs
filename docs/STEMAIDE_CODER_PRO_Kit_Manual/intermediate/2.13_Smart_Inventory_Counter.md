# Project 2.13: Smart Inventory Counter

| **Description** | This project uses RFID technology to automatically track items entering and leaving inventory. Every RFID tag represents an item, and the system updates the total inventory count on an LCD display. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as retail stores, warehouses, logistics centers, and manufacturing facilities. It demonstrates how RFID and display systems can automate inventory tracking and asset management. |

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) power rail on the breadboard.

- Connect the **3V3** pin on the ESP32 board to a separate empty row on the breadboard (for the RFID Reader).

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) ground rail on the breadboard.

**Step 2:** Wire the RFID Reader (MFRC522)

- Connect **3.3V (VCC)** of the RFID reader to the **3V3** row. *(**NB:** Do not connect to 5V!)*

- Connect **GND** of the RFID reader to the ground rail.

- Connect **RST** of the RFID reader to **GPIO 23** on the ESP32 board.

- Connect **MISO** of the RFID reader to **GPIO 26** on the ESP32 board.

- Connect **MOSI** of the RFID reader to **GPIO 25** on the ESP32 board.

- Connect **SCK** of the RFID reader to **GPIO 27** on the ESP32 board.

- Connect **SDA (SS)** of the RFID reader to **GPIO 33** on the ESP32 board.

**Step 3:** Wire the I2C LCD Display

- Connect **VCC** of the LCD to the **5V** positive rail.

- Connect **GND** of the LCD to the ground rail.

- Connect **SDA** of the LCD to **GPIO 21** on the ESP32 board.

- Connect **SCL** of the LCD to **GPIO 22** on the ESP32 board.

### 1. Library Inclusion, Object Setup, and Variables

```cpp
#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

#define SS_PIN 33
#define RST_PIN 23

MFRC522 rfid(SS_PIN, RST_PIN);
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Maximum number of inventory items we can store
const int MAX_ITEMS = 20;

// Store scanned RFID UIDs as Strings in an array
String inventory[MAX_ITEMS];

int inventoryCount = 0;
```
*Explanation:* We include the SPI and RFID libraries for the MFRC522 reader, and the LCD libraries. We create an array of `String` called `inventory` that can hold up to 20 scanned card UIDs, and an `inventoryCount` to keep track of how many items are currently in storage.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("Inventory");
  lcd.setCursor(0, 1);
  lcd.print("System Ready");

  delay(2000);
  updateDisplay(); // Call custom function to show current count
}
```
*Explanation:* Initializes all components, displays a startup message, and then calls a helper function to show the empty inventory screen.

---

### 3. Main Loop

```cpp
void loop() {
  // Look for new cards
  if (!rfid.PICC_IsNewCardPresent()) {
    return;
  }
  // Verify if the UID has been read
  if (!rfid.PICC_ReadCardSerial()) {
    return;
  }

  // Construct the UID string
  String uid = "";
  for (byte i = 0; i < rfid.uid.size; i++) {
    uid += String(rfid.uid.uidByte[i], HEX);
  }
  uid.toUpperCase();

  Serial.print("UID: ");
  Serial.println(uid);

  // Send the UID to our custom inventory logic function
  processInventory(uid);

  // Stop reading this specific card to avoid double-scans immediately
  rfid.PICC_HaltA();
  rfid.PCD_StopCrypto1();
  
  delay(1000); // Wait a second before allowing the next scan
}
```
*Explanation:* The loop constantly checks for a card. If it finds one, it reads its unique ID bytes, converts them into a single uppercase `String` (e.g., "DEADBEEF"), and passes it to `processInventory()`.

---

### 4. Custom Logic Functions

```cpp
void processInventory(String uid) {
  // 1. Check if the item is already stored in inventory
  for (int i = 0; i < inventoryCount; i++) {
    if (inventory[i] == uid) {
      
      // The item is already here, which means we are REMOVING it!
      // Shift all remaining items down the list to close the gap
      for (int j = i; j < inventoryCount - 1; j++) {
        inventory[j] = inventory[j + 1];
      }
      
      inventoryCount--; // Decrease total count
      
      lcd.clear();
      lcd.print("Item Removed");
      lcd.setCursor(0, 1);
      lcd.print("Total: ");
      lcd.print(inventoryCount);
      Serial.println("Item Removed");
      
      delay(1500);
      updateDisplay();
      return; // Exit the function entirely
    }
  }

  // 2. If it wasn't found, we are ADDING a new item!
  if (inventoryCount < MAX_ITEMS) {
    inventory[inventoryCount] = uid; // Store it at the end of the list
    inventoryCount++; // Increase total count
    
    lcd.clear();
    lcd.print("Item Added");
    lcd.setCursor(0, 1);
    lcd.print("Total: ");
    lcd.print(inventoryCount);
    Serial.println("Item Added");
  } else {
    // Inventory array is full!
    lcd.clear();
    lcd.print("Inventory");
    lcd.setCursor(0, 1);
    lcd.print("Memory Full");
    Serial.println("Inventory Full");
  }

  delay(1500);
  updateDisplay();
}

void updateDisplay() {
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Inventory");
  lcd.setCursor(0, 1);
  lcd.print("Items: ");
  lcd.print(inventoryCount);
}
```
*Explanation:* 

- `processInventory()` is where the magic happens. It loops through the `inventory` array.

- If it finds the UID, it means the item was already scanned into the warehouse, so scanning it again means it's leaving (checking out). It removes the item and shrinks the list.

- If it doesn't find the UID, it means the item is new (checking in). It adds the UID to the list and grows the list.

- `updateDisplay()` just draws the default waiting screen showing the total count.

## CONCLUSION

The Smart Inventory Counter successfully demonstrates how RFID technology can be used for automated asset tracking. By reading the unique ID of each scanned card, the system dynamically checks if the item is known. If it is, it checks it out; if it isn't, it checks it in, updating the total count on the LCD display in real time—simulating a practical warehouse inventory management system!
