# Project 2.10.2: Smart Street Light (1 LED)

| **Description** | This project demonstrates how to build an automatic smart street light system using an LDR (Light Dependent Resistor) and an LED. The ESP32 board reads the surrounding light intensity through the LDR sensor and automatically switches the LED ON when it becomes dark and OFF when sufficient light is detected. Through this project, you will learn how sensors can be used with microcontrollers to create automated lighting systems. |
|------------------|----------------------------------------------------------------|
| **Use case**     | Automatic street lighting systems, smart home lighting, security lights, outdoor pathway lighting, energy-saving lighting solutions, and any application where lights need to respond automatically to changes in surrounding light conditions. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the LDR Sensor on the breadboard so its four pins sit in separate adjacent rows.

- Insert the Red LED into the breadboard (remember the longer leg is positive).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the LDR Sensor

- Connect the **VCC** pin of the LDR to the positive power rail.

- Connect the **GND** pin of the LDR to the negative power rail.

- Connect the **AO** (Analog Out) pin of the LDR to **GPIO 36** (also labeled VP) on the ESP32 board.

- Connect the **DO** (Digital Out) pin of the LDR to **GPIO 2** on the ESP32 board.

**Step 3:** Wire the Red LED

- Connect a **220Ω resistor** from the positive (longer) leg of the Red LED to **GPIO 18**.

- Connect the negative (shorter) leg of the Red LED to the negative ground rail.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variables and Setup

```cpp
const int LDR_AO_PIN = 36;
const int LDR_DO_PIN = 2;
const int LED_PIN = 18;

void setup() {
  Serial.begin(9600);
  
  // Set up the digital pins
  pinMode(LDR_DO_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
}
```
*Explanation:* We define our analog pin (`36`), digital pin (`2`), and our output LED pin (`18`). In `setup()`, we start the serial monitor and configure the pins.

---

### 2. Main Loop

```cpp
void loop() {
  // Read the analog value (0-4095)
  int analogValue = analogRead(LDR_AO_PIN);
  
  // Read the digital value (HIGH or LOW)
  // The LDR module usually outputs HIGH when dark and LOW when bright
  int digitalValue = digitalRead(LDR_DO_PIN);
  
  // Print values to the Serial Monitor
  Serial.print("Analog: ");
  Serial.print(analogValue);
  Serial.print(" | Digital: ");
  Serial.println(digitalValue);
  
  // If the digital pin is HIGH, it means it's dark! Turn on the street light!
  if (digitalValue == HIGH) {
    digitalWrite(LED_PIN, HIGH);
  } else {
    // If it's bright enough, turn the light off.
    digitalWrite(LED_PIN, LOW);
  }
  
  delay(100); // Check 10 times a second
}
```
*Explanation:* We check the digital output of the light sensor. When it gets dark, the sensor sends a `HIGH` signal. We detect that and use it to power the LED, perfectly simulating an automatic street lamp!
