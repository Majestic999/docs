## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the Push Button firmly across the center gap of the breadboard.

- Insert the Red LED into the breadboard (remember the longer leg is positive).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Push Button

- Connect one terminal of the Push Button to **GPIO 27** on the ESP32 board.

- Connect the opposite terminal of the Push Button to the negative ground rail.

**Step 3:** Wire the LED

- Connect a **220Ω resistor** from the positive (longer) leg of the LED to **GPIO 18** on the ESP32 board.

- Connect the negative (shorter) leg of the LED to the negative ground rail.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variables and Setup

```cpp
const int pushButton = 27;
const int ledPin = 18;

void setup() {
  pinMode(ledPin, OUTPUT);
  // We use INPUT_PULLUP so the pin is naturally HIGH, and goes LOW when pressed
  pinMode(pushButton, INPUT_PULLUP);
}
```
*Explanation:* We assign our button to pin 27 and LED to pin 18. The `INPUT_PULLUP` setting uses the ESP32's internal resistor to keep the button's pin reading `HIGH` until it is actively pressed down.

---

### 2. Main Loop

```cpp
void loop() {
  // Read if the button is pressed (LOW)
  int buttonState = digitalRead(pushButton);
  
  if (buttonState == LOW) {
    // If button is pressed down, turn LED ON
    digitalWrite(ledPin, HIGH);
  } else {
    // If button is released, turn LED OFF
    digitalWrite(ledPin, LOW);
  }
}
```
*Explanation:* The loop constantly checks the state of the button. Because of `INPUT_PULLUP`, the button reads `LOW` when pressed. When it reads `LOW`, we apply power (`HIGH`) to the LED.
