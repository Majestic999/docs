# Project 2.10.7: Crosswalk Hazard Warning

| **Description** | This project uses an LED flash warning alongside a cycling Traffic Light Module to simulate a pedestrian crosswalk hazard alert. It flashes an external warning light whenever the traffic light changes states. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used in automation systems, interactive street installations, and embedded control applications for road safety and traffic management. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the Traffic Light Module on the breadboard so its four pins sit in separate adjacent rows.

- Insert the standard LED into the breadboard (remember the longer leg is positive).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Standard Warning LED

- Connect a **220Ω resistor** from the positive (longer) leg of the LED to **GPIO 21**.

- Connect the negative (shorter) leg of the LED to the negative ground rail.

**Step 3:** Wire the Traffic Light Module

- Connect the **Green (G)** pin of the Traffic Light Module to **GPIO 5** on the ESP32 board.

- Connect the **Yellow (Y)** pin of the Traffic Light Module to **GPIO 18** on the ESP32 board.

- Connect the **Red (R)** pin of the Traffic Light Module to **GPIO 19** on the ESP32 board.

- Connect the **GND** pin of the Traffic Light Module to the negative ground rail.

### 1. Variables and Setup

```cpp
const int greenLED = 5;
const int yellowLED = 18;
const int redLED = 19;
const int warningLED = 21;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(warningLED, OUTPUT);
}
```
*Explanation:* We assign variables for the 3 colors of the traffic light module and the separate warning LED.

Then we set them all as outputs in the setup function.

---

### 2. Main Loop and Custom Function

```cpp
void loop() {
  // 1. Green Phase
  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  flashWarningLED(3000); // Wait 3 seconds, flashing the warning light the whole time
  
  // 2. Yellow Phase
  digitalWrite(greenLED, LOW);
  digitalWrite(yellowLED, HIGH);
  digitalWrite(redLED, LOW);
  flashWarningLED(1000); // Wait 1 second, flashing the warning light
  
  // 3. Red Phase
  digitalWrite(greenLED, LOW);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, HIGH);
  flashWarningLED(3000); // Wait 3 seconds, flashing the warning light
}

// Custom function to flash the warning LED while waiting for a specific duration
void flashWarningLED(int duration) { 
  unsigned long startTime = millis();
  
  // Keep looping until the duration has passed
  while (millis() - startTime < duration) {
    digitalWrite(warningLED, HIGH); // Flash On
    delay(250);
    digitalWrite(warningLED, LOW);  // Flash Off
    delay(250); 
  }
}
```
*Explanation:* 

- The `loop()` cycles the traffic light through Green, Yellow, and Red phases.

- Instead of using a normal `delay()` to wait between light changes, we created a custom `flashWarningLED()` function.

- This function uses `millis()` (the internal stopwatch) to track how much time has passed, and actively flashes the external warning LED `ON` and `OFF` every 250 milliseconds until the total `duration` for that traffic light phase is over!
