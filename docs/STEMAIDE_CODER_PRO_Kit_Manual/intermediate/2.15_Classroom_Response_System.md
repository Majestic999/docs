|------------------|----------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as classroom response systems ("clickers"), surveys, quizzes, and electronic voting platforms. It demonstrates how multiple inputs can be tracked and displayed in real time for instant feedback. |

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Push Buttons (A, B, C, D)

- Connect one terminal of **Button A** to **GPIO 2** on the ESP32 board.

- Connect one terminal of **Button B** to **GPIO 4** on the ESP32 board.

- Connect one terminal of **Button C** to **GPIO 5** on the ESP32 board.

- Connect one terminal of **Button D** to **GPIO 18** on the ESP32 board.

- Connect the opposite terminals of *all four* push buttons to the negative ground rail.

**Step 3:** Wire the I2C LCD Display

- Connect **VCC** of the LCD to the positive power rail.

- Connect **GND** of the LCD to the negative power rail.

- Connect **SDA** of the LCD to **GPIO 21** on the ESP32 board.

- Connect **SCL** of the LCD to **GPIO 22** on the ESP32 board.

### 1. Library Inclusion, Object Setup, and Variables

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

// Button Pins
const int buttonA = 2;
const int buttonB = 4;
const int buttonC = 5;
const int buttonD = 18;

// Vote Counters
int votesA = 0;
int votesB = 0;
int votesC = 0;
int votesD = 0;

// Track the previous button states to only count a press ONCE per click
bool lastA = HIGH;
bool lastB = HIGH;
bool lastC = HIGH;
bool lastD = HIGH;
```
*Explanation:* We include libraries and initialize the LCD. We define the 4 button pins, create integers to tally the votes for each option, and create boolean variables that will help us "debounce" the buttons so holding a button down doesn't add thousands of votes in one second.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);

  // Use internal pull-ups so the pins don't float
  pinMode(buttonA, INPUT_PULLUP);
  pinMode(buttonB, INPUT_PULLUP);
  pinMode(buttonC, INPUT_PULLUP);
  pinMode(buttonD, INPUT_PULLUP);

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("Class Response");
  lcd.setCursor(0, 1);
  lcd.print("System Ready");

  delay(2000); // Show startup message

  updateDisplay(); // Draw the voting scoreboard
}
```
*Explanation:* Configures the buttons as `INPUT_PULLUP` (meaning they will read `LOW` when pressed) and displays a startup message.

---

### 3. Main Loop and Button Checking Logic

```cpp
void loop() {
  checkButtons(); // We put our messy checking logic in a custom function!
}

void checkButtons() {
  // Read the current state of all 4 buttons
  bool currentA = digitalRead(buttonA);
  bool currentB = digitalRead(buttonB);
  bool currentC = digitalRead(buttonC);
  bool currentD = digitalRead(buttonD);

  // If Button A was unpressed last time we checked, but is pressed now...
  if (lastA == HIGH && currentA == LOW) {
    votesA++;
    showVote("Vote A");
  }

  // If Button B...
  if (lastB == HIGH && currentB == LOW) {
    votesB++;
    showVote("Vote B");
  }

  // If Button C...
  if (lastC == HIGH && currentC == LOW) {
    votesC++;
    showVote("Vote C");
  }

  // If Button D...
  if (lastD == HIGH && currentD == LOW) {
    votesD++;
    showVote("Vote D");
  }

  // Save the current states for the next loop to compare against
  lastA = currentA;
  lastB = currentB;
  lastC = currentC;
  lastD = currentD;
}
```
*Explanation:* 

- `checkButtons()` is doing "state change detection". We don't want to just know if a button *is* pressed; we want to know exactly when it *goes from being unpressed to being pressed*.

- `if (lastA == HIGH && currentA == LOW)` exactly checks for this transition. When a button is pushed, it adds a vote and calls another custom function `showVote()`.

- At the very end, we update our memory (`lastA = currentA`) so it's ready for the next microsecond.

### 4. Display Custom Functions

```cpp
void showVote(String option) {
  Serial.println(option);

  // Momentarily interrupt the scoreboard to confirm the vote was cast
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print(option);
  lcd.setCursor(0, 1);
  lcd.print("Recorded");

  delay(800); // Wait 0.8 seconds to show the confirmation

  updateDisplay(); // Bring the scoreboard back
}

void updateDisplay() {
  lcd.clear();
  
  // Row 1: A and B
  lcd.setCursor(0, 0);
  lcd.print("A:");
  lcd.print(votesA);
  lcd.print(" B:");
  lcd.print(votesB);

  // Row 2: C and D
  lcd.setCursor(0, 1);
  lcd.print("C:");
  lcd.print(votesC);
  lcd.print(" D:");
  lcd.print(votesD);
}
```
*Explanation:* 

- `showVote()` gives the student visual feedback that their vote was counted, then immediately restores the scoreboard.

- `updateDisplay()` is responsible for formatting the final scoreboard tally so it fits perfectly on the 16x2 character LCD screen.
