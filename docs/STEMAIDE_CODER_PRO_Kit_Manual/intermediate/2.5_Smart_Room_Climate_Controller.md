## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the Temperature Sensor, NPN Transistor, and Buzzer on the breadboard so their pins sit in separate adjacent rows.

- Attach the Fan Blade to the DC Motor.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Temperature Sensor

- Connect **VCC** of the temperature sensor to the positive power rail.

- Connect **GND** of the temperature sensor to the negative power rail.

- Connect the **OUT** (signal) pin to **GPIO 36** (also labeled VP) on the ESP32 board.

**Step 3:** Wire the I2C LCD Display

- Connect **VCC** of the LCD to the positive power rail.

- Connect **GND** of the LCD to the negative power rail.

- Connect **SDA** of the LCD to **GPIO 21** on the ESP32 board.

- Connect **SCL** of the LCD to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the DC Motor and NPN Transistor

- Connect the DC motor and NPN transistor such that the transistor can act as a switch for the motor.

- Connect the control pin (Base) of the NPN transistor to **GPIO 23** on the ESP32 board.

**Step 5:** Wire the Buzzer

- Connect the **positive (+)** pin of the buzzer to **GPIO 18** on the ESP32 board.

- Connect the **negative (-)** pin of the buzzer to the negative power rail.

## PROGRAMMING

### 1. Library Inclusion and Object Setup

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Temperature sensor
const int tempPin = 36;

// Outputs
const int fanPin = 23;
const int buzzerPin = 18;
```
*Explanation:* We include the library to control the I2C LCD and set its address (`0x27`). We define `tempPin` for our analog temperature sensor, `fanPin` to control the transistor/motor, and `buzzerPin` for the alarm.

---

### 2. Setup Function

```cpp
void setup() {
  lcd.init();
  lcd.backlight();
  
  pinMode(fanPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  
  Serial.begin(9600);
}
```
*Explanation:* Initializes the LCD screen, configures the fan and buzzer pins as outputs, and starts the Serial Monitor.

---

### 3. Loop Function

```cpp
void loop() {
  // Read temperature sensor (0-4095 on ESP32)
  int sensorValue = analogRead(tempPin);
  
  // Convert reading to voltage (assuming 3.3V max for ESP32 analog pins)
  float voltage = sensorValue * (3.3 / 4095.0);
  
  // Convert voltage to Celsius (LM35 outputs 10mV per degree C)
  float temperature = voltage * 100;
  
  // Display temperature
  lcd.setCursor(0, 0);
  lcd.print("Temp: ");
  lcd.print(temperature);
  lcd.print(" C  ");
  
  // Normal Condition
  if (temperature < 28) {
    digitalWrite(fanPin, LOW);
    digitalWrite(buzzerPin, LOW);
    lcd.setCursor(0, 1);
    lcd.print("Status: Normal  ");
  }
  // Cooling Required
  else if (temperature >= 28 && temperature < 35) {
    digitalWrite(fanPin, HIGH);
    digitalWrite(buzzerPin, LOW);
    lcd.setCursor(0, 1);
    lcd.print("Cooling Active  ");
  }
  // Critical Temperature
  else {
    digitalWrite(fanPin, HIGH);
    digitalWrite(buzzerPin, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("TEMP WARNING!   ");
  }
  
  delay(500); // Wait half a second before next reading
}
```
*Explanation:* 

- We read the raw analog value, convert it to voltage (ESP32 ADC is 12-bit, so it goes to 4095, and uses 3.3V), and then convert that voltage into a temperature in Celsius.

- The LCD prints the current temperature on the first line.

- The `if/else` logic checks the temperature:
  - `< 28°C`: Everything is normal. Fan and buzzer are off.
  - `>= 28°C and < 35°C`: Room is hot. Fan turns on to cool it down, but no alarm.
  - `>= 35°C`: Critical! Fan is on, and the buzzer sounds the alarm!
