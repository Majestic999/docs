# Project 2.14: Touch Free Hand Sanitizer Simulator

| **Description** | This project demonstrates a contactless automation system that uses proximity sensing to simulate hand sanitizer dispensing. An Ultrasonic Sensor detects when hands are close, triggering a Servo Motor to pump the sanitizer. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as hospitals, airports, schools, shopping centers, and public hygiene stations. It demonstrates how proximity sensors and servo-controlled mechanisms can support touch-free automation. |

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Ultrasonic Sensor

- Connect the **VCC** pin of the ultrasonic sensor to the positive power rail.

- Connect the **GND** pin of the ultrasonic sensor to the negative power rail.

- Connect the **Trig** (Trigger) pin to **GPIO 23** on the ESP32 board.

- Connect the **Echo** pin to **GPIO 33** on the ESP32 board.

**Step 3:** Wire the Servo Motor

- Connect the **VCC (Red or Brown)** wire of the servo to the positive power rail.

- Connect the **GND (Black or Brown)** wire of the servo to the negative power rail.

- Connect the **Signal (Yellow or Orange)** wire of the servo to **GPIO 19** on the ESP32 board.

### 1. Library Inclusion and Object Setup

```cpp
#include <ESP32Servo.h>

Servo dispenser; // Create a servo object to control the dispenser mechanism

const int trigPin = 23;
const int echoPin = 33;
const int servoPin = 19;
```
*Explanation:* We include the `ESP32Servo` library and name our motor `dispenser`. We define the pins for the ultrasonic sensor (Trig and Echo) and the Servo (servoPin).

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  
  dispenser.attach(servoPin); // Tell the servo object which pin to control
  dispenser.write(0);         // Move the servo to its starting (idle) position
}
```
*Explanation:* The trigger pin sends out the sound wave (OUTPUT), and the echo pin listens for the bounce back (INPUT). We attach the servo and set it to 0 degrees, which represents the pump being fully raised and not dispensing.

---

### 3. Loop Function

```cpp
void loop() {
  // 1. Send out an ultrasonic pulse
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  // 2. Measure the time it takes for the echo to return
  long duration = pulseIn(echoPin, HIGH);
  
  // 3. Calculate distance in centimeters
  // Speed of sound is ~343 m/s, or 0.034 cm/microsecond. Divide by 2 for the round trip.
  int distance = duration * 0.034 / 2;
  
  // 4. Check if hands are placed underneath the dispenser (within 10 cm)
  if (distance > 0 && distance < 10) {
    dispenser.write(90); // Press the pump down!
    delay(1000);         // Wait a second for hands to receive sanitizer
    
    dispenser.write(0);  // Release the pump back to original position
    delay(1000);         // Cooldown so it doesn't immediately dispense again
  }
  
  delay(100); // Small delay before taking the next reading
}
```
*Explanation:* 

- We trigger a tiny 10-microsecond sound pulse, and then use `pulseIn()` to time how long it takes to bounce off a hand and return to the echo pin.

- We do some math to convert that time into a `distance` in centimeters.

- The `if` statement checks if a hand is closer than 10 centimeters. If yes, it moves the servo to 90 degrees to simulate pushing down on a pump bottle. It waits, releases the pump back to 0 degrees, and waits again before continuing.
