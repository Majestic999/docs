## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the Buzzer on the breadboard with its pins in separate rows.

- (The LCD, RFID Reader, and PIR Sensor can be connected directly via jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) power rail on the breadboard.

- Connect the **3V3** pin on the ESP32 board to a separate empty row on the breadboard (for the RFID Reader).

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) ground rail on the breadboard.

**Step 2:** Wire the RFID Reader (MFRC522)

- Connect **3.3V (VCC)** of the RFID reader to the **3V3** row. *(**NB:** Do not connect to 5V!)*

- Connect **GND** of the RFID reader to the ground rail.

- Connect **RST** of the RFID reader to **GPIO 23** on the ESP32 board.

- Connect **MISO** of the RFID reader to **GPIO 26** on the ESP32 board.

- Connect **MOSI** of the RFID reader to **GPIO 25** on the ESP32 board.

- Connect **SCK** of the RFID reader to **GPIO 27** on the ESP32 board.

- Connect **SDA (SS)** of the RFID reader to **GPIO 33** on the ESP32 board.

**Step 3:** Wire the I2C LCD Display

- Connect **VCC** of the LCD to the **5V** positive rail.

- Connect **GND** of the LCD to the ground rail.

- Connect **SDA** of the LCD to **GPIO 21** on the ESP32 board.

- Connect **SCL** of the LCD to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the PIR Sensor and Buzzer

- Connect the **VCC** pin of the PIR motion sensor to the **5V** positive rail.

- Connect the **GND** pin of the PIR motion sensor to the ground rail.

- Connect the **OUT** (Signal) pin of the PIR motion sensor to **GPIO 2** on the ESP32 board.

- Connect the **positive (+)** terminal of the buzzer to **GPIO 18** on the ESP32 board.

- Connect the **negative (-)** terminal of the buzzer to the ground rail.

### 1. Library Inclusion, Object Setup, and Variables

```cpp
#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

#define SS_PIN 33
#define RST_PIN 23

#define PIR_PIN 2
#define BUZZER_PIN 18

MFRC522 rfid(SS_PIN, RST_PIN);
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Replace with your authorized card's UID bytes (find via Serial Monitor)
byte authorizedUID[4] = {0xDE, 0xAD, 0xBE, 0xEF};

bool authorizedAccess = false;
unsigned long accessTimer = 0;
const unsigned long accessDuration = 10000; // 10 seconds of access
```
*Explanation:* We include the necessary libraries and initialize the RFID and LCD. We define pins for the PIR and Buzzer. `authorizedUID` holds the secret byte array of our keycard. We also create variables to track if the system is currently "unlocked" (`authorizedAccess`), and a timer to lock it again after 10 seconds.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();

  pinMode(PIR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  digitalWrite(BUZZER_PIN, LOW); // Ensure alarm is off

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Security");
  lcd.setCursor(0, 1);
  lcd.print("System Ready");

  delay(2000);
  lcd.clear();
}
```
*Explanation:* Starts up all components, ensures the buzzer is off, and displays a startup message.

---

### 3. Alarm Function and Main Loop

```cpp
void alarm() {
  for (int i = 0; i < 5; i++) {
    // We use digitalWrite for a raw beeping if tone() is problematic, or tone():
    tone(BUZZER_PIN, 1000);
    delay(150);
    noTone(BUZZER_PIN);
    delay(150);
  }
}

void loop() {
  checkRFID();
  checkMotion();

  // Relock the system after 10 seconds
  if (authorizedAccess && (millis() - accessTimer > accessDuration)) {
    authorizedAccess = false;
    lcd.clear();
    lcd.print("System Locked");
    delay(1500);
    lcd.clear();
  }
}
```
*Explanation:* 

- `alarm()` is a custom helper function that simply pulses the buzzer 5 times rapidly.

- In the `loop()`, we constantly check for RFID cards and motion. If access was granted, we check `millis()` (the number of milliseconds since the ESP32 turned on). If 10 seconds have passed, we lock the system again!

---

### 4. Custom RFID and Motion Check Functions

```cpp
void checkRFID() {
  if (!rfid.PICC_IsNewCardPresent() || !rfid.PICC_ReadCardSerial()) {
    return;
  }
  
  bool match = true;
  for (byte i = 0; i < 4; i++) {
    if (rfid.uid.uidByte[i] != authorizedUID[i]) {
      match = false;
    }
  }

  if (match) {
    authorizedAccess = true;
    accessTimer = millis(); // Reset the 10-second timer
    
    lcd.clear();
    lcd.print("Access Granted");
    lcd.setCursor(0, 1);
    lcd.print("Welcome!");
    tone(BUZZER_PIN, 2000, 150); // Friendly beep
  } else {
    authorizedAccess = false;
    
    lcd.clear();
    lcd.print("Access Denied");
    lcd.setCursor(0, 1);
    lcd.print("Unknown Card");
    alarm(); // Sound the intruder alarm!
  }
  
  rfid.PICC_HaltA(); // Stop reading this card
  rfid.PCD_StopCrypto1();
  delay(1500);
  lcd.clear();
}

void checkMotion() {
  int motion = digitalRead(PIR_PIN);
  
  if (motion == HIGH) {
    if (!authorizedAccess) { // System is locked and someone is moving!
      lcd.clear();
      lcd.print("INTRUDER!");
      lcd.setCursor(0, 1);
      lcd.print("Motion Detected");
      alarm();
      delay(1000);
      lcd.clear();
    } else { // System is unlocked, movement is okay
      lcd.clear();
      lcd.print("Authorized");
      lcd.setCursor(0, 1);
      lcd.print("Movement");
      delay(500);
      lcd.clear();
    }
  }
}
```
*Explanation:* 

- `checkRFID()` reads the card and compares the bytes. If it matches, we unlock the system and start the 10-second countdown (`accessTimer`). If not, we lock it and sound the alarm.

- `checkMotion()` looks for PIR triggers. If movement is detected while `authorizedAccess` is FALSE (meaning no one scanned a valid card), it triggers the intruder alarm. If movement is detected while it is TRUE, it ignores it because the user is allowed to be there.

## CONCLUSION

The Multi-Level Security Alarm provides a robust demonstration of access control and intrusion detection. By scanning an authorized RFID card, the system temporarily grants access and suppresses alarms. If unauthorized motion is detected when the system is locked, or if an unrecognized card is scanned, the buzzer sounds and the LCD displays an alert, showcasing how different sensors can work together to secure an area.
