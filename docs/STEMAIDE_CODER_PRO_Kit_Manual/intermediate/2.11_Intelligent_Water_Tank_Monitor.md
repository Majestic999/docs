## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Water Level Sensor

- Connect the **VCC** (or +) pin of the water sensor to the positive power rail.

- Connect the **GND** (or -) pin of the water sensor to the negative power rail.

- Connect the **Signal** (or S) pin of the water sensor to **GPIO 36** (also labeled VP) on the ESP32 board.

**Step 3:** Wire the Buzzer

- Connect the **positive (+)** terminal of the buzzer to **GPIO 18** on the ESP32 board.

- Connect the **negative (-)** terminal of the buzzer to the negative power rail.

**Step 4:** Wire the I2C LCD Display

- Connect **VCC** of the LCD to the positive power rail.

- Connect **GND** of the LCD to the negative power rail.

- Connect **SDA** of the LCD to **GPIO 21** on the ESP32 board.

- Connect **SCL** of the LCD to **GPIO 22** on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

### 1. Library Inclusion and Object Setup

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

// Sensor and buzzer pins
const int waterPin = 36;
const int buzzerPin = 18;
```
*Explanation:* We include libraries for the LCD and define its address (`0x27`). We define `waterPin` for our analog water sensor reading and `buzzerPin` for the alarm.

---

### 2. Setup Function

```cpp
void setup() {
  lcd.init();
  lcd.backlight();
  pinMode(buzzerPin, OUTPUT);
}
```
*Explanation:* Initializes the LCD screen, turns on its backlight, and configures the buzzer pin as an output so we can sound the alarm.

---

### 3. Loop Function

```cpp
void loop() {
  // Read water level (0-4095 on ESP32)
  int waterLevel = analogRead(waterPin);
  
  // Display reading on the LCD
  lcd.setCursor(0, 0);
  lcd.print("Water: ");
  lcd.print(waterLevel);
  lcd.print("    "); // Clear any trailing digits
  
  // Low water condition
  if (waterLevel < 200) {
    digitalWrite(buzzerPin, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("Tank Low!     ");
  }
  // Medium (Normal) water condition
  else if (waterLevel >= 200 && waterLevel < 1500) {
    digitalWrite(buzzerPin, LOW);
    lcd.setCursor(0, 1);
    lcd.print("Level Normal  ");
  }
  // High water condition
  else {
    digitalWrite(buzzerPin, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("Tank Full!    ");
  }
  
  delay(500); // Check twice a second
}
```
*Explanation:* 

- We read the current water depth analog value. The deeper the water touching the sensor's traces, the higher the number.

- The LCD prints this raw value on the top line.

- The `if/else if/else` logic acts as our smart threshold:
  - `< 200`: The tank is almost empty! Buzzer sounds and LCD warns "Tank Low!".
  - `Between 200 and 1500`: The tank is fine. Buzzer is quiet, LCD says "Level Normal".
  - `>= 1500`: The tank is overflowing! Buzzer sounds again and LCD warns "Tank Full!". (You may need to adjust these threshold numbers depending on your sensor and water conductivity).
