# Project 1.6.1: Light Intensity Checker

| **Description** | This is a simple project that measures how bright or dark an environment is using an LDR (Light Dependent Resistor). It helps detect light levels and shows whether a place has high light intensity (bright) or low light intensity (dark), making it useful for automatic lighting systems and simple environmental monitoring. |
|------------------|----------------------------------------------------------------|
| **Use case**     |  An LDR (Light Dependent Resistor) is used in engineering systems to detect light levels and control devices automatically, such as turning street lights or home lights on at night and off during the day to save energy. In simple terms, it works like a small “eye” that senses brightness or darkness, helping systems react automatically to changes in light, like switching lights on when it gets dark. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 board and LDR Module:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the LDR Module on the breadboard. It typically has 4 pins: `VCC`, `GND`, `DO`, and `AO`.

Insert these into separate adjacent rows (e.g., Rows 20 to 23, Column A).
  - `VCC` pin in **Row 20, Column A**
  - `GND` pin in **Row 21, Column A**
  - `DO` (Digital Out) pin in **Row 22, Column A**
  - `AO` (Analog Out) pin in **Row 23, Column A**

![LDR fixed on breadboard](../../../assets/coder_pro/beginner/LDR_Module/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire Power and Ground

- Connect a jumper wire from **Row 20, Column B** (VCC pin) to the **3V3** or **5V** pin on the ESP32 board. (Check your module's operating voltage; 3.3V is standard for ESP32).

- Connect a jumper wire from **Row 21, Column B** (GND pin) to a **GND pin** on the ESP32 board.

**Step 2:** Wire the Signal Pins

- Connect a jumper wire from **Row 22, Column B** (DO pin) to **GPIO 2** on the ESP32 board.

- Connect a jumper wire from **Row 23, Column B** (AO pin) to **GPIO 36** (also labeled as VP) on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int LDR_PIN = 36;
const int DO_PIN = 2;
```
*Explanation:* We declare `LDR_PIN` as 36 for the analog reading and `DO_PIN` as 2 for the digital reading.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(DO_PIN, INPUT);
  Serial.begin(9600);
}
```
*Explanation:* The `setup()` function configures the digital pin as an `INPUT` so we can read from it. It also starts the Serial Monitor at a baud rate of 9600, allowing us to send data to the computer screen. The analog pin doesn't strictly need `pinMode` setup for reading.

---

### 3. Loop Function

```cpp
void loop() {
  int ldrValue = analogRead(LDR_PIN);
  int digitalValue = digitalRead(DO_PIN);
  
  Serial.print("Analog Value: ");
  Serial.println(ldrValue);
  
  Serial.print("Digital Value: ");
  Serial.println(digitalValue);
  
  delay(1000); // Wait 1 second before reading again
}
```
*Explanation:* 

- `analogRead(LDR_PIN)` reads the exact light intensity (0-4095 on ESP32).

- `digitalRead(DO_PIN)` reads a simple HIGH/LOW (1 or 0) indicating if the light has crossed a threshold (usually adjustable via a screw on the module).

- `Serial.print()` and `Serial.println()` send these values to your computer so you can see them.

- `delay(1000)` pauses the loop so the screen isn't flooded with numbers too quickly.
