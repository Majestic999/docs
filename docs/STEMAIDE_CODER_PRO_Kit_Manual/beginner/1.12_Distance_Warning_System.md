## Building the circuit

### Mounting Instructions

1. **ESP32 Microcontroller:**
   - Straddle the ESP32 board across the central divider of the breadboard so that its pins occupy columns **e** and **f**.
   - Align the top pins of the ESP32 with **Row 1** down through **Row 19**.

2. **Ultrasonic Sensor (HC-SR04):**
   - The ultrasonic sensor has four header pins: **VCC**, **Trig**, **Echo**, and **GND**.
   - Insert the sensor facing outwards near the middle of the breadboard:
     - **VCC pin** into **Row 25, Column e**
     - **Trig pin** into **Row 26, Column e**
     - **Echo pin** into **Row 27, Column e**
     - **GND pin** into **Row 28, Column e**
   - Ensure each pin is in its own unique row to avoid short-circuiting the sensor.

3. **Buzzer:**
   - Identify the buzzer terminals. The longer leg is the **Positive (+)** pin, and the shorter leg is the **Negative (-)** pin.
   - Insert the **longer positive leg** into **Row 32, Column e**.
   - Insert the **shorter negative leg** into **Row 33, Column e**.
   - Ensure both legs are installed in separate rows so current flows through the buzzer.

---

### Wiring Instructions

Connect the jumper wires from the corresponding breadboard rows to the ESP32 pin locations:

1. **Ultrasonic Sensor Power (VCC):**
   - Connect a male-to-male jumper wire from **Row 25** (Ultrasonic VCC) to the **5V / VIN pin** on the ESP32.

2. **Ultrasonic Sensor Ground (GND):**
   - Connect a jumper wire from **Row 28** (Ultrasonic GND) to a **GND pin** on the ESP32.

3. **Ultrasonic Sensor Trigger Pin (Trig):**
   - Connect a jumper wire from **Row 26** (Ultrasonic Trig) to **GPIO 23** on the ESP32.

4. **Ultrasonic Sensor Echo Pin (Echo):**
   - **Wire the Echo Pin Voltage Divider (5V to 3.3V Protection)**:
  - Connect a **1kΩ resistor** from the Ultrasonic Sensor's **ECHO** pin to **GPIO 33** on the ESP32 board.
  - Connect a **2kΩ resistor** from **GPIO 33** to the **GND** rail on the breadboard.
  > **Voltage Safety Notice:** Because the HC-SR04 operates at 5V, its Echo pin outputs a 5V signal. The 1kΩ/2kΩ voltage divider safely steps this down to ~3.33V, protecting the ESP32 GPIO 33 from over-voltage damage.

5. **Buzzer Positive Connection (+):**
   - Connect a jumper wire from **Row 32** (Buzzer Positive Leg) to **GPIO 22** on the ESP32.

6. **Buzzer Negative Connection (-):**
   - Connect a jumper wire from **Row 33** (Buzzer Negative Leg) to a **GND pin** on the ESP32.

7. **USB Cable:**
   - Connect the Micro USB cable to the ESP32 board and plug the opposite end into your computer.

## Programming

### Step 1: Variable Declarations

```cpp
int trigPin = 23;
int echoPin = 33;
int buzzerPin = 22;
```

*Explanation:* Here we define the ESP32 pin numbers connected to our hardware components. The trigger pin (`trigPin`) is assigned to GPIO 23, the echo pin (`echoPin`) to GPIO 33, and the warning buzzer (`buzzerPin`) to GPIO 22.

---

### Step 2: Setup Function

```cpp
void setup() {
 pinMode(trigPin, OUTPUT);
 pinMode(echoPin, INPUT);
 pinMode(buzzerPin, OUTPUT);
}
```

*Explanation:* The `setup()` function configures the pin modes. `trigPin` is set as an `OUTPUT` to send ultrasonic sound pulses out. `echoPin` is set as an `INPUT` to listen for returning echo signals. The `buzzerPin` is set as an `OUTPUT` to drive the audio alert.

---

### Step 3: Loop Function

```cpp
void loop() {
 digitalWrite(trigPin, LOW);
 delayMicroseconds(2);
 digitalWrite(trigPin, HIGH);
 delayMicroseconds(10);
 digitalWrite(trigPin, LOW);
 
 long duration = pulseIn(echoPin, HIGH);
 int distance = duration * 0.034 / 2;
 
 if(distance < 15){
   digitalWrite(buzzerPin, HIGH);
 }
 else{
   digitalWrite(buzzerPin, LOW);
 }
}
```

*Explanation:* In the main loop, we first clear the trigger pin by setting it `LOW` for 2 microseconds, then trigger a 10-microsecond high pulse to emit ultrasonic waves. We measure the pulse signal duration on `echoPin` using `pulseIn()`. The calculated time duration is converted to distance in centimeters using the speed of sound formula (`duration * 0.034 / 2`). If an object is closer than 15 cm, the ESP32 activates the buzzer (`HIGH`). Otherwise, the buzzer remains silent (`LOW`).
