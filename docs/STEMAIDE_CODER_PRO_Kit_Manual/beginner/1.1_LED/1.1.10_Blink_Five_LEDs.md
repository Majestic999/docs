| **Description** | This project shows how to make five LEDs turn on and off one after the other using an ESP32 board. It introduces light sequencing and timing control.|
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used to create decorative lighting effects, such as party lights that blink in a repeated pattern. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 board and 5 LEDs:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the 5 LEDs side-by-side along the lower section of the breadboard (e.g. from Row 20 to Row 28). For each LED, ensure the longer positive leg (anode) and the shorter negative leg (cathode) are in different rows.
  - **LED 1:** Anode in **Row 20, Column E**, Cathode in **Row 21, Column E**
  - **LED 2:** Anode in **Row 22, Column E**, Cathode in **Row 23, Column E**
  - **LED 3:** Anode in **Row 24, Column E**, Cathode in **Row 25, Column E**
  - **LED 4:** Anode in **Row 26, Column E**, Cathode in **Row 27, Column E**
  - **LED 5:** Anode in **Row 28, Column E**, Cathode in **Row 29, Column E**

**Step 2:** Add resistors:

- Place a 220Ω resistor bridging from each LED's cathode row to the common ground rail (negative strip) on the side of the breadboard. For example, connect a resistor from **Row 21, Column D** to the negative rail, **Row 23, Column D** to the negative rail, and so on.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the common Ground

- Connect a jumper wire from a **GND pin** on the ESP32 to the Negative (-) power rail on the breadboard.

**Step 2:** Wire the LEDs to the ESP32

- Connect a jumper wire from **Row 20, Column A** (LED 1 Anode) to **GPIO 19** on the ESP32 board.

- Connect a jumper wire from **Row 22, Column A** (LED 2 Anode) to **GPIO 18** on the ESP32 board.

- Connect a jumper wire from **Row 24, Column A** (LED 3 Anode) to **GPIO 5** on the ESP32 board.

- Connect a jumper wire from **Row 26, Column A** (LED 4 Anode) to **GPIO 4** on the ESP32 board.

- Connect a jumper wire from **Row 28, Column A** (LED 5 Anode) to **GPIO 2** on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Setup Function

```cpp
void setup() {
  pinMode(19, OUTPUT);
  pinMode(18, OUTPUT);
  pinMode(5, OUTPUT);
  pinMode(4, OUTPUT);
  pinMode(2, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures the five GPIO pins connected to our LEDs (19, 18, 5, 4, 2) as `OUTPUT`s so they can supply voltage to light up the LEDs.

---

### 2. Loop Function

```cpp
void loop() {
  digitalWrite(19, HIGH);
  delay(1000);
  digitalWrite(19, LOW);
  delay(1000);

  digitalWrite(18, HIGH);
  delay(1000);
  digitalWrite(18, LOW);
  delay(1000);

  digitalWrite(5, HIGH);
  delay(1000);
  digitalWrite(5, LOW);
  delay(1000);

  digitalWrite(4, HIGH);
  delay(1000);
  digitalWrite(4, LOW);
  delay(1000);

  digitalWrite(2, HIGH);
  delay(1000);
  digitalWrite(2, LOW);
  delay(1000);
}
```
*Explanation:* The `loop()` continuously runs, turning each LED on and off one by one. It sends a `HIGH` signal to GPIO 19, waits for 1 second (`delay(1000)`), and then sends a `LOW` signal to turn it off. This exact pattern is repeated sequentially for pins 18, 5, 4, and 2 before starting over at the top.
