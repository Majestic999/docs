# Project 1.1.4: Double LED Blink

| **Description** | This project shows how to make two LEDs blink one after the other using an ESP32 board. It helps learners understand basic timing and control of multiple outputs.
|------------------|----------------------------------------------------------------|
| **Use case**     | This type of blinking pattern can be used in simple warning lights, signal systems, and effects similar to police siren lights. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 board and 2 LEDs:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F. Press down gently.

- Place the first Red LED onto the breadboard:
  - Insert the longer positive leg (anode) into **Row 20, Column E**.
  - Insert the shorter negative leg (cathode) into **Row 21, Column E**.

- Place the second Red LED onto the breadboard:
  - Insert the longer positive leg (anode) into **Row 23, Column E**.
  - Insert the shorter negative leg (cathode) into **Row 24, Column E**.

- Connect one end of a 220Ω resistor to **Row 21, Column D** (first LED cathode) and the other end to the negative (-) ground rail.

- Connect one end of another 220Ω resistor to **Row 24, Column D** (second LED cathode) and the other end to the negative (-) ground rail.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the LEDs to the ESP32

- Connect a jumper wire from **Row 20, Column A** (First LED anode) to **GPIO 19** on the ESP32 board.

- Connect a jumper wire from **Row 23, Column A** (Second LED anode) to **GPIO 18** on the ESP32 board.

**Step 2:** Wire the common Ground

- Connect a jumper wire from a **GND pin** on the ESP32 to the Negative (-) power rail on the breadboard.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Setup Function

```cpp
void setup() {
  pinMode(19, OUTPUT);
  pinMode(18, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures both GPIO 19 and GPIO 18 as `OUTPUT`s so the ESP32 can send electrical signals to turn both LEDs on and off.

---

### 2. Loop Function

```cpp
void loop() {
  digitalWrite(19, HIGH);
  delay(1000);
  digitalWrite(19, LOW);
  delay(1000);

  digitalWrite(18, HIGH);
  delay(1000);
  digitalWrite(18, LOW);
  delay(1000);
}
```
*Explanation:* The `loop()` continuously runs. 
It first turns on the LED attached to pin 19 (`HIGH`), waits 1 second, and turns it off (`LOW`), waiting another 1 second.

Then, it moves to the second LED attached to pin 18, turns it `HIGH`, waits 1 second, and turns it `LOW`, waiting another 1 second. 
The entire sequence then repeats, making the LEDs blink one after the other.
