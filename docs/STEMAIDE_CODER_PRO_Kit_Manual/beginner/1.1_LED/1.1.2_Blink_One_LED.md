## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and LED onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F. Press down gently until seated.

- Place the Red LED onto the breadboard:
  - Insert the longer positive leg (anode) into **Row 10, Column E**.
  - Insert the shorter negative leg (cathode) into **Row 11, Column E**.

- Connect one end of the 220Ω resistor to **Row 11, Column D** (in the same row as the LED cathode) and the other end to the negative (-) ground rail.

![LED fixed on breadboard](../../../assets/coder_pro/beginner/LED_BLINK/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Connect the LED to the ESP32:

- Connect a jumper wire from **Row 10, Column A** (LED anode) to **GPIO 19** on the ESP32 board.

**Step 2:** Connect the common ground:

- Connect a jumper wire from a **GND pin** on the ESP32 to the negative (-) power rail on the breadboard.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Setup Function

```cpp
void setup() {
  pinMode(19, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures GPIO pin 19 as an `OUTPUT` so the ESP32 can send electrical signals to turn the LED on and off.

---

### 2. Loop Function

```cpp
void loop() {
  digitalWrite(19, HIGH);
  delay(1000);
  digitalWrite(19, LOW);
  delay(1000);
}
```
*Explanation:* The `loop()` continuously runs. 
First, `digitalWrite(19, HIGH)` sends voltage to the LED, turning it ON.

Then, `delay(1000)` tells the ESP32 to wait for 1000 milliseconds (1 second). 
Next, `digitalWrite(19, LOW)` stops the voltage, turning the LED OFF. 
Finally, another `delay(1000)` creates a 1-second pause before the loop starts over again, creating a steady blinking effect.
