| **Description** | This project simulates a drawbridge using a servo motor. A push button is used to raise and lower the bridge manually. Each press of the button changes the bridge position between lowered and raised states. |

## Mounting the Components on the Breadboard

**Step 1: Mount the ESP32 Board**

1. Position the ESP32 board at the top of the breadboard, straddling the central divider gap.

2. Align pin 1 (3V3) at Row 1, Column E, and pin 19 (CLK) at Row 19, Column E.

3. Align pin 20 (GND) at Row 1, Column F, and pin 38 (GPIO 23) at Row 19, Column F.

4. Press down firmly until the pins are fully inserted into the breadboard holes.

**Step 2: Mount the Push Button**

1. Align the four-pin tactile push button over the central divider gap at Row 25 and Row 27.

2.

Insert top-left pin into Row 25, Column E, and top-right pin into Row 25, Column F.

3.

Insert bottom-left pin into Row 27, Column E, and bottom-right pin into Row 27, Column F.

4. Press firmly until the button sits flat on the breadboard.

**Step 3: Mount the Pull-Down Resistor**

1.

Take a 10kΩ resistor (Color code: Brown-Black-Orange-Gold).

2.

Insert one terminal lead into Row 27, Column I (connected to the bottom-right leg of the push button).

3.

Insert the second terminal lead into the negative power rail (GND) on the right side of the breadboard.

**Step 4: Mount the Servo Motor Header**

1. Position the 3-pin connector header of the Servo Motor near the bottom of the breadboard across Rows 31 to 33 in Column J.

2.

Ensure the pin layout corresponds to:
   - Row 31: Brown/Black Wire (GND)
   - Row 32: Red Wire (5V / Power)
   - Row 33: Orange/Yellow Wire (Signal)

## Wiring Instructions

Follow the precise step-by-step wiring standard below to connect the components using jumper wires:

1. **Power Rail Connections:**
   - Connect a jumper wire from Row 19, Column J (ESP32 5V/VIN pin) to the positive power rail (+) on the right side of the breadboard.
   - Connect a jumper wire from Row 14, Column J (ESP32 GND pin) to the negative power rail (-) on the right side of the breadboard.

2. **Push Button Wiring:**
   - Connect a jumper wire from Row 25, Column A (top-left pin of the push button) to the positive power rail (+).
   - Connect a jumper wire from Row 27, Column C (bottom-left pin of the push button) to Row 11, Column A (ESP32 GPIO 2).

3. **Servo Motor Wiring:**
   - Connect a jumper wire from Row 31, Column I (Servo GND / Brown wire) to the negative power rail (-) on the right side.
   - Connect a jumper wire from Row 32, Column I (Servo VCC / Red wire) to the positive power rail (+) on the right side.
   - Connect a jumper wire from Row 33, Column I (Servo Signal / Orange wire) to Row 19, Column A (ESP32 GPIO 23).

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write and structure your code block by block as shown below:

### Logic Block 1: Library Inclusions, Pin Definitions, and Variable Declarations

```cpp
#include <ESP32Servo.h>

const int BUTTON_PIN = 2;
const int SERVO_PIN = 23;

Servo drawbridgeServo;

int buttonState = LOW;
int lastButtonState = LOW;
bool isRaised = false;

unsigned long lastDebounceTime = 0;
const unsigned long debounceDelay = 50;
```

*Explanation:* 
This block includes the `ESP32Servo` library to allow hardware PWM servo control. It assigns GPIO 2 to the push button and GPIO 23 to the servo motor signal pin. An instance of the `Servo` class named `drawbridgeServo` is instantiated. Variables are initialized to track the bridge position state (`isRaised`), monitor button state toggles, and store software debounce timing variables to prevent false triggers from button contacts.

---

### Logic Block 2: Setup Function

```cpp
void setup() {
  Serial.begin(115200);
  pinMode(BUTTON_PIN, INPUT);
  
  drawbridgeServo.attach(SERVO_PIN);
  drawbridgeServo.write(0); // Start at lowered position (0 degrees)
  
  Serial.println("System Ready: Drawbridge is in the LOWERED position.");
}
```

*Explanation:* 
The `setup()` function configures serial communication at a 115200 baud rate for diagnostic output. GPIO 2 is configured as a digital input to read signals from the push button circuit. The servo object is attached to GPIO 23, and initialized to 0 degrees, setting the initial physical position of the drawbridge to "lowered."

---

### Logic Block 3: Loop Function and Bridge Control Logic

```cpp
void loop() {
  int reading = digitalRead(BUTTON_PIN);

  if (reading != lastButtonState) {
    lastDebounceTime = millis();
  }

  if ((millis() - lastDebounceTime) > debounceDelay) {
    if (reading != buttonState) {
      buttonState = reading;

      if (buttonState == HIGH) {
        isRaised = !isRaised;

        if (isRaised) {
          Serial.println("Action: Raising Drawbridge...");
          for (int pos = 0; pos <= 90; pos += 1) {
            drawbridgeServo.write(pos);
            delay(15);
          }
          Serial.println("State: Drawbridge RAISED.");
        } else {
          Serial.println("Action: Lowering Drawbridge...");
          for (int pos = 90; pos >= 0; pos -= 1) {
            drawbridgeServo.write(pos);
            delay(15);
          }
          Serial.println("State: Drawbridge LOWERED.");
        }
      }
    }
  }

  lastButtonState = reading;
}
```

*Explanation:* 
The `loop()` function continuously reads the push button input pin. It implements software debouncing using `millis()` to filter mechanical noise from the button press. When a valid high state transition is detected, the `isRaised` state toggles. The code then uses a `for` loop to step the servo position incrementally between 0 degrees and 90 degrees with a 15-millisecond delay between steps, producing a smooth mechanical movement during bridge raising and lowering actions.
