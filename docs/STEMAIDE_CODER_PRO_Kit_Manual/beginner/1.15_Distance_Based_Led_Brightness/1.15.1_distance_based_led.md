# Project 1.15.1: Distance-based LED Brightness Control

| **Description** | This project uses an ultrasonic sensor to control the brightness of an LED. As an object moves closer to the sensor, the LED becomes brighter. As the object moves farther away, the LED gradually becomes dimmer.| 
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use case** | Touchless lighting systems, proximity-based indicators, parking assistance systems, interactive STEM demonstrations.|

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32, Ultrasonic Sensor, and LED onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so its left pins sit in Column E and right pins in Column F.

- Locate the 4 pins on the HC-SR04 Ultrasonic sensor (`VCC`, `TRIG`, `ECHO`, `GND`).

Insert the sensor into the lower section of the breadboard (e.g., Rows 25 to 28, Column A) ensuring each pin is on a separate row:
  - `VCC` pin in **Row 25, Column A**
  - `TRIG` pin in **Row 26, Column A**
  - `ECHO` pin in **Row 27, Column A**
  - `GND` pin in **Row 28, Column A**

- Place the LED on the breadboard nearby:
  - Insert the longer positive leg (anode) into **Row 10, Column E**.
  - Insert the shorter negative leg (cathode) into **Row 11, Column E**.

- Connect one end of the 220Ω resistor to **Row 11, Column D** (in the same row as the LED cathode) and the other end to the negative (-) ground rail.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1: Wire the Ultrasonic Sensor**

- Connect a jumper wire from **Row 25, Column B** (VCC pin) to the **5V / VIN pin** on the ESP32 board.

- Connect a jumper wire from **Row 26, Column B** (TRIG pin) to **GPIO 23** on the ESP32 board.

- **Wire the Echo Pin Voltage Divider (5V to 3.3V Protection)**:
  - Connect a **1kΩ resistor** from the Ultrasonic Sensor's **ECHO** pin to **GPIO 33** on the ESP32 board.
  - Connect a **2kΩ resistor** from **GPIO 33** to the **GND** rail on the breadboard.
  > **Voltage Safety Notice:** Because the HC-SR04 operates at 5V, its Echo pin outputs a 5V signal. The 1kΩ/2kΩ voltage divider safely steps this down to ~3.33V, protecting the ESP32 GPIO 33 from over-voltage damage.

- Connect a jumper wire from **Row 28, Column B** (GND pin) to a **GND pin** on the ESP32 board (or common ground rail).

**Step 2: Wire the LED**

- Connect a jumper wire from **Row 10, Column A** (LED anode) to **GPIO 4** on the ESP32 board.

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

### 1. Variable Declarations

```cpp
int trigPin = 23;
int echoPin = 33;
int ledPin = 4;
```
*Explanation:* We declare integer variables to map the physical wiring connections to code names. The `trigPin` is attached to GPIO 23, the `echoPin` to GPIO 33, and the `ledPin` to GPIO 4.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}
```
*Explanation:* The `setup()` function runs once. It configures the `trigPin` and `ledPin` as outputs so the ESP32 can send voltage out to the sensor and LED. It configures the `echoPin` as an input so the ESP32 can "listen" to the returning signal from the ultrasonic sensor. The `Serial.begin(9600)` command starts communication with the computer so we can print out the distance measurements.

---

### 3. Loop Function

```cpp
void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.print(" cm");

  int brightness = 0;
  if (distance < 50) {
    brightness = map(distance, 5, 50, 255, 0);
    if (brightness > 255) brightness = 255;
    if (brightness < 0) brightness = 0;
  }
  
  analogWrite(ledPin, brightness);
  
  Serial.print(" | Brightness: ");
  Serial.println(brightness);

  delay(100);
}
```
*Explanation:* The `loop()` continuously runs. 
First, we trigger the ultrasonic sensor by sending a 10-microsecond `HIGH` pulse to `trigPin`. 
Second, we use `pulseIn()` on the `echoPin` to measure how long the sound wave took to bounce back, and calculate the `distance` in centimeters.
Third, we check if the object is closer than 50 cm. If it is, we use the `map()` function to inversely translate the distance (from 5cm to 50cm) into a brightness level (from 255 down to 0). This means the closer the object (e.g. 5cm), the brighter the LED (255). 
Finally, `analogWrite(ledPin, brightness)` sends the calculated PWM brightness to the LED, and a 100ms `delay` repeats the process.

## OBSERVATION

- When your hand is very close to the sensor, the LED shines at maximum brightness. 

- As your hand moves away, the LED becomes dimmer. 

- At distances greater than 50 cm, the LED turns off. 

- The Serial Monitor displays both the measured distance and the LED brightness value. 

## CONCLUSION

This project demonstrates ultrasonic distance measurement, PWM-based brightness control, analog output simulation, and real-time sensor interaction. It provides a practical introduction to touchless control systems and shows how sensor data can be used to dynamically adjust electronic outputs.
