## Mounting Instructions

1. **ESP32 Microcontroller Placement:** Place the ESP32 board straddling the central divider of the breadboard, with pin 3V3 placed in row 1 column E and pin GND placed on row 14 column E.

Ensure the left pins sit in column E (rows 1 to 15) and right pins sit in column F (rows 1 to 15).

2. **Push Button Mounting:** Place the 4-pin push button across the central divider.

Insert the top-left pin into row 20 column E and the top-right pin into row 20 column F.

Insert the bottom-left pin into row 22 column E and the bottom-right pin into row 22 column F.

Ensure top and bottom pins reside in separate rows to prevent short circuits.

3. **RGB Module Mounting:** Insert the 4 pins of the RGB 3-color module into consecutive rows on the breadboard.

Insert the GND (-) terminal pin into row 26 column E, the Red pin (R) into row 27 column E, the Green pin (G) into row 28 column E, and the Blue pin (B) into row 29 column E.

Ensure each pin occupies a distinct row to prevent electrical shorts.

## Wiring Instructions

1. **Push Button Signal Wiring:** Insert a jumper wire from row 20 column A (connected to one terminal of the push button) to row 10 column A on the breadboard, which connects to **GPIO 2** on the ESP32.

2. **Push Button Ground Wiring:** Connect a jumper wire from row 22 column A (connected to the opposite terminal of the push button) to row 14 column A on the breadboard, which connects to the **GND** pin of the ESP32.

3. **RGB Module Ground Wiring:** Insert a jumper wire from row 26 column A (connected to the GND (-) pin of the RGB module) to row 14 column B on the breadboard, which connects to the **GND** pin of the ESP32.

4. **RGB Red Channel Wiring:** Connect a jumper wire from row 27 column A (connected to the R pin of the RGB module) to row 11 column A on the breadboard, which connects to **GPIO 4** on the ESP32.

5. **RGB Green Channel Wiring:** Connect a jumper wire from row 28 column A (connected to the G pin of the RGB module) to row 6 column J on the breadboard, which connects to **GPIO 18** on the ESP32.

6. **RGB Blue Channel Wiring:** Connect a jumper wire from row 29 column A (connected to the B pin of the RGB module) to row 5 column J on the breadboard, which connects to **GPIO 19** on the ESP32.

_Make sure to connect the Micro USB cable to the ESP32 board._

### Variable Declarations and Pin Definitions

```cpp
const int buttonPin = 2;
const int redPin = 4;
const int greenPin = 18;
const int bluePin = 19;

int buttonState = HIGH;
int lastButtonState = HIGH;
int color = 0;
```

*Explanation:* This section defines the constants for hardware connection pins (`buttonPin` set to GPIO 2, `redPin` to GPIO 4, `greenPin` to GPIO 18, and `bluePin` to GPIO 19). It also creates global variables to keep track of the current button state, the previous button state, and the active color pattern index (`color`).

### Setup Function

```cpp
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);

  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);

  setColor(0);   // Start with Red
}
```

*Explanation:* The `setup()` function runs once when the board powers on. `pinMode(buttonPin, INPUT_PULLUP)` enables the internal pull-up resistor for the push button pin, setting its default unpressed state to HIGH. The RGB control pins are configured as outputs using `pinMode()`. Finally, `setColor(0)` is called to initialize the display with the first color state (Red).

### Loop Function

```cpp
void loop() {
  buttonState = digitalRead(buttonPin);

  // Detect button press
  if (lastButtonState == HIGH && buttonState == LOW) {
    color++;
    if (color > 6) color = 0;

    setColor(color);

    delay(200); // Debounce
  }

  lastButtonState = buttonState;
}
```

*Explanation:* The `loop()` function continuously monitors the state of the push button. It reads the pin value using `digitalRead()` and compares it to `lastButtonState`. When a falling edge is detected (transition from HIGH to LOW indicating a button press), `color` increments to the next index (cycling back to 0 if it exceeds 6). The helper function `setColor()` is called to update the RGB pins, followed by a 200 ms `delay()` to handle switch debouncing. The function ends by saving the current state into `lastButtonState`.

### Helper Function: State Control

```cpp
void setColor(int c) {
  switch (c) {
    case 0: // Red
      digitalWrite(redPin, HIGH);
      digitalWrite(greenPin, LOW);
      digitalWrite(bluePin, LOW);
      break;

    case 1: // Green
      digitalWrite(redPin, LOW);
      digitalWrite(greenPin, HIGH);
      digitalWrite(bluePin, LOW);
      break;

    case 2: // Blue
      digitalWrite(redPin, LOW);
      digitalWrite(greenPin, LOW);
      digitalWrite(bluePin, HIGH);
      break;

    case 3: // Yellow
      digitalWrite(redPin, HIGH);
      digitalWrite(greenPin, HIGH);
      digitalWrite(bluePin, LOW);
      break;

    case 4: // Cyan
      digitalWrite(redPin, LOW);
      digitalWrite(greenPin, HIGH);
      digitalWrite(bluePin, HIGH);
      break;

    case 5: // Magenta
      digitalWrite(redPin, HIGH);
      digitalWrite(greenPin, LOW);
      digitalWrite(bluePin, HIGH);
      break;

    case 6: // White
      digitalWrite(redPin, HIGH);
      digitalWrite(greenPin, HIGH);
      digitalWrite(bluePin, HIGH);
      break;
  }
}
```

*Explanation:* The `setColor()` function uses a `switch` statement to set the appropriate digital HIGH/LOW states on the RGB pins corresponding to the passed integer `c`. Each case drives a unique combination of Red, Green, and Blue output lines to output distinct colors (Red, Green, Blue, Yellow, Cyan, Magenta, White).
