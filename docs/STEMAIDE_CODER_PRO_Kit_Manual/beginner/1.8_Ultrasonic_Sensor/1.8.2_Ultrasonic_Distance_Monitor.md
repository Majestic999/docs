## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Ultrasonic Sensor:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the Ultrasonic sensor on the breadboard so its 4 pins (VCC, Trig, Echo, GND) sit in separate adjacent rows (e.g., Rows 10 to 13, Column A).

![Component on breadboard](../../../assets/coder_pro/beginner/Ultrasonic_Sensor/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Connect Power and Ground

- Connect a jumper wire from the **VCC** pin on the sensor to the **5V** or **VIN** pin on your ESP32 board.

- Connect a jumper wire from the **GND** pin on the sensor to a **GND pin** on your ESP32 board.

**Step 2:** Connect the Signal Pins

- Connect a jumper wire from the **Trig** pin on the sensor to **GPIO 23** on your ESP32 board.

- Connect a jumper wire from the **Echo** pin on the sensor to **GPIO 33** on your ESP32 board.

![Component on breadboard](../../../assets/coder_pro/beginner/Ultrasonic_Sensor/circuit_5.png)

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int trigPin = 23;
const int echoPin = 33;

long duration;
int distance;
```
*Explanation:* We declare `trigPin` as 23 and `echoPin` as 33 to match our physical wiring. `duration` will store how long the sound wave took to travel, and `distance` will store the final calculated distance in cm.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}
```
*Explanation:* We configure the `trigPin` as an output to send the sound pulse, and the `echoPin` as an input to receive the bounce-back. We also initialize the Serial monitor at 9600 baud rate to view the output on the computer.

---

### 3. Loop Function

```cpp
void loop() {
  // Clear the trigPin
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  
  // Send a 10 microsecond pulse to trigger the sensor
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  // Read the echo pin time
  duration = pulseIn(echoPin, HIGH);
  
  // Calculate distance in cm (Speed of sound is ~0.034 cm/us)
  distance = duration * 0.034 / 2;
  
  // Print to the serial monitor
  Serial.print("Distance: ");
  Serial.println(distance);
  
  delay(100);
}
```
*Explanation:* The code sends a short 10-microsecond high pulse from the `trigPin` to emit an ultrasonic sound wave. It then measures how long the `echoPin` stays HIGH using `pulseIn()`. The math `duration * 0.034 / 2` calculates the distance to the obstacle in centimeters. The result is printed to the Serial Monitor.
