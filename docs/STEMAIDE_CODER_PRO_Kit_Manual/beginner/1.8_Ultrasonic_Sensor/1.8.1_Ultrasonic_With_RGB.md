# Project 1.8.1: Smart lightening system with RGB module.

| **Description** | This project shows how to use an ultrasonic sensor and an RGB module with an ESP32 board. The RGB lights change when an object comes close to the ultrasonic sensor. |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use case**    | This project can be used as a smart lighting system where different colours appear depending on the distance detected by the ultrasonic sensor.                                  |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32, Ultrasonic Sensor, and RGB module:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the Ultrasonic sensor on the breadboard so its 4 pins (VCC, Trig, Echo, GND) sit in separate adjacent rows (e.g., Rows 10 to 13, Column A).

- Place the RGB module on the breadboard so its 4 pins (R, GND, G, B) sit in separate adjacent rows (e.g., Rows 20 to 23, Column A).

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the Ultrasonic Sensor to the ESP32

- Connect **VCC** of the ultrasonic sensor to the **5V** or **VIN** pin on the ESP32.

- Connect **GND** of the ultrasonic sensor to a **GND pin** on the ESP32.

- Connect **Trig** of the ultrasonic sensor to **GPIO 4** on the ESP32.

- Connect **Echo** of the ultrasonic sensor to **GPIO 2** on the ESP32.

**Step 2:** Wire the RGB Module to the ESP32

- Connect **GND** (-) of the RGB module to a **GND pin** on the ESP32.

- Connect the **R** (Red) pin to **GPIO 5** on the ESP32.

- Connect the **G** (Green) pin to **GPIO 18** on the ESP32.

- Connect the **B** (Blue) pin to **GPIO 19** on the ESP32.

![connect red jumper wire to RGB](../../../assets/coder_pro/beginner/ultrasonic_sensor_rgb/circuit_9.png)

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int echoPin = 2;
const int trigPin = 4;

const int redPin = 5;
const int greenPin = 18;
const int bluePin = 19;

long duration;
long distance;
const int dis_threshold = 15;
```
*Explanation:* We declare variables linking to the GPIO pins for the ultrasonic sensor (`echoPin`, `trigPin`) and the RGB module (`redPin`, `greenPin`, `bluePin`). We also declare variables to store the `duration` of the sound wave and the calculated `distance`. The `dis_threshold` is set to 15 cm.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(echoPin, INPUT);
  pinMode(trigPin, OUTPUT);
  
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  
  Serial.begin(9600);
}
```
*Explanation:* The `setup()` function configures the `echoPin` as an input to receive sound waves, and the `trigPin` as an output to send them. All RGB pins are set as outputs. `Serial.begin(9600)` starts communication with the computer to print distances.

---

### 3. Loop Function

```cpp
void loop() {
  // Clear the trigPin
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  
  // Send a 10 microsecond pulse to trigger the sensor
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  // Read the echo pin time
  duration = pulseIn(echoPin, HIGH);
  
  // Calculate distance in cm
  distance = duration * 0.034 / 2;
  
  Serial.print(distance);
  Serial.println(" cm");
  
  // Check if an object is closer than the threshold
  if (distance < dis_threshold) {
    // Flash RGB colors
    digitalWrite(redPin, HIGH);
    delay(200);
    digitalWrite(redPin, LOW);
    
    digitalWrite(bluePin, HIGH);
    delay(200);
    digitalWrite(bluePin, LOW);
    
    digitalWrite(greenPin, HIGH);
    delay(200);
    digitalWrite(greenPin, LOW);
  } else {
    // Turn all lights off if no object is close
    digitalWrite(redPin, LOW);
    digitalWrite(greenPin, LOW);
    digitalWrite(bluePin, LOW);
  }
  
  delay(100);
}
```
*Explanation:* The `loop()` continuously triggers the ultrasonic sensor to measure distance. If the distance is less than `dis_threshold` (15 cm), it cycles through Red, Blue, and Green lights, creating an alert effect. If an object is further away, all lights stay off.
