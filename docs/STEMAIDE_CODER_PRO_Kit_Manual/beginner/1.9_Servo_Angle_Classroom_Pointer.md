## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Potentiometer:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F. Press down gently until seated.

- Place the three pins of the potentiometer into three separate adjacent rows on the breadboard lower down (e.g., Rows 25 to 27, Column E):
  - Left pin (Terminal 1) into **Row 25, Column E**.
  - Middle pin (Wiper) into **Row 26, Column E**.
  - Right pin (Terminal 2) into **Row 27, Column E**.

**Step 2:** Prepare the Servo Motor:

- Keep the servo motor loose next to the breadboard. Note the three wire colors on the servo's female connector (usually Brown/Black for GND, Red for VCC, and Orange/Yellow for Signal).

Use male-to-male jumper wires to plug into these female slots so they can be connected to the breadboard.

## WIRING THE CIRCUIT

Follow these step-by-step connection details using your jumper wires:

**Step 1: Set up the common power rail**

- Connect a jumper wire from the **5V / VIN pin** on the ESP32 to the Positive (+) Power Rail on the breadboard.

- Connect a jumper wire from a **GND pin** on the ESP32 to the Negative (-) Power Rail on the breadboard.

![Components on breadboard](../../assets/coder_pro/beginner/ServoAngle_Classroom_Pointer/circuit_2.png)
![Components on breadboard](../../assets/coder_pro/beginner/ServoAngle_Classroom_Pointer/circuit_3.png)

**Step 2: Wire the Potentiometer**

- Connect a jumper wire from **Row 25, Column A** (Left pin) to the Positive (+) Power Rail.

- Connect a jumper wire from **Row 27, Column A** (Right pin) to the Negative (-) Power Rail.

- Connect a jumper wire from **Row 26, Column A** (Middle pin/wiper) to **GPIO 36** on the ESP32 board.

![Components on breadboard](../../assets/coder_pro/beginner/ServoAngle_Classroom_Pointer/circuit_6.png)

**Step 3: Wire the Servo Motor**

- Connect the Servo's **VCC (Red)** wire to the Positive (+) Power Rail.

- Connect the Servo's **GND (Brown/Black)** wire to the Negative (-) Power Rail.

- Connect the Servo's **Signal (Orange/Yellow)** wire to **GPIO 18** on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Library and Variable Declarations

```cpp
#include <ESP32Servo.h>

Servo servo1;

const int servoPin = 18;
const int sensorPin = 36;
```
*Explanation:* We include the `Servo.h` library to easily control the servo motor. We create a Servo object named `servo1`.

Then we define our GPIO pins: `servoPin` is connected to GPIO 18, and `sensorPin` is connected to GPIO 36 for the potentiometer.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
  servo1.attach(servoPin);
}
```
*Explanation:* The `setup()` function runs once. We start the serial monitor at 9600 baud so we can view the angle readings. We also use `servo1.attach(servoPin)` to link our servo object to GPIO 18 so it can send control signals to the physical motor.

---

### 3. Loop Function

```cpp
void loop() {
  int value = analogRead(sensorPin);
  int angle = map(value, 0, 4095, 0, 180);

  servo1.write(angle);

  Serial.print("Potentiometer: ");
  Serial.print(value);
  Serial.print("  Angle: ");
  Serial.println(angle);

  delay(15);
}
```
*Explanation:* The `loop()` continuously runs. `analogRead()` reads the potentiometer's value, which on an ESP32 ranges from 0 to 4095. The `map()` function converts this large range down to an angle between 0 and 180 degrees. `servo1.write(angle)` moves the motor to that mapped angle. Finally, the values are printed to the Serial Monitor and a small 15-millisecond `delay` allows the servo time to reach the physical position before reading the dial again.

## CONCLUSION

When you twist the potentiometer knob, the servo motor will sweep its arm in direct proportion to your movement. Turning the dial fully left moves the servo to 0 degrees, and turning it fully right moves it to 180 degrees. This provides a direct mechanical pointer representing your analog input!
