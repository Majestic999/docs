# Project 1.3.5: Push-Button Door Lock

| **Description** | This project creates a simple digital door lock using a push button and a servo motor. The ESP32 board counts the number of button presses, and when the correct number of presses is entered, the servo unlocks the door for a few seconds before automatically locking again.
|
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use case** | Electronic door locks, access control systems, cabinet security, and basic password-protected mechanisms.|

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Push Button onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so its left pins sit in Column E and right pins in Column F.

- Place the 4-pin tactile Push Button across the center trench of the breadboard further down (e.g., Rows 25 and 27). This isolates the left and right legs.
  - Top-left pin in **Row 25, Column E**
  - Bottom-left pin in **Row 27, Column E**

**Step 2:** Prepare the Servo Motor:

- Keep the servo motor loose next to the breadboard. Note the three wire colors on the servo's female connector (usually Brown/Black for GND, Red for VCC, and Orange/Yellow for Signal).

Use male-to-male jumper wires to plug into these female slots so they can be connected to the breadboard.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the Push Button

- Connect a jumper wire from **Row 25, Column A** (top-left button pin) to a **GND pin** on the ESP32 board.

- Connect a jumper wire from **Row 27, Column A** (bottom-left button pin) to **GPIO 2** on the ESP32 board.

**Step 2:** Wire the Servo Motor

- Connect the Servo's **VCC (Red)** wire to the **5V / VIN pin** on the ESP32 board.

- Connect the Servo's **GND (Brown/Black)** wire to a **GND pin** on the ESP32 board.

- Connect the Servo's **Signal (Orange/Yellow)** wire to **GPIO 19** on the ESP32 board.

## PROGRAMMING

### 1. Library and Variable Declarations

```cpp
#include <ESP32Servo.h>

Servo lockServo;

int buttonPin = 2;
int servoPin = 19;
int pressCount = 0;
int lastButtonState = HIGH;

bool locked = true;
const int code = 3;
```
*Explanation:* We include `Servo.h` to easily control the servo. We define the button on GPIO 2 and the servo on GPIO 19. We also create tracking variables: `pressCount` to count how many times the button has been pressed, `lastButtonState` (set to `HIGH` because we use `INPUT_PULLUP`), and `locked` to track the state of the door. The `code` variable is our "password" (3 presses to unlock).

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  lockServo.attach(servoPin);
  lockServo.write(0); // Set initial locked position
}
```
*Explanation:* The `setup()` function runs once. It configures the `buttonPin` as an `INPUT_PULLUP` so it defaults to `HIGH` and goes `LOW` when pressed. It attaches the `lockServo` to GPIO 19 and turns it to 0 degrees to simulate a locked deadbolt.

---

### 3. Loop Function

```cpp
void loop() {
  int buttonState = digitalRead(buttonPin);
  
  // Detect a button press (transition from HIGH to LOW)
  if (buttonState == LOW && lastButtonState == HIGH) {
    pressCount++;
    delay(200); // Debounce delay
  }
  
  lastButtonState = buttonState;
  
  // Check if correct code is entered
  if (pressCount >= code && locked) {
    lockServo.write(90); // Unlock position
    locked = false;
    
    delay(3000); // Keep unlocked for 3 seconds
    
    lockServo.write(0); // Return to locked position
    locked = true;
    pressCount = 0; // Reset counter for next time
  }
}
```
*Explanation:* The `loop()` continuously reads the `buttonPin`. It detects when the button is physically pressed down by checking if it changed from `HIGH` to `LOW`. If pressed, it adds 1 to `pressCount`. 
Next, it checks if the `pressCount` has reached our `code` (3). If it has, the servo turns to 90 degrees (unlocking the door) and waits for 3 seconds. Afterward, it automatically returns the servo to 0 degrees (locking the door again) and resets the `pressCount` to 0 so the user has to type the code again to get back in.

## OBSERVATION

- Each button press increases the internal counter. 

- The servo remains locked until the correct number of presses is reached. 

- After three presses, the servo rotates to the unlock position (90 degrees). 

- The servo stays unlocked for 3 seconds. 

- The servo automatically returns to the locked position (0 degrees). 

- The counter resets after each successful unlock. 

## CONCLUSION

This project introduces button input detection, counting mechanisms, servo motor control, and simple password-based access systems. It demonstrates how digital inputs can be used to trigger mechanical actions and serves as a foundation for more advanced electronic locking systems.
