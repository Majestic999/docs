# Project 1.3.4: LED Control with ESP32 board and Push Button

| **Description** | In this project, you will learn how to use a push button to control four LEDs with an ESP32 board. The push button acts as an input switch that sends a signal to the ESP32 board, which then controls the four LEDs by blinking them in a sequence based on programmed instructions. This helps to demonstrate how a single input device can trigger a complex multiple output sequence in a simple electronic control system.|
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use case** | This project can be used in simple control and indicator systems where multiple status signals are triggered by a user action. For example, the push button can be used to initiate a light show, progress indicators, or sequential warning levels. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32, LEDs, and Push Button onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the 4-pin tactile Push Button across the center trench of the breadboard further down (e.g., Rows 25 and 27). This isolates the left and right legs.
  - Top-left pin in **Row 25, Column E**
  - Bottom-left pin in **Row 27, Column E**

- Place the four LEDs side-by-side along the lower section of the breadboard. For each LED, insert the longer positive leg (anode) in one row, and the shorter negative leg (cathode) in the row immediately below it.
  - **LED 1 (Red):** Anode in **Row 10, Column E**, Cathode in **Row 11, Column E**
  - **LED 2 (Blue):** Anode in **Row 13, Column E**, Cathode in **Row 14, Column E**
  - **LED 3 (Yellow):** Anode in **Row 16, Column E**, Cathode in **Row 17, Column E**
  - **LED 4 (White):** Anode in **Row 19, Column E**, Cathode in **Row 20, Column E**

- Connect a 220Ω resistor bridging from each LED's cathode row (**Row 11, Row 14, Row 17, Row 20, Column D**) to the negative (-) ground rail.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the LEDs to the ESP32

- Connect a jumper wire from **Row 10, Column A** (Red LED anode) to **GPIO 12** on the ESP32 board.

- Connect a jumper wire from **Row 13, Column A** (Blue LED anode) to **GPIO 23** on the ESP32 board.

- Connect a jumper wire from **Row 16, Column A** (Yellow LED anode) to **GPIO 5** on the ESP32 board.

- Connect a jumper wire from **Row 19, Column A** (White LED anode) to **GPIO 2** on the ESP32 board.

**Step 2:** Wire the Push Button

- Connect a jumper wire from **Row 25, Column A** (top-left button pin) to a **GND pin** on the ESP32 board (or negative power rail).

- Connect a jumper wire from **Row 27, Column A** (bottom-left button pin) to **GPIO 13** on the ESP32 board.

**Step 3:** Wire the common Ground

- Connect a jumper wire from a **GND pin** on the ESP32 to the Negative (-) power rail on the breadboard.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int ledRed = 12;
const int ledBlue = 23;
const int ledYellow = 5;
const int ledWhite = 2;
const int buttonPin = 13;

int buttonState = 0;
```
*Explanation:* We declare constants linking our physical wiring to code logic: `ledRed` to GPIO 12, `ledBlue` to GPIO 23, `ledYellow` to GPIO 5, `ledWhite` to GPIO 2, and `buttonPin` to GPIO 13. We create `buttonState` to hold the current read status of the button.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(ledRed, OUTPUT);
  pinMode(ledBlue, OUTPUT);
  pinMode(ledYellow, OUTPUT);
  pinMode(ledWhite, OUTPUT);
  
  pinMode(buttonPin, INPUT_PULLUP);
}
```
*Explanation:* The `setup()` function runs once. It configures all four LED pins as `OUTPUT`s. The `buttonPin` is configured as an `INPUT_PULLUP`. This internal resistor keeps the pin state `HIGH` naturally, allowing it to drop to `LOW` when the button connects to ground during a press.

---

### 3. Loop Function

```cpp
void loop() {
  buttonState = digitalRead(buttonPin);
  
  if (buttonState == LOW) {
    digitalWrite(ledRed, HIGH);
    delay(500);
    digitalWrite(ledRed, LOW);
    delay(500);
    
    digitalWrite(ledBlue, HIGH);
    delay(500);
    digitalWrite(ledBlue, LOW);
    delay(500);
    
    digitalWrite(ledYellow, HIGH);
    delay(500);
    digitalWrite(ledYellow, LOW);
    delay(500);
    
    digitalWrite(ledWhite, HIGH);
    delay(500);
    digitalWrite(ledWhite, LOW);
    delay(500);
  }
}
```
*Explanation:* The `loop()` continuously reads the `buttonPin`. The conditional `if (buttonState == LOW)` checks if the button is currently being pressed. If it is, a sequence begins: it turns the Red LED ON for 500ms then OFF for 500ms, followed sequentially by the Blue, Yellow, and White LEDs. This creates a cascading blinking light effect triggered by a single button press.
