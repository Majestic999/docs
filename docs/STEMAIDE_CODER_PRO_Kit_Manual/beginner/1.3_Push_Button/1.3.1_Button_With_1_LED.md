# Project 1.3.1: Push Button with One LED

| **Description** | This project shows how to control an LED using a push button with an ESP32 board. When the button is pressed, the LED turns on, and when the button is released, the LED turns off.|
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used as a simple bedside light switch or a control system where a button is used to turn a light on and off. |

## Mounting the component on the breadboard

**Step 1:** Place the LED on the breadboard. 

- A standard breadboard has a grid of holes divided into rows (numbered) and columns (lettered).

- The longer leg of the LED is the positive pin (anode), while the shorter leg is the negative pin (cathode).

- Insert the longer positive leg into a row (e.g., row 10) and the shorter negative leg into another row (e.g., row 11). Make sure they are not on the same row.

![Push Button Fig.1](../../../assets/1.0/Push_Button/Push_Button_One_LED/circuit_1.png).

_**NB:** Make sure you identify where the positive pin (+) and the negative pin (-) is connected to on the breadboard._

**Step 2:** Place the push button on the breadboard.

- A standard push button has four pins.

Place the button across the middle groove (the trench) of the breadboard so that two pins are on one side and two pins are on the other side.

- For example, you can place it so that one set of pins is in row 20 and the other in row 22.

![Push Button Fig.3](../../../assets/1.0/Push_Button/Push_Button_One_LED/circuit_4.png).

## WIRING THE CIRCUIT

**Step 3:** Connect the LED.

- Connect one end of a **220Ω resistor** to the row with the LED's positive leg (row 10) and the other end to an empty row nearby. 

- Take a **jumper wire** and connect the empty row of the resistor to **GPIO 27** on the ESP32 board.

- Connect another **jumper wire** from the row with the LED's negative leg (row 11) to any **GND** pin on the ESP32 board.

![Push Button Fig.2](../../../assets/1.0/Push_Button/Push_Button_One_LED/circuit_2.png).
![Push Button Fig.3](../../../assets/1.0/Push_Button/Push_Button_One_LED/circuit_3.png).

**Step 4:** Connect the Push Button.

- Take a **jumper wire** and connect one side (e.g., row 20) of the push button to any **GND** pin on the ESP32 board.

- Take another **jumper wire** and connect the opposite side (e.g., row 22) of the push button to **GPIO 2** on the ESP32 board.

![Push Button Fig.3](../../../assets/1.0/Push_Button/Push_Button_One_LED/circuit_5.png).
![Push Button Fig.3](../../../assets/1.0/Push_Button/Push_Button_One_LED/circuit_6.png).

_**NB:** This completes the circuit for the LED and button._

_Make sure to connect the ESP32 board USB blue cable to the ESP32 board_.


## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Define your variables before the `setup()` function.

```cpp
const int PushButton = 2;
const int LedPin = 27;
int buttonState = 0;
```
*Explanation:* `const int PushButton = 2;` assigns GPIO 2 to the push button. `const int LedPin = 27;` assigns GPIO 27 to the LED. `int buttonState = 0;` creates a variable to store whether the button is being pressed or not.

**Step 3:** Configure your pins inside the `void setup()` function.

```cpp
void setup() {
  pinMode(LedPin, OUTPUT);
  pinMode(PushButton, INPUT_PULLUP);
}
```
*Explanation:* `pinMode(LedPin, OUTPUT);` sets the LED pin to output power. `pinMode(PushButton, INPUT_PULLUP);` sets the button pin as an input and activates the ESP32's built-in pull-up resistor. This keeps the pin HIGH (unpressed) until you press it to connect it to ground (LOW).

**Step 4:** Read the button state inside the `void loop()` function.

```cpp
void loop() {
  buttonState = digitalRead(PushButton);
```
*Explanation:* `buttonState = digitalRead(PushButton);` reads the current state of the button (whether it is sending a HIGH or LOW signal) and stores it in the `buttonState` variable.

**Step 5:** Write the logic to control the LED based on the button state, continuing inside the `void loop()` function.

```cpp
  if (buttonState == LOW) {
    digitalWrite(LedPin, HIGH);
  } else {
    digitalWrite(LedPin, LOW);
  }
}
```
*Explanation:* The `if (buttonState == LOW)` line checks if the button is currently pressed. If it is pressed, `digitalWrite(LedPin, HIGH);` turns the LED ON. The `else` block ensures that if the button is NOT pressed, `digitalWrite(LedPin, LOW);` turns the LED OFF.
