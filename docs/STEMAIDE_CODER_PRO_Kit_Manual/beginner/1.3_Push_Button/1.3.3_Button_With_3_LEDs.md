# Project 1.3.3: Buzzer with Three LEDs and Push Button

| **Description** | This project shows how to control three LEDs using a push button with an ESP32 board. When the button is pressed, all three LEDs turn on together. When the button is released, all the LEDs turn off. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used as a decorative lighting system, signal indicator, or simple party light display. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32, LEDs, and Push Button onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the 4-pin tactile Push Button across the center trench of the breadboard further down (e.g., Rows 25 and 27). This isolates the left and right legs.
  - Top-left pin in **Row 25, Column E**
  - Bottom-left pin in **Row 27, Column E**

- Place the three LEDs onto the breadboard:
  - **LED 1:** Insert the longer positive leg (anode) into **Row 10, Column E**, and the shorter negative leg (cathode) into **Row 11, Column E**.
  - **LED 2:** Insert the longer positive leg (anode) into **Row 13, Column E**, and the shorter negative leg (cathode) into **Row 14, Column E**.
  - **LED 3:** Insert the longer positive leg (anode) into **Row 16, Column E**, and the shorter negative leg (cathode) into **Row 17, Column E**.

- Connect a 220Ω resistor from each LED's cathode row (**Row 11, Row 14, Row 17, Column D**) to the negative (-) ground rail.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the LEDs to the ESP32

- Connect a jumper wire from **Row 10, Column A** (LED 1 anode) to **GPIO 26** on the ESP32 board.

- Connect a jumper wire from **Row 13, Column A** (LED 2 anode) to **GPIO 23** on the ESP32 board.

- Connect a jumper wire from **Row 16, Column A** (LED 3 anode) to **GPIO 18** on the ESP32 board.

**Step 2:** Wire the Push Button

- Connect a jumper wire from **Row 25, Column A** (top-left button pin) to a **GND pin** on the ESP32 board (or negative power rail).

- Connect a jumper wire from **Row 27, Column A** (bottom-left button pin) to **GPIO 27** on the ESP32 board.

**Step 3:** Wire the common Ground

- Connect a jumper wire from a **GND pin** on the ESP32 to the Negative (-) power rail on the breadboard.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int ledPin1 = 26;
const int ledPin2 = 23;
const int ledPin3 = 18;
const int buttonPin = 27;

int buttonState = 0;
```
*Explanation:* We declare constants linking our physical wiring to code logic: `ledPin1` to GPIO 26, `ledPin2` to GPIO 23, `ledPin3` to GPIO 18, and `buttonPin` to GPIO 27. We create `buttonState` to hold the current read status of the button.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(ledPin1, OUTPUT);
  pinMode(ledPin2, OUTPUT);
  pinMode(ledPin3, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);
}
```
*Explanation:* The `setup()` function runs once. It configures all three LED pins as `OUTPUT`s. The `buttonPin` is configured as an `INPUT_PULLUP`. This internal resistor keeps the pin state `HIGH` naturally, allowing it to drop to `LOW` when the button connects to ground during a press.

---

### 3. Loop Function

```cpp
void loop() {
  buttonState = digitalRead(buttonPin);

  if (buttonState == LOW) {
    digitalWrite(ledPin1, HIGH);
    digitalWrite(ledPin2, HIGH);
    digitalWrite(ledPin3, HIGH);
  } else {
    digitalWrite(ledPin1, LOW);
    digitalWrite(ledPin2, LOW);
    digitalWrite(ledPin3, LOW);
  }
}
```
*Explanation:* The `loop()` continuously reads the `buttonPin`. The conditional `if (buttonState == LOW)` checks if the button is currently being pressed. If it is, `digitalWrite()` turns all three LEDs `HIGH` (ON). If it is not pressed (`else`), it turns all three LEDs `LOW` (OFF).
