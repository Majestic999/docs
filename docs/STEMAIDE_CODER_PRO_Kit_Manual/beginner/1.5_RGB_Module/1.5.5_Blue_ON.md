# Project 1.5.5: R -G-Blue

| **Description** | This project teaches how to connect and program an RGB LED so that only the blue light turns on/off using an ESP32 board.|
|------------------|----------------------------------------------------------------|
| **Use case**     | In real-life engineering systems, the blue LED on an RGB indicator is often used to show communication or connectivity status, such as when a device has successfully connected to Bluetooth, Wi-Fi, or a control network. For example, in smart home devices or industrial controllers, a blue light can indicate that the system is paired, linked to a server, or actively exchanging data without errors. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and RGB module onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Locate the 4 pins on the RGB module (typically R, GND, G, B).

Insert the RGB module into the breadboard so each pin is in its own row (e.g., Rows 20 to 23, Column A):
  - `R` (Red) pin in **Row 20, Column A**
  - `GND` (-) pin in **Row 21, Column A**
  - `G` (Green) pin in **Row 22, Column A**
  - `B` (Blue) pin in **Row 23, Column A**

![LED fixed on breadboard](../../../assets/coder_pro/beginner/RGB_Module/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the RGB module to the ESP32 board:

- Connect a Blue jumper wire from **Row 23, Column B** (the B pin of the RGB module) to **GPIO 21** on the ESP32 board.

- Connect a White (or Black) jumper wire from **Row 21, Column B** (the GND pin of the RGB module) to a **GND pin** on the ESP32 board.

![LED fixed on breadboard](../../../assets/coder_pro/beginner/RGB_Module/circuit_4.png)

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int blue = 21;
```
*Explanation:* We declare a constant integer variable named `blue` and assign it the value `21`. This tells the ESP32 that the blue pin of our RGB module is connected to GPIO 21.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(blue, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures the `blue` pin as an `OUTPUT` so the ESP32 can send electrical signals (voltage) out of this pin to power the LED.

---

### 3. Loop Function

```cpp
void loop() {
  digitalWrite(blue, HIGH);
}
```
*Explanation:* The `loop()` continuously runs. `digitalWrite(blue, HIGH);` sends voltage to the blue pin, keeping the light ON constantly.

**NB:** To turn off the blue light, replace `HIGH` with `LOW` in the code. This will stop sending a signal to the LED, turning it off.
