# Project 1.5.3: Turning ON/OFF Green LED On RGB

| **Description** | This project teaches how to connect and program an RGB LED so that only the green light turns on/off using an ESP32 board.|
|------------------|----------------------------------------------------------------|
| **Use case**     | The green light on the RGB LED can be used as an indicator for safety, permission, or normal operation, such as showing that a system is active or access is allowed. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and RGB module onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Locate the 4 pins on the RGB module (typically R, GND, G, B).

Insert the RGB module into the breadboard so each pin is in its own row (e.g., Rows 20 to 23, Column A):
  - `R` (Red) pin in **Row 20, Column A**
  - `GND` (-) pin in **Row 21, Column A**
  - `G` (Green) pin in **Row 22, Column A**
  - `B` (Blue) pin in **Row 23, Column A**

![LED fixed on breadboard](../../../assets/coder_pro/beginner/RGB_Module/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the RGB module to the ESP32 board:

- Connect a Green jumper wire from **Row 22, Column B** (the G pin of the RGB module) to **GPIO 19** on the ESP32 board.

- Connect a White (or Black) jumper wire from **Row 21, Column B** (the GND pin of the RGB module) to a **GND pin** on the ESP32 board.

![LED fixed on breadboard](../../../assets/coder_pro/beginner/RGB_Module/circuit_3.png)

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int green = 19;
```
*Explanation:* We declare a constant integer variable named `green` and assign it the value `19`. This tells the ESP32 that the green pin of our RGB module is connected to GPIO 19.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(green, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures the `green` pin as an `OUTPUT` so the ESP32 can send electrical signals (voltage) out of this pin to power the LED.

---

### 3. Loop Function

```cpp
void loop() {
  digitalWrite(green, HIGH);
}
```
*Explanation:* The `loop()` continuously runs. `digitalWrite(green, HIGH);` sends voltage to the green pin, keeping the light ON constantly.

**NB:** To turn off the green light, replace `HIGH` with `LOW` in the code. This will stop sending a signal to the LED, turning it off.
