# Project 1.5.7: RAINBOW COLORS ON RGB

| **Description** | This programming section demonstrates how to control an RGB LED using ESP32 board to produce rainbow colors. By combining different values of red, green, and blue in sequence with short delays, the LED smoothly transitions through multiple colors such as red, orange, yellow, green, blue, indigo, and violet. This helps in understanding how color mixing, timing, and code functions work together to create dynamic visual effects. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This can be used in real life for decorative lighting systems, such as LED mood lights, stage lighting, or smart room lighting, where smooth rainbow color transitions are used to create visual effects, set ambiance, or attract attention in displays and events. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and RGB module onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Locate the 4 pins on the RGB module (typically R, GND, G, B).

Insert the RGB module into the breadboard so each pin is in its own row (e.g., Rows 20 to 23, Column A):
  - `R` (Red) pin in **Row 20, Column A**
  - `GND` (-) pin in **Row 21, Column A**
  - `G` (Green) pin in **Row 22, Column A**
  - `B` (Blue) pin in **Row 23, Column A**

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the RGB module to the ESP32 board:

- Connect a jumper wire from **Row 20, Column B** (the R pin of the RGB module) to **GPIO 22** on the ESP32 board.

- Connect a jumper wire from **Row 22, Column B** (the G pin of the RGB module) to **GPIO 23** on the ESP32 board.

- Connect a jumper wire from **Row 23, Column B** (the B pin of the RGB module) to **GPIO 33** on the ESP32 board.

- Connect a jumper wire from **Row 21, Column B** (the GND pin of the RGB module) to a **GND pin** on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int redPin = 22;
const int greenPin = 23;
const int bluePin = 33;
```
*Explanation:* We declare variables for the three pins connected to our RGB module: Red to GPIO 22, Green to GPIO 23, and Blue to GPIO 33.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures all three of our color pins as `OUTPUT`s so the ESP32 can send electrical signals (PWM signals) to each color channel independently.

---

### 3. Custom Function (Helper)

Write this custom function *outside* of `setup()` and `loop()` (e.g., below `setup()`).

```cpp
void SetColor(int r, int g, int b) {
  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}
```
*Explanation:* This creates a reusable helper function called `SetColor()`. It takes three arguments representing the intensity of Red, Green, and Blue (from 0 to 255). It uses `analogWrite()` to mix the colors together dynamically.

---

### 4. Loop Function

```cpp
void loop() {
  SetColor(255, 0, 0);     // Red
  delay(1000);
  
  SetColor(255, 127, 0);   // Orange
  delay(1000);
  
  SetColor(255, 255, 0);   // Yellow
  delay(1000);
  
  SetColor(0, 255, 0);     // Green
  delay(1000);
  
  SetColor(0, 0, 255);     // Blue
  delay(1000);
  
  SetColor(75, 0, 130);    // Indigo
  delay(1000);
  
  SetColor(148, 0, 211);   // Violet
  delay(1000);
}
```
*Explanation:* The `loop()` continuously runs. We call our custom `SetColor()` function to mix varying amounts of red, green, and blue to create the seven colors of the rainbow. Between each color, we use `delay(1000)` to hold that color for 1 second before moving to the next.
