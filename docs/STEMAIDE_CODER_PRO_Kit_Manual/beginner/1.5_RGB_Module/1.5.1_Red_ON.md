# Project 1.5.1: RED-G-B

| **Description** | This project teaches how to connect and program an RGB LED so that only the red light turns on using an ESP32 board. |
|------------------|----------------------------------------------------------------|

## Mounting the component on the breadboard

**Step 1:** Mount the ESP32 and RGB module onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F. Press down gently until seated.

- Locate the 4 pins on the RGB module (typically R, GND, G, B).

Insert the RGB module into the breadboard so each pin is in its own row (e.g., Rows 20 to 23, Column A):
  - `R` (Red) pin in **Row 20, Column A**
  - `GND` (-) pin in **Row 21, Column A**
  - `G` (Green) pin in **Row 22, Column A**
  - `B` (Blue) pin in **Row 23, Column A**

![LED fixed on breadboard](../../assets/coder_pro/beginner/RGB_Module/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 2:** Connect the RGB module to the ESP32 board:

- Connect a Red jumper wire from **Row 20, Column B** (the R pin of the RGB module) to **GPIO 18** on the ESP32 board.

- Connect a White (or Black) jumper wire from **Row 21, Column B** (the GND pin of the RGB module) to a **GND pin** on the ESP32 board.

![LED fixed on breadboard](../../assets/coder_pro/beginner/RGB_Module/circuit_2.png)

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int red = 18;
```
*Explanation:* Here we declare a constant integer variable named `red` and assign it the value `18`. This tells the ESP32 that the red pin of our RGB module is connected to GPIO pin 18.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(red, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once when the board powers up. The `pinMode(red, OUTPUT);` line configures GPIO 18 (the `red` pin) to behave as an output, meaning the ESP32 can send electrical signals (voltage) out of this pin to power the LED.

---

### 3. Loop Function

```cpp
void loop() {
  digitalWrite(red, HIGH);
}
```
*Explanation:* The `loop()` function runs continuously. `digitalWrite(red, HIGH);` sends a HIGH signal (3.3V) to the red pin, which turns the red light ON. Since there is no `LOW` command or delay, the light will simply remain on indefinitely. 
*(Note: If you wanted to turn the light off, you would use `digitalWrite(red, LOW);`)*
