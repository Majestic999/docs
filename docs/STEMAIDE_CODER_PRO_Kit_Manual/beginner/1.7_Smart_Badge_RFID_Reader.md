## Mounting the components on the breadboard

Follow these steps to place components onto the breadboard accurately without causing short circuits:

1. **Mount the ESP32 Board:**
   - Straddle the central divider channel of the breadboard with the ESP32 board.
   - Insert the left pin header into **Column D (Rows 1 to 15)** and the right pin header into **Column G (Rows 1 to 15)**.
   - Press down gently and evenly until the pins are firmly seated into the breadboard sockets.

2. **Mount the I2C LCD Display Adapter:**
   - Place the 4-pin header of the LCD I2C module into **Column J, Rows 20 to 23**.
   - Ensure pin 1 (GND) is at Row 20, pin 2 (VCC) at Row 21, pin 3 (SDA) at Row 22, and pin 4 (SCL) at Row 23.
   - Ensure no two pins occupy the same breadboard row to avoid short circuits.

3. **Mount the MFRC522 RFID Module:**
   - Place the 8-pin straight header of the MFRC522 module into **Column A, Rows 25 to 32**.
   - Ensure the pins occupy separate sequential rows: Row 25 (SDA), Row 26 (SCK), Row 27 (MOSI), Row 28 (MISO), Row 29 (IRQ - unused), Row 30 (GND), Row 31 (RST), Row 32 (3.3V).

---

## Wiring Instructions

Connect the jumper wires between the breadboard rows and the ESP32 board pins according to the pin assignment details below:

1. **Power Rail Setup:**
   - Connect a jumper wire from the **ESP32 5V Pin** (Row 1, Column B) to the **Positive (+) Power Rail** on the breadboard.
   - Connect a jumper wire from the **ESP32 GND Pin** (Row 2, Column B) to the **Negative (-) Ground Rail** on the breadboard.

2. **I2C LCD Module Wiring:**
   - Connect a jumper wire from **Row 20, Column I** (LCD GND) to the **Negative (-) Ground Rail**.
   - Connect a jumper wire from **Row 21, Column I** (LCD VCC) to the **Positive (+) Power Rail**.
   - Connect a jumper wire from **Row 22, Column I** (LCD SDA) to **ESP32 GPIO 21** (Row 3, Column J).
   - Connect a jumper wire from **Row 23, Column I** (LCD SCL) to **ESP32 GPIO 22** (Row 4, Column J).

3. **MFRC522 RFID Module Wiring:**
   - Connect a jumper wire from **Row 32, Column B** (RFID 3.3V) directly to the **ESP32 3.3V Pin** (Row 1, Column I). *Note: Do not connect the RFID reader to 5V, as this will damage the module.*
   - Connect a jumper wire from **Row 31, Column B** (RFID RST) to **ESP32 GPIO 4** (Row 6, Column B).
   - Connect a jumper wire from **Row 30, Column B** (RFID GND) to the **Negative (-) Ground Rail**.
   - Connect a jumper wire from **Row 28, Column B** (RFID MISO) to **ESP32 GPIO 19** (Row 7, Column J).
   - Connect a jumper wire from **Row 27, Column B** (RFID MOSI) to **ESP32 GPIO 23** (Row 8, Column J).
   - Connect a jumper wire from **Row 26, Column B** (RFID SCK) to **ESP32 GPIO 18** (Row 9, Column J).
   - Connect a jumper wire from **Row 25, Column B** (RFID SDA/SS) to **ESP32 GPIO 33** (Row 10, Column B).

4. **Power Source:**
   - Plug the Micro USB cable into the ESP32 micro-USB port and connect the other end to your computer.

## PROGRAMMING

### Block 1: Library Declarations and Module Configurations

```cpp
#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

#define SS_PIN 33
#define RST_PIN 4

MFRC522 rfid(SS_PIN, RST_PIN);
LiquidCrystal_I2C lcd(0x27, 16, 2);
```

*Explanation:* 
This block imports the required libraries for SPI communication (`SPI.h`), the RFID MFRC522 module (`MFRC522.h`), I2C communication (`Wire.h`), and the I2C LCD screen (`LiquidCrystal_I2C.h`). It defines the Slave Select (`SS_PIN`) on GPIO 33 and the Reset pin (`RST_PIN`) on GPIO 4 for the RFID module. Finally, it creates instances for the RFID reader and the LCD display at I2C address `0x27` with 16 columns and 2 rows.

---

### Block 2: System Setup Function

```cpp
void setup() {
  Serial.begin(9600);

  SPI.begin();
  rfid.PCD_Init();

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0, 0);
  lcd.print("Scan Card");
}
```

*Explanation:* 
The `setup()` function runs once when the board powers up. It opens Serial communication at 9600 baud for debugging purposes. It then initializes the SPI bus and calls `rfid.PCD_Init()` to prepare the MFRC522 reader. Next, it initializes the I2C LCD, turns on its backlight, sets the cursor to column 0, row 0, and displays the default prompt message `"Scan Card"`.

---

### Block 3: Main Program Control Loop

```cpp
void loop() {
  if (!rfid.PICC_IsNewCardPresent())
    return;

  if (!rfid.PICC_ReadCardSerial())
    return;

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Card Detected");

  Serial.print("UID: ");

  String uid = "";

  for (byte i = 0; i < rfid.uid.size; i++) {
    uid += String(rfid.uid.uidByte[i], HEX);
    Serial.print(rfid.uid.uidByte[i], HEX);
    Serial.print(" ");
  }

  Serial.println();

  lcd.setCursor(0, 1);
  lcd.print(uid);

  delay(3000);

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Scan Card");

  rfid.PICC_HaltA();
}
```

*Explanation:* 
The `loop()` function runs repeatedly. It checks if an RFID tag is near the reader using `PICC_IsNewCardPresent()` and ensures its data can be read via `PICC_ReadCardSerial()`. If no card is detected, it exits early. When a card is read, it updates the LCD to show `"Card Detected"`. A `for` loop extracts each byte of the card's Unique Identifier (UID), converts it into a hexadecimal string, and prints it to both the Serial Monitor and the second row of the LCD screen. After a 3-second delay, the screen clears, resets back to the `"Scan Card"` message, and halts further reading on the current card until it is removed and re-scanned.
