# 1.1. LED Morse Code Messenger

| **Description** | In this project, learners will use an LED to transmit short messages in Morse code. Morse code represents letters and numbers using combinations of short and long flashes. This activity introduces learners to controlling outputs using timing, one of the most important concepts in programming. Instead of simply blinking an LED, learners will use code to create meaningful communication patterns. |
|------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as maritime emergencies, aviation, military communication, amateur radio, and emergency signaling. This project demonstrates how simple outputs can be used to transmit meaningful information through programming. |

## Building the circuit

> **Tip:** Use the [ESP32 Pin Mapping](../../assets/esp32_pin_mapping.png) image to locate the correct GPIO pins on your ESP32 board.

Things Needed:

- ESP32 board = 1

- Micro USB cable = 1

- Bread Board = 1

- Jumper Wires

- 220Ω resistor

- LED

## Mounting the component on the breadboard

**Step 1:** Insert the ESP32 board onto the breadboard, straddling the center divider canal.

**Step 2:** Place the LED onto the breadboard.

Insert the longer positive leg (anode) into row 15, column e.

Insert the shorter negative leg (cathode) into row 16, column e.

Ensure that both legs are inserted into different rows to prevent a short circuit.

**Step 3:** Place the 220Ω resistor on the breadboard.

Insert one leg into row 16, column d (connecting it directly to the LED's shorter negative leg on the same row).

Insert the second leg of the resistor into row 20, column d.

![Components on breadboard](../../assets/coder_pro/beginner/LED_Morse_Code_Messenger/circuit_1.png)

## WIRING THE CIRCUIT

**Step 1:** Connect a jumper wire from breadboard row 15, column a (connected to the long positive leg of the LED) to **GPIO 22** on the ESP32 board.

![Wiring diagram](../../assets/coder_pro/beginner/LED_Morse_Code_Messenger/circuit_2.png)

**Step 2:** Connect a jumper wire from breadboard row 20, column a (connected to the free end of the 220Ω resistor) to a **GND** pin on the ESP32 board.

![Wiring diagram](../../assets/coder_pro/beginner/LED_Morse_Code_Messenger/circuit_3.png)

_Make sure to connect the Micro USB cable to the ESP32 board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Enter the code logic line by line as outlined below:

### Variable Declarations

```cpp
int ledPin = 22;
```

*Explanation:* This line defines an integer variable named `ledPin` and sets it to pin `22`. This matches the physical GPIO pin on the ESP32 connected to the LED's positive terminal.

---

### Setup Function

```cpp
void setup() {
  pinMode(ledPin, OUTPUT);
}
```

*Explanation:* The `setup()` function executes once when the microcontroller powers up or resets. `pinMode(ledPin, OUTPUT);` configures GPIO pin 22 as a digital output pin so it can send voltage to power the LED.

---

### Morse Code Helper Functions

```cpp
void dot() {
  digitalWrite(ledPin, HIGH);
  delay(250);
  digitalWrite(ledPin, LOW);
  delay(250);
}

void dash() {
  digitalWrite(ledPin, HIGH);
  delay(750);
  digitalWrite(ledPin, LOW);
  delay(250);
}
```

*Explanation:* These custom helper functions define the signals for dots and dashes in Morse code. The `dot()` function turns the LED on (`HIGH`) for 250 milliseconds, turns it off (`LOW`), and pauses for 250 milliseconds. The `dash()` function turns the LED on for 750 milliseconds (three times longer than a dot), turns it off, and pauses for 250 milliseconds.

---

### Main Loop Function

```cpp
void loop() {
  // Letter S: three dots
  dot();
  dot();
  dot();
  delay(500);

  // Letter O: three dashes
  dash();
  dash();
  dash();
  delay(500);

  // Letter S: three dots
  dot();
  dot();
  dot();
  delay(2000);
}
```

*Explanation:* The `loop()` function runs continuously in a loop. It transmits the emergency distress signal "SOS" (`... --- ...`). It triggers `dot()` three times for 'S', delays 500ms between letters, triggers `dash()` three times for 'O', delays 500ms, triggers `dot()` three times for 'S', and delays 2000ms (2 seconds) before repeating the message sequence.
