# 1.2. Adjustable LED Dimmer

| **Description** | In this project, learners will use a potentiometer (variable resistor) to control the brightness of an LED. Unlike the previous project where the LED was simply turned ON or OFF, this activity introduces the concept of gradual control. By turning the potentiometer knob, the brightness of the LED changes smoothly. This project provides an excellent introduction to analog inputs and Pulse Width Modulation (PWM), which is widely used in electronics to control brightness, motor speed, and other variable outputs. |
| --- | --- |
| **Use case**     | This project is connected to real-world uses such as light dimmer switches, volume knobs, motor speed controllers, temperature regulators, and industrial process controls. It demonstrates how physical input devices allow users to interact with electronic systems in intuitive ways. |

## Mounting the component on the breadboard

**Step 1:** Mount the LED, resistor, and potentiometer onto the breadboard:

1. **LED Placement:**
   - Insert the longer positive leg (anode) of the LED into **Row 10, Column e**.
   - Insert the shorter negative leg (cathode) of the LED into **Row 11, Column e**.

Ensure both legs are in different rows to avoid creating a short circuit.

2. **Resistor Placement:**
   - Insert one end of the 220Ω resistor into **Row 11, Column d** (in the same row as the LED cathode).
   - Insert the other end of the 220Ω resistor into **Row 15, Column d**.

3. **Potentiometer Placement:**
   - Place the three pins of the potentiometer into three separate adjacent rows on the breadboard:
     - Left pin (Terminal 1) into **Row 20, Column e**.
     - Middle pin (Wiper) into **Row 21, Column e**.
     - Right pin (Terminal 2) into **Row 22, Column e**.

![Components on breadboard](../../assets/coder_pro/beginner/Adjustable_LED_Dimmer/circuit_1.png)

## WIRING THE CIRCUIT

**Step 2:** Wire the potentiometer to the ESP32 board using jumper wires:

- Connect a jumper wire from **Row 20** (Left pin of the potentiometer) to the **5V pin** on the ESP32 board.

- Connect a jumper wire from **Row 21** (Middle pin/wiper of the potentiometer) to **GPIO 36** (VP) on the ESP32 board.

- Connect a jumper wire from **Row 22** (Right pin of the potentiometer) to a **GND pin** on the ESP32 board.

![Wiring diagram](../../assets/coder_pro/beginner/Adjustable_LED_Dimmer/circuit_2.png)

**Step 3:** Wire the LED circuit to the ESP32 board using jumper wires:

- Connect a jumper wire from **Row 10** (Anode/longer leg of the LED) to **GPIO 23** on the ESP32 board.

- Connect a jumper wire from **Row 15** (Unconnected leg of the 220Ω resistor) to a **GND pin** on the ESP32 board.

![Wiring diagram](../../assets/coder_pro/beginner/Adjustable_LED_Dimmer/circuit_3.png)

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
int potPin = 36;
int ledPin = 23;
int sensorValue = 0;
int brightness = 0;
```

*Explanation:* Here, we define integer variables to store pin assignments and operational values. `potPin` assigns the potentiometer signal pin to GPIO 36 (an analog input pin), while `ledPin` assigns the LED signal to GPIO 23. `sensorValue` is initialized to store raw analog readings from the potentiometer, and `brightness` will hold the mapped output value for the LED brightness.

---

### 2. Setup Function

```cpp
void setup() {
  // No special configuration needed for analogRead and analogWrite on ESP32
}
```

*Explanation:* The `setup()` function runs once when the board powers up. ESP32 automatically configures GPIO 36 for analog input upon calling `analogRead()`, and dynamically configures PWM output on `analogWrite()`, so no explicit pin modes are required inside setup for basic operation.

---

### 3. Loop Function

```cpp
void loop() {
  sensorValue = analogRead(potPin);
  brightness = map(sensorValue, 0, 4095, 0, 255);
  analogWrite(ledPin, brightness);
  delay(10);
}
```

*Explanation:* The `loop()` function executes continuously:

1. `analogRead(potPin)` reads the voltage level from the potentiometer, returning a raw 12-bit ADC value between `0` and `4095`.

2. `map(sensorValue, 0, 4095, 0, 255)` converts the 12-bit analog input value (`0–4095`) down to an 8-bit PWM range (`0–255`) suitable for controlling LED brightness.

3. `analogWrite(ledPin, brightness)` outputs a Pulse Width Modulation (PWM) signal on GPIO 23 corresponding to the calculated brightness value.

4. `delay(10)` introduces a short 10-millisecond pause to ensure smooth reading transitions and stability during operation.

## CONCLUSION

When the potentiometer is rotated, the LED responds as follows: when the knob is turned fully left, the LED is OFF; when it is turned halfway, the LED glows at medium brightness; and when it is turned fully right, the LED reaches maximum brightness. The LED brightness should change smoothly as the knob is turned.
