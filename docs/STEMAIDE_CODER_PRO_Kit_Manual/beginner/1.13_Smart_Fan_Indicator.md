# 1.13. Smart Fan Indicator

| **Description** | In this project, learners will build an automatic cooling system that switches on a DC fan whenever the temperature exceeds a predefined limit. The system continuously monitors temperature using a temperature sensor and activates a motor-driven fan when cooling is required. This project introduces environmental automation and demonstrates how sensor data can directly control mechanical devices. |
|------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as: cooling systems in computers, air conditioners, incubators, and industrial equipment. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Temperature Sensor onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Press down gently until the pins are firmly seated.

- Locate the 3 pins on the Temperature Sensor (VCC, OUT, GND).

Insert the sensor into the breadboard in lower rows (e.g., Rows 20 to 22, Column A) ensuring each pin occupies its own separate row:
  - `VCC` pin in **Row 20, Column A**
  - `OUT` pin in **Row 21, Column A**
  - `GND` pin in **Row 22, Column A**

**Step 2:** Prepare the DC Motor:

- Attach the Fan Blade securely to the shaft of the DC Motor.

- Ensure the two wire leads from the DC Motor are ready to be plugged into the breadboard or directly connected using jumper wires.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1: Wire the Temperature Sensor**

- Connect a jumper wire from **Row 20, Column B** (Temperature Sensor VCC) to the **3.3V pin** on the ESP32 board.

- Connect a jumper wire from **Row 22, Column B** (Temperature Sensor GND) to a **GND pin** on the ESP32 board.

- Connect a jumper wire from **Row 21, Column B** (Temperature Sensor OUT) to **GPIO 36** on the ESP32 board.

![Components on breadboard](../../assets/coder_pro/beginner/Smart_Fan_Indicator/circuit_2.png)
![Components on breadboard](../../assets/coder_pro/beginner/Smart_Fan_Indicator/circuit_3.png)

**Step 2: Wire the DC Motor**

- Connect the **Positive (Red)** wire lead of the DC motor to **GPIO 23** on the ESP32 board.

- Connect the **Negative (Black)** wire lead of the DC motor to a **GND pin** on the ESP32 board.

- *(Note: For a simple low-power DC motor this direct connection is for demonstration; high-power motors require a transistor/relay).*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
int tempPin = 36;
int motorPin = 23;
float threshold = 30.0;
```
*Explanation:* We declare integer variables to assign the temperature sensor's signal to GPIO 36 (`tempPin`) and the motor control to GPIO 23 (`motorPin`). We also set a `threshold` of 30.0 degrees Celsius, which determines when the fan should turn on.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(motorPin, OUTPUT);
  Serial.begin(9600);
}
```
*Explanation:* The `setup()` function runs once. It configures the `motorPin` as an `OUTPUT` so it can send voltage to turn the fan on. It also starts the serial monitor at a baud rate of 9600 to allow us to view the live temperature readings on our computer.

---

### 3. Loop Function

```cpp
void loop() {
  int sensorValue = analogRead(tempPin);
  float voltage = sensorValue * (3.3 / 4095.0);
  float temperature = voltage * 100.0;

  Serial.print("Temperature: ");
  Serial.println(temperature);

  if (temperature >= threshold) {
    digitalWrite(motorPin, HIGH);
  } else {
    digitalWrite(motorPin, LOW);
  }

  delay(500);
}
```
*Explanation:* In the `loop()`, `analogRead()` reads the raw ADC value from the sensor (0-4095 on ESP32). We convert this raw value into `voltage` (assuming a 3.3V reference). For an LM35 sensor, every 10mV equals 1°C, so multiplying the voltage by 100 gives the `temperature`. 
If the calculated `temperature` is greater than or equal to our `threshold` (30°C), we send a `HIGH` signal to `motorPin` to turn the fan ON. Otherwise, we send a `LOW` signal to turn it OFF. A `delay(500)` pauses the loop for half a second before the next reading.

## CONCLUSION

When the temperature is below 30°C, the fan remains OFF. As the temperature rises above 30°C (e.g. by holding the sensor with your fingers), the motor starts rotating to cool the environment. Temperature readings update continuously in the Serial Monitor.
