# Project 1.13.1: Push Button RGB Selector

| **Description** | This project uses a push button to cycle through different RGB LED colours. Each time the button is pressed, the RGB LED changes to the next preset colour in the sequence. After the last colour is displayed, the cycle starts again from the first colour. |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use case**    | Colour selection systems, mood lighting, user interface indicators, RGB LED control demonstrations. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32, RGB Module, and Push Button onto the breadboard:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the 4-pin tactile Push Button across the center trench of the breadboard further down (e.g., Rows 25 and 27). This ensures the left pins are isolated from the right pins.
  - Top-left pin in **Row 25, Column E**
  - Bottom-left pin in **Row 27, Column E**

- Locate the 4 pins on the RGB module (typically R, GND, G, B).

Insert the RGB module into the breadboard so each pin is in its own row (e.g., Rows 30 to 33, Column A):
  - `R` (Red) pin in **Row 30, Column A**
  - `GND` (-) pin in **Row 31, Column A**
  - `G` (Green) pin in **Row 32, Column A**
  - `B` (Blue) pin in **Row 33, Column A**

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1: Wire the Push Button**

- Connect a jumper wire from **Row 25, Column A** (one side of the button) to a **GND pin** on the ESP32 board.

- Connect a jumper wire from **Row 27, Column A** (the other side of the button) to **GPIO 2** on the ESP32 board.

**Step 2: Wire the RGB Module**

- Connect a jumper wire from **Row 31, Column B** (GND pin of RGB) to a **GND pin** on the ESP32 board (or use the breadboard's negative power rail if established).

- Connect a jumper wire from **Row 30, Column B** (Red pin) to **GPIO 23** on the ESP32 board.

- Connect a jumper wire from **Row 32, Column B** (Green pin) to **GPIO 33** on the ESP32 board.

- Connect a jumper wire from **Row 33, Column B** (Blue pin) to **GPIO 25** on the ESP32 board.

## PROGRAMMING

### 1. Variable Declarations

```cpp
int buttonPin = 2;
int redPin = 23;
int greenPin = 33;
int bluePin = 25;

int buttonState = 0;
int lastButtonState = HIGH;
int colorMode = 0;
```
*Explanation:* We declare integer variables for the hardware pins: `buttonPin` on GPIO 2, and the RGB pins on GPIOs 23, 33, and 25. We also create tracking variables: `buttonState` and `lastButtonState` to monitor the physical pressing of the button, and `colorMode` to keep track of which color is currently supposed to be displayed.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures the RGB pins as `OUTPUT`s so they can emit voltage to the LED. Crucially, it configures `buttonPin` as an `INPUT_PULLUP`. This internal resistor keeps the pin state `HIGH` normally, and the state will drop to `LOW` when the button is physically pressed and connects to ground.

---

### 3. Loop Function

```cpp
void loop() {
  buttonState = digitalRead(buttonPin);

  if (buttonState == LOW && lastButtonState == HIGH) {
    colorMode++;
    if (colorMode > 6) {
      colorMode = 0;
    }
    delay(200); // Debounce delay
  }
  lastButtonState = buttonState;

  if (colorMode == 0) {
    // Red
    digitalWrite(redPin, HIGH);
    digitalWrite(greenPin, LOW);
    digitalWrite(bluePin, LOW);
  } else if (colorMode == 1) {
    // Green
    digitalWrite(redPin, LOW);
    digitalWrite(greenPin, HIGH);
    digitalWrite(bluePin, LOW);
  } else if (colorMode == 2) {
    // Blue
    digitalWrite(redPin, LOW);
    digitalWrite(greenPin, LOW);
    digitalWrite(bluePin, HIGH);
  } else if (colorMode == 3) {
    // Yellow (Red + Green)
    digitalWrite(redPin, HIGH);
    digitalWrite(greenPin, HIGH);
    digitalWrite(bluePin, LOW);
  } else if (colorMode == 4) {
    // Magenta (Red + Blue)
    digitalWrite(redPin, HIGH);
    digitalWrite(greenPin, LOW);
    digitalWrite(bluePin, HIGH);
  } else if (colorMode == 5) {
    // Cyan (Green + Blue)
    digitalWrite(redPin, LOW);
    digitalWrite(greenPin, HIGH);
    digitalWrite(bluePin, HIGH);
  } else if (colorMode == 6) {
    // White (Red + Green + Blue)
    digitalWrite(redPin, HIGH);
    digitalWrite(greenPin, HIGH);
    digitalWrite(bluePin, HIGH);
  }
}
```
*Explanation:* The `loop()` continuously reads the `buttonPin`. By comparing `buttonState == LOW` (currently pressed) with `lastButtonState == HIGH` (was previously unpressed), we ensure the code registers exactly one press event rather than rapidly scrolling through colors. When a press is detected, we increment `colorMode` by 1. If it goes past 6, we reset it to 0. A small 200ms `delay` prevents physical switch bouncing. Finally, a series of `if/else` statements check the `colorMode` number and turn the appropriate combination of Red, Green, and Blue pins `HIGH` or `LOW` to mix the correct light color.

## OBSERVATION

When the button is pressed, the RGB LED changes colour every time the button is pressed. It cycles through Red, Green, Blue, Yellow, Magenta, Cyan, and White, before starting the cycle over again.

## CONCLUSION

This project demonstrates digital input handling, button debouncing, conditional logic, RGB LED control, and colour cycling techniques. It provides a practical introduction to user-controlled interfaces and colour selection systems commonly used in lighting projects, indicators, and interactive electronic devices.
