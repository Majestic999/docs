# Project 1.13.2: Serial Button Terminal

| **Description** | This project shows how to read the state of a push button using the ESP32 board internal pull-up resistor and displays "PRESSED" or "RELEASED" on the Serial Monitor. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used in control panels and user input interfaces where button presses need to be detected and logged. |

## Mounting the component on the breadboard

**Step 1:** Mount the ESP32 board onto the breadboard so that it straddles the central divide (the ridge between column rows e and f).

Place pin 1 at row 1.

Ensure the board is firmly pressed down across rows 1 through 15.

**Step 2:** Insert the push button onto the breadboard across the central divide (rows 20 and 22).

Insert the top two pins into Row 20 (Column e and Column f) and the bottom two pins into Row 22 (Column e and Column f).

Ensure the legs span across the center gap so opposite terminal pairs are on separate rows.

## WIRING THE CIRCUIT

**Step 1:** Connect a red jumper wire from row 20, column j (connected to one terminal of the push button) to the ESP32 pin labeled **GPIO 2** (located on row 3, column a).

## PROGRAMMING

### 1. Variable Declarations

```cpp
const int buttonPin = 2;
int buttonState = 0;
```

*Explanation:* Sets `buttonPin` as a constant integer pointing to GPIO pin 2 where the push button is wired. `buttonState` is initialized to hold the current numerical state (HIGH or LOW) read from the pin.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(115200);
  pinMode(buttonPin, INPUT_PULLUP);
}
```

*Explanation:* Initializes serial communication at a baud rate of 115200 to enable communication with the Serial Monitor. The `pinMode()` function configures `buttonPin` as an `INPUT_PULLUP`, which activates the ESP32's internal resistor to keep the pin default HIGH until grounded by a button press.

---

### 3. Loop Function

```cpp
void loop() {
  buttonState = digitalRead(buttonPin);

  if (buttonState == LOW) {
    Serial.println("PRESSED");
  } else {
    Serial.println("RELEASED");
  }
  
  delay(100);
}
```

*Explanation:* The `digitalRead()` function continuously checks the state of pin 2. When the push button is pressed, it shorts the pin to GND, driving `buttonState` to `LOW` and printing "PRESSED" to the Serial Monitor. When released, the internal pull-up resistor returns the state to `HIGH`, printing "RELEASED". A small delay stabilizes the loop execution.
