## Mounting the Components on the Breadboard

1. **Mounting the ESP32 Board:**
   - Place the ESP32 microcontroller straddling the center divider (the trench) of the breadboard.
   - Insert the left set of pins into **Column b, Rows 1 to 15** and the right set of pins into **Column i, Rows 1 to 15**. Press down firmly until seated.

2. **Mounting the PIR Motion Sensor:**
   - Place the PIR motion sensor onto an open space on the breadboard.
   - Insert the **VCC pin** into **Row 20, Column e**.
   - Insert the **OUTPUT pin** into **Row 21, Column e**.
   - Insert the **GND pin** into **Row 22, Column e**.
   - Ensure each pin sits in a separate row to avoid creating a short circuit.

3. **Mounting the Buzzer:**
   - Locate the positive (+) longer leg and the negative (-) shorter leg of the buzzer.
   - Insert the longer positive leg into **Row 25, Column e**.
   - Insert the shorter negative leg into **Row 26, Column e**.
   - *Note:* Ensure both legs are inserted into completely separate rows on the breadboard to prevent shorting the buzzer.

---

## Wiring Instructions

Follow these step-by-step wiring connections using jumper wires:

1. **Powering the Sensor (5V):**
   - Connect a jumper wire from the **5V pin** of the ESP32 (located at Row 1, Column a) to the positive power rail (+) of the breadboard.
   - Connect another jumper wire from the positive power rail (+) to **Row 20, Column a** (PIR Sensor VCC).

2. **Ground Connections (GND):**
   - Connect a jumper wire from a **GND pin** on the ESP32 (e.g., Row 14, Column a) to the negative ground rail (-) of the breadboard.
   - Connect a jumper wire from the negative ground rail (-) to **Row 22, Column a** (PIR Sensor GND).
   - Connect another jumper wire from the negative ground rail (-) to **Row 26, Column a** (Buzzer Negative Leg).

3. **Sensor Signal Connection:**
   - Connect a jumper wire from **Row 21, Column a** (PIR Sensor OUTPUT) directly to **GPIO 13** on the ESP32.

4. **Buzzer Signal Connection:**
   - Connect a jumper wire from **Row 25, Column a** (Buzzer Positive Leg) directly to **GPIO 22** on the ESP32.

5.

Connect the Micro USB cable to the ESP32 board and plug the other end into your computer.

## PROGRAMMING

### 1. Variable Declarations

```cpp
const int buzzerPin = 22;
const int digitalSensorPin = 13;
```
*Explanation:* We define constant variables to store the pin assignments. `buzzerPin` is set to GPIO 22 (connected to the buzzer's positive lead), and `digitalSensorPin` is set to GPIO 13 (connected to the PIR Motion Sensor output pin).

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
  pinMode(buzzerPin, OUTPUT);
  pinMode(digitalSensorPin, INPUT);
}
```
*Explanation:* The `setup()` block runs once when the board is powered on or reset. `Serial.begin(9600)` opens serial communication at 9600 baud rate for monitoring. `pinMode(buzzerPin, OUTPUT)` configures pin 22 as an output to send signals to the buzzer. `pinMode(digitalSensorPin, INPUT)` configures pin 13 as an input to receive motion detection signals from the sensor.

---

### 3. Loop Function

```cpp
void loop() {
  int value = digitalRead(digitalSensorPin);
  
  if (value == HIGH) { 
    digitalWrite(buzzerPin, HIGH); 
  } else { 
    digitalWrite(buzzerPin, LOW); 
  }
  
  delay(500);
}
```
*Explanation:* The `loop()` function executes continuously. It reads the status of the PIR motion sensor using `digitalRead(digitalSensorPin)`. If motion is detected (`value == HIGH`), the ESP32 activates the buzzer using `digitalWrite(buzzerPin, HIGH)`. If no motion is detected, it turns off the buzzer using `digitalWrite(buzzerPin, LOW)`. Finally, a `delay(500)` adds a half-second pause between readings to keep output stable.
