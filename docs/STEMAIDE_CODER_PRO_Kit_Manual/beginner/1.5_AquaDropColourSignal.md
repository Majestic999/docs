### Mounting Instructions

1. **Mounting the ESP32 Board:**
   - Align the ESP32 board across the center divider (trough) of the breadboard.
   - Insert the left pin row into Column E, spanning Rows 1 to 15.
   - Insert the right pin row into Column F, spanning Rows 1 to 15.
   - Press down gently to firmly secure the ESP32 onto the breadboard.

Ensure pins on opposite sides do not share the same row across the trough.

2. **Mounting the Water Sensor Module:**
   - Locate an unused section of the breadboard (e.g., Rows 20 to 22).
   - Insert the VCC pin into Row 20, Column h.
   - Insert the GND pin into Row 21, Column h.
   - Insert the SIG (Signal) pin into Row 22, Column h.
   - Ensure each terminal leg sits on its own individual row to prevent short circuits.

3. **Mounting the RGB LED Module:**
   - Locate an unused section on the breadboard (e.g., Rows 25 to 28).
   - Insert the R (Red) pin into Row 25, Column h.
   - Insert the G (Green) pin into Row 26, Column h.
   - Insert the B (Blue) pin into Row 27, Column h.
   - Insert the GND (-) pin into Row 28, Column h.
   - Ensure all four module pins occupy distinct rows on the breadboard.

---

### Wiring Instructions

1. **ESP32 Power Rail Setup:**
   - Connect a jumper wire from the ESP32 3V3 pin (Row 1, Column B) to the positive (+) power rail of the breadboard.
   - Connect a jumper wire from the ESP32 GND pin (Row 2, Column B) to the negative (-) GND power rail of the breadboard.

2. **Water Sensor Power & Signal Connections:**
   - Connect a jumper wire from Row 20, Column j (Water Sensor VCC) to the positive (+) power rail.
   - Connect a jumper wire from Row 21, Column j (Water Sensor GND) to the negative (-) GND power rail.
   - Connect a jumper wire from Row 22, Column j (Water Sensor SIG) to ESP32 GPIO 2 (Row 11, Column B).

3. **RGB LED Module Power & Signal Connections:**
   - Connect a jumper wire from Row 28, Column j (RGB GND pin) to the negative (-) GND power rail.
   - Connect a jumper wire from Row 25, Column j (RGB R pin) to ESP32 GPIO 4 (Row 10, Column B).
   - Connect a jumper wire from Row 26, Column j (RGB G pin) to ESP32 GPIO 18 (Row 9, Column I).
   - Connect a jumper wire from Row 27, Column j (RGB B pin) to ESP32 GPIO 19 (Row 8, Column I).

4. **Power Connection:**
   - Connect the Micro USB cable to the ESP32 board and plug the other end into your computer.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Pin Definitions
const int sensorPin = 2;   // Water Sensor signal connected to GPIO 2
const int redPin    = 4;   // RGB Red channel connected to GPIO 4
const int greenPin  = 18;  // RGB Green channel connected to GPIO 18
const int bluePin   = 19;  // RGB Blue channel connected to GPIO 19
```
*Explanation:* We declare `const int` variables to assign the specific ESP32 GPIO pins connected to our water sensor and RGB LED module. GPIO 2 receives the analog signal from the water sensor, while GPIO 4, 18, and 19 output signals to control the Red, Green, and Blue channels of the RGB module.

```cpp
void setup() {
  // Initialize serial communication for debugging
  Serial.begin(9600);
  
  // Set RGB LED pins as outputs
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}
```
*Explanation:* In the `setup()` function, `Serial.begin(9600)` initializes serial communication at a speed of 9600 baud for debugging. The `pinMode()` function configures the Red, Green, and Blue control pins as `OUTPUT` pins so the ESP32 can send control signals to light up the RGB module.

```cpp
void loop() {
  // Read the analog value from the moisture sensor
  int value = analogRead(sensorPin);
  
  // Print sensor value to Serial Monitor
  Serial.print("Water Reading: ");
  Serial.println(value);
  
  // Update RGB LED colors based on sensor value
  // Modulo operator (%) keeps color values within the 0-255 PWM range
  analogWrite(redPin,   value % 255);
  analogWrite(greenPin, (value * 2) % 255);
  analogWrite(bluePin,  (value * 3) % 255);
  
  // Small delay for stability
  delay(500);
}
```
*Explanation:* In the `loop()` function, `analogRead(sensorPin)` continuously reads the moisture intensity detected by the water sensor and stores it in the variable `value`. This reading is output to the Serial Monitor. Using `analogWrite()` combined with the modulo operator (`% 255`), the code maps the raw reading into valid 8-bit color intensities (0 to 255) for the Red, Green, and Blue pins. This causes the RGB LED to dynamically shift color depending on the presence and quantity of water. A 500-millisecond delay stabilizes readings before repeating the loop.
