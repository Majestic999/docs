## Mounting the component on the breadboard and wiring the circuit

### Mounting Instructions

1. **Place the ESP32 Board**: Insert the ESP32 board across the center divider (trench) of the breadboard so that its left pins occupy Row 1 to Row 15 in Column E and its right pins occupy Row 1 to Row 15 in Column F.

2. **Mount the Push Button**:
   - Straddle the push button across the center divider, or place it on one side of the breadboard across two distinct rows.
   - Insert top terminal legs into Row 20 (Terminal 20E) and the bottom terminal legs into Row 22 (Terminal 22E). 
   - *Ensure the top and bottom pins are placed in separate rows (Row 20 and Row 22) so they are not short-circuited.*

3. **Mount the I2C LCD Display Module**:
   - Insert the 4 pins of the LCD's I2C module directly into four separate rows on the breadboard (e.g., Column J, Rows 25 to 28).
   - Assign the pins sequentially: Pin 1 (GND) into Row 25, Pin 2 (VCC) into Row 26, Pin 3 (SDA) into Row 27, and Pin 4 (SCL) into Row 28.

---

### Wiring Instructions

1. **Push Button Connections**:
   - Connect a jumper wire from **Row 20** (connected to one terminal of the push button) to **GPIO 2** on the ESP32 board.
   - Connect a jumper wire from **Row 22** (connected to the opposite terminal of the push button) to a **GND pin** on the ESP32 board.

2. **I2C LCD Display Connections**:
   - Connect a jumper wire from **Row 25** (GND pin on the I2C module) to a **GND pin** on the ESP32 board.
   - Connect a jumper wire from **Row 26** (VCC pin on the I2C module) to the **5V / VIN pin** on the ESP32 board.
   - Connect a jumper wire from **Row 27** (SDA pin on the I2C module) to **GPIO 21** on the ESP32 board.
   - Connect a jumper wire from **Row 28** (SCL pin on the I2C module) to **GPIO 22** on the ESP32 board.

## PROGRAMMING

### 1. Library Inclusions and Global Variable Declarations

```cpp
// Required Libraries
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Initialize LCD object (I2C address 0x27, 16 columns, 2 rows)
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Pin and state definitions
int buttonPin = 2;
int count = 0;
int lastState = HIGH;
```

*Explanation:* 
This section imports the necessary libraries for I2C communication (`Wire.h`) and LCD control (`LiquidCrystal_I2C.h`). It initializes an LCD object targeting address `0x27` with a screen size of 16x2. `buttonPin` is assigned to GPIO 2, `count` tracks the number of button presses starting at zero, and `lastState` tracks the previous button reading to detect single presses (edge detection).

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  
  lcd.init();
  lcd.backlight();
  
  lcd.setCursor(0, 0);
  lcd.print("Visitors:");
}
```

*Explanation:* 
In the `setup()` function, the push button pin is configured as `INPUT_PULLUP`, utilizing the ESP32's internal resistor so the default state reads `HIGH` when unpressed and `LOW` when pressed. The LCD screen is initialized, its backlight is turned on, and the static label `"Visitors:"` is printed on the first row (column 0, row 0).

---

### 3. Main Loop Function

```cpp
void loop() {
  // Read current button state
  int currentState = digitalRead(buttonPin);

  // Detect falling edge (transition from unpressed HIGH to pressed LOW)
  if (currentState == LOW && lastState == HIGH) {
    count++;
    lcd.setCursor(0, 1);
    lcd.print(count);
    lcd.print("     "); // Clear leftover trailing digits
    delay(200);        // Software debounce delay
  }

  // Update previous state
  lastState = currentState;
}
```

*Explanation:* 
The `loop()` reads the current digital state of the push button. When it detects a state change from `HIGH` to `LOW` (a button press event), it increments the `count` variable by 1. It then updates the second line of the LCD (column 0, row 1) with the new visitor count and appends spaces to overwrite remaining characters from previous higher numbers. A small delay of 200 ms prevents accidental double-counting due to mechanical button bounce. Finally, `lastState` is updated for the next iteration loop.
