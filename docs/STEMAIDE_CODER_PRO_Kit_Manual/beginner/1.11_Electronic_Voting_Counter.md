---

### Mounting Instructions

1. **Mounting the ESP32 Board**:
   - Place the ESP32 board straddling the central divider of the breadboard.
   - Align the left pins to column **D**, starting from row **1** to row **15**.
   - Align the right pins to column **G**, starting from row **1** to row **15**.

Ensure the Micro-USB port points toward the bottom edge of the board.

2. **Mounting Candidate A Push Button**:
   - Insert the first 4-pin tactile push button across the center terminal strip on the breadboard.
   - Place pin 1 into row **20, column E** and pin 2 into row **22, column E**.

Ensure opposite pins fit into rows **20** and **22** in column **F**.

3. **Mounting Candidate B Push Button**:
   - Insert the second 4-pin tactile push button lower down on the breadboard.
   - Place pin 1 into row **26, column E** and pin 2 into row **28, column E**.

Ensure opposite pins fit into rows **26** and **28** in column **F**.

4. **LCD Display (I2C Adapter)**:
   - Connect female-to-male jumper wires directly to the 4 pins (GND, VCC, SDA, SCL) on the back of the I2C interface attached to the LCD display screen.

---

### Wiring Instructions

1. **Candidate A Button Connections**:
   - Connect a jumper wire from **Row 20, Column A** (Candidate A Button terminal 1) to the common **GND rail** or row **14, Column B** (ESP32 GND pin).
   - Connect a jumper wire from **Row 22, Column A** (Candidate A Button terminal 2) to row **11, Column B** (**ESP32 GPIO 2**).

2. **Candidate B Button Connections**:
   - Connect a jumper wire from **Row 26, Column A** (Candidate B Button terminal 1) to the common **GND rail** or row **14, Column B** (ESP32 GND pin).
   - Connect a jumper wire from **Row 28, Column A** (Candidate B Button terminal 2) to row **6, Column I** (**ESP32 GPIO 18**).

3. **I2C LCD Display Connections**:
   - Connect the jumper wire from the LCD **VCC** pin to row **1, Column J** (**ESP32 5V/VIN**).
   - Connect the jumper wire from the LCD **GND** pin to row **14, Column J** (**ESP32 GND**).
   - Connect the jumper wire from the LCD **SDA** pin to row **3, Column J** (**ESP32 GPIO 21**).
   - Connect the jumper wire from the LCD **SCL** pin to row **2, Column J** (**ESP32 GPIO 22**).

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the program implementing the voting machine logic step-by-step.

### 1. Library Definitions and Global Variables

```cpp
#include <LiquidCrystal_I2C.h>

// Initialize LCD at address 0x27 with 16 columns and 2 rows
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Counters for candidate votes
int candidateA = 0;
int candidateB = 0;
```
*Explanation:* This section includes the header file for the I2C Liquid Crystal display. It creates an instance named `lcd` configured for address `0x27` with 16 columns and 2 rows. Two integer variables, `candidateA` and `candidateB`, are declared and initialized to zero to store the vote counts.

### 2. Setup Function

```cpp
void setup() {
  // Configure push button pins with internal pull-up resistors
  pinMode(2, INPUT_PULLUP);
  pinMode(18, INPUT_PULLUP);

  // Initialize and turn on the LCD screen
  lcd.init();
  lcd.backlight();
}
```
*Explanation:* The `setup()` function configures GPIO 2 (Candidate A button) and GPIO 18 (Candidate B button) as input pins with internal pull-up resistors (`INPUT_PULLUP`). This ensures the pin states default to `HIGH` and switch to `LOW` when pressed. It also initializes the LCD panel and switches on its backlight.

### 3. Loop Function

```cpp
void loop() {
  // Check if Candidate A button is pressed
  if (digitalRead(2) == LOW) {
    candidateA++;
    delay(300);
  }

  // Check if Candidate B button is pressed
  if (digitalRead(18) == LOW) {
    candidateB++;
    delay(300);
  }

  // Print Candidate A's votes on row 0, column 0
  lcd.setCursor(0, 0);
  lcd.print("A:");
  lcd.print(candidateA);

  // Print Candidate B's votes on row 0, column 8
  lcd.setCursor(8, 0);
  lcd.print("B:");
  lcd.print(candidateB);
}
```
*Explanation:* The `loop()` function continuously checks if either button is pressed (`LOW`). When Candidate A's button is pressed, `candidateA` increments by 1, followed by a 300 ms delay to prevent button bouncing (multiple rapid triggers). The same logic applies to Candidate B's button. Finally, `lcd.setCursor()` and `lcd.print()` update and display the current vote totals for both candidates on the LCD screen in real time.
