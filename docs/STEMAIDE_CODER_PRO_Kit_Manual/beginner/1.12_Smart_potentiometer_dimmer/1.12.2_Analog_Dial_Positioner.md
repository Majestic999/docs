# Project 1.12.2: Analog Dial Positioner

| **Description** | This project shows how to read the analog output of a rotary potentiometer and map the value to a meaningful scale such as percentage displayed on the Serial Monitor. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used in volume control knobs, dimmer switches, and any application requiring variable analog input. |

## Building the circuit

> **Tip:** Use the [ESP32 Pin Mapping](../../assets/esp32_pin_mapping.png) image to locate the correct GPIO pins on your ESP32 board.

Things Needed:

- ESP32 board = 1

- Micro USB cable = 1

- Potentiometer = 1

- Jumper wires

### Mounting the components

1.

Insert the potentiometer into three consecutive rows on the breadboard terminal strip (for example, Column E, Rows 15, 16, and 17).

Ensure that each of the three legs is inserted into a different row so they do not short-circuit:
   - **Left pin (Pin 1 / Terminal 1):** Insert into **Row 15, Column E**.
   - **Middle pin (Pin 2 / Wiper signal):** Insert into **Row 16, Column E**.
   - **Right pin (Pin 3 / Terminal 2):** Insert into **Row 17, Column E**.

![Component on breadboard](../../../assets/1.0/Potentiometer/circuit_1.png)

_**NB:** Make sure you identify the correct pin connections for the component._

### Wiring the circuit

1. **Ground Connection:** Connect a jumper wire from **Breadboard Row 15** (connected to the left pin of the potentiometer) to a **GND** pin on your ESP32 board.
![Component on breadboard](../../../assets/1.0/Potentiometer/circuit_2.png)

2. **Signal Connection:** Connect a jumper wire from **Breadboard Row 16** (connected to the middle wiper pin of the potentiometer) to **GPIO 36** (VP) on the analog side of your ESP32 board.
![Component on breadboard](../../../assets/1.0/Potentiometer/circuit_3.png)

3. **Power Connection:** Connect a jumper wire from **Breadboard Row 17** (connected to the right pin of the potentiometer) to the **3.3V** (or 5V) pin on your ESP32 board.
![Component on breadboard](../../../assets/1.0/Potentiometer/circuit_4.png)

_Make sure to connect the Micro USB cable to the ESP32 board._

## Programming

### Step 1: Variable Declarations

```cpp
const int potPin = 36;
int potValue = 0;
int percentage = 0;
```

*Explanation:* This section declares the variables used in the program. `potPin` assigns GPIO 36 as the analog input pin connected to the potentiometer wiper. `potValue` is initialized to hold the raw analog reading, and `percentage` will store the calculated percentage value from 0% to 100%.

### Step 2: Setup Function

```cpp
void setup() {
  Serial.begin(115200);
  pinMode(potPin, INPUT);
}
```

*Explanation:* The `setup()` function configures initial settings when the board powers on. `Serial.begin(115200)` initializes serial communication at a baud rate of 115200 so the board can output data to the Serial Monitor. `pinMode(potPin, INPUT)` sets GPIO 36 as an input to read the analog voltage level from the potentiometer.

### Step 3: Loop Function

```cpp
void loop() {
  potValue = analogRead(potPin);
  percentage = map(potValue, 0, 4095, 0, 100);

  Serial.print("Value: ");
  Serial.print(potValue);
  Serial.print(" (");
  Serial.print(percentage);
  Serial.println("%)");

  delay(500);
}
```

*Explanation:* The `loop()` function executes repeatedly. `analogRead(potPin)` reads the raw 12-bit analog signal (0 to 4095) from the potentiometer. The `map()` function scales this value down to a 0–100 range representing position percentage. The `Serial.print()` functions display the raw analog value alongside its mapped percentage on the Serial Monitor, and `delay(500)` adds a brief pause between readings to make the output readable.
