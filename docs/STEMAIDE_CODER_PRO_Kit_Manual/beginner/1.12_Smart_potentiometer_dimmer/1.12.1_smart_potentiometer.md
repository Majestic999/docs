# Project 1.12.1: Smart Potentiometer

| **Description** | This project allows you to control the brightness of an LED using a potentiometer. As the potentiometer knob is rotated, the LED brightness increases or decreases smoothly. |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use case**    | Light dimmers, brightness control systems, user input devices, analog sensor demonstrations.                                                                                 |

## Mounting Instructions

**Step 1:** Mount the ESP32 board on the breadboard so that it straddles the central dividing ridge, placing the left set of header pins into Column D (rows 1 through 15) and the right set of header pins into Column G (rows 1 through 15).

**Step 2:** Insert the three pins of the potentiometer into separate, adjacent rows in Column E on the breadboard. For example:

- Insert the left terminal pin into **Row 20, Column E**.

- Insert the center wiper terminal pin into **Row 21, Column E**.

- Insert the right terminal pin into **Row 22, Column E**.
*Ensure that no two pins share the same row to avoid short-circuiting the potentiometer.*

**Step 3:** Mount the LED onto the breadboard:

- Insert the longer, positive leg (anode) into **Row 25, Column E**.

- Insert the shorter, negative leg (cathode) into **Row 26, Column E**.
*Ensure the two legs are placed in different rows so that current flows through the component properly.*

**Step 4:** Insert one leg of the 220 Ω resistor into **Row 25, Column D** (making contact with the LED anode).

Insert the other leg of the resistor into **Row 27, Column D**.

---

## Wiring Instructions

1. **Potentiometer Power Connection:** Connect a jumper wire from **Row 20** (left pin of the potentiometer) to the **5V** (or 3.3V) pin on the ESP32 board.

2. **Potentiometer Signal Connection:** Connect a jumper wire from **Row 21** (center wiper pin of the potentiometer) to **GPIO 36 (VP)** on the ESP32 board.

3. **Potentiometer Ground Connection:** Connect a jumper wire from **Row 22** (right pin of the potentiometer) to a **GND** pin on the ESP32 board.

4. **LED Signal Connection:** Connect a jumper wire from **Row 27** (the free end of the 220 Ω resistor) to **GPIO 23** on the ESP32 board.

5. **LED Ground Connection:** Connect a jumper wire from **Row 26** (LED cathode leg) to a **GND** pin on the ESP32 board.

6. **USB Interface:** Connect the ESP32 board to your computer using the Micro USB cable.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Enter the logic blocks as shown below into your Arduino IDE workspace.

### Block 1: Variable Declarations and Pin Definitions

```cpp
// Pin assignments
const int POT_PIN = 36;  // ESP32 GPIO 36 (VP) connected to the potentiometer wiper pin
const int LED_PIN = 23;  // ESP32 GPIO 23 connected to the LED resistor

// Variables for processing analog and output levels
int potValue = 0;        // Stores raw analog input value from potentiometer (0 to 4095)
int pwmValue = 0;        // Stores mapped output PWM value for LED brightness (0 to 255)
```

*Explanation:* In this initial section, constants are created to map the physical connection points: `POT_PIN` is set to GPIO 36 for reading the analog input, and `LED_PIN` is mapped to GPIO 23 to drive the LED output. Two integer variables, `potValue` and `pwmValue`, are declared to hold the raw input data (0 to 4095 from the ESP32 12-bit ADC) and the scaled brightness data (0 to 255 for 8-bit PWM control), respectively.

---

### Block 2: Setup Function

```cpp
void setup() {
  // Initialize serial communication for real-time monitoring
  Serial.begin(115200);

  // Set the LED pin as an output
  pinMode(LED_PIN, OUTPUT);
}
```

*Explanation:* The `setup()` function executes once when the ESP32 powers up. `Serial.begin(115200)` configures the serial communication speed to 115200 baud, enabling diagnostic output to be viewed in the Serial Monitor. The `pinMode()` function sets `LED_PIN` (GPIO 23) as an output pin so that the ESP32 can send control signals to the LED.

---

### Block 3: Main Loop Function

```cpp
void loop() {
  // Read the analog signal level from the potentiometer
  potValue = analogRead(POT_PIN);

  // Map the 12-bit analog range (0-4095) to an 8-bit PWM range (0-255)
  pwmValue = map(potValue, 0, 4095, 0, 255);

  // Write the PWM signal to adjust the LED brightness
  analogWrite(LED_PIN, pwmValue);

  // Print values to the Serial Monitor
  Serial.print("Potentiometer Value: ");
  Serial.print(potValue);
  Serial.print(" | LED Brightness (PWM): ");
  Serial.println(pwmValue);

  // Small delay to stabilize sampling rate and serial readings
  delay(50);
}
```

*Explanation:* The `loop()` function runs continuously. First, `analogRead(POT_PIN)` measures the analog voltage level on GPIO 36, storing the value (0 to 4095) inside `potValue`. Next, `map()` converts this 12-bit ADC reading proportionally into an 8-bit range (0 to 255) suited for PWM LED dimming. `analogWrite()` applies this PWM value to `LED_PIN` to alter the brightness. `Serial.print()` and `Serial.println()` transmit both the raw and mapped values to the computer display screen, followed by a 50ms pause for stability.

## OBSERVATION

When the potentiometer is rotated:

- Turning it fully counterclockwise makes the LED turn OFF.

- Turning it slightly increases the LED brightness gradually.

- Turning it halfway produces medium brightness.

- Turning it fully clockwise makes the LED reach maximum brightness.

- The Serial Monitor displays the potentiometer reading and the corresponding brightness value.
