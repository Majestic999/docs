## Wiring the circuit

Follow these step-by-step connection details using your jumper wires. The servo motor has three wires extending from it, typically colored Red (Power), Brown (Ground), and Orange/Yellow (Signal).

**Step 1:** Connect the servo power wire

- Attach a jumper wire to the servo’s **Red** wire and connect the other end to the **5V** or **VIN** pin on the ESP32 board. This supplies power to the servo motor. 

**Step 2:** Connect the ground wire

- Attach a jumper wire to the servo’s **Brown** (or Black) wire and connect the other end to the **GND pin** on the ESP32 board. This completes the electrical circuit.

**Step 3:** Connect the control wire

- Attach a jumper wire to the servo’s **Orange** (or Yellow) wire and connect the other end to **GPIO 33** on the ESP32 board. This wire sends movement commands from the ESP32 board to the servo motor.

![complete circuit](../../../assets/coder_pro/beginner/Servo_Motor/One_Angle/circuit_5.png)

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

*(Note: Ensure you have the `ESP32Servo` library installed via the Arduino Library Manager for best compatibility, though some setups use standard `Servo.h` with ESP32).*

### 1. Library Inclusion and Object Creation

```cpp
#include <ESP32Servo.h>

Servo motor;
```
*Explanation:* `#include <ESP32Servo.h>` tells the program to use the library of code that knows how to control servo motors on the ESP32. `Servo motor;` creates a 'Servo' object named `motor` that we will use to control the physical motor.

---

### 2. Setup Function

```cpp
void setup() {
  motor.attach(33);
}
```
*Explanation:* The `setup()` function runs once. `motor.attach(33);` links our `motor` object to GPIO 33, where we connected the orange signal wire. 

---

### 3. Loop Function

```cpp
void loop() {
  motor.write(90); 
}
```
*Explanation:* `motor.write(90);` commands the servo to rotate its arm to exactly the 90-degree position. It will hold this position continuously.

**NB:** The swing arm can generally turn between 0 and 180 degrees. You can change the angle by adjusting the number in the brackets. For example, `motor.write(180);` will move the arm to its maximum position.
