## Wiring the circuit

Follow these step-by-step connection details using your jumper wires. The servo motor has three wires extending from it, typically colored Red (Power), Brown (Ground), and Orange/Yellow (Signal).

**Step 1:** Connect the servo power wire

- Attach a jumper wire to the servo’s **Red** wire and connect the other end to the **5V** or **VIN** pin on the ESP32 board. This supplies power to the servo motor. 

**Step 2:** Connect the ground wire

- Attach a jumper wire to the servo’s **Brown** (or Black) wire and connect the other end to the **GND pin** on the ESP32 board. This completes the electrical circuit.

**Step 3:** Connect the control wire

- Attach a jumper wire to the servo’s **Orange** (or Yellow) wire and connect the other end to **GPIO 33** on the ESP32 board. This wire sends movement commands from the ESP32 board to the servo motor.

![complete circuit](../../../assets/coder_pro/beginner/Servo_Motor/motor_sweep/circuit_6.png)

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Library Inclusion and Object Creation

```cpp
#include <ESP32Servo.h>

Servo motor;
```
*Explanation:* `#include <ESP32Servo.h>` allows the ESP32 to understand servo control commands. `Servo motor;` creates a 'Servo' object named `motor` that we will use to control it.

---

### 2. Setup Function

```cpp
void setup() {
  motor.attach(33);
}
```
*Explanation:* The `setup()` function runs once. `motor.attach(33);` links our `motor` object to GPIO 33, where we connected the signal wire. 

---

### 3. Loop Function

```cpp
void loop() {
  // Sweep upwards from 0 to 180 degrees
  for (int i = 0; i <= 180; i++) {
    motor.write(i);
    delay(10);
  }
  
  // Sweep downwards from 180 to 0 degrees
  for (int i = 180; i >= 0; i--) {
    motor.write(i);
    delay(10);
  }
}
```
*Explanation:* The `loop()` continuously runs. 

- The first `for` loop gradually moves the servo from 0° to 180° by increasing the angle `i` by 1 degree at a time, pausing for 10 milliseconds between each step. This creates a smooth upward sweep.

- The second `for` loop moves the servo back from 180° to 0° by decreasing the angle `i` by 1 degree at a time, creating a smooth downward sweep.
