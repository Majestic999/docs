## Mounting Instructions

1. **ESP32 Board Placement:** Straddle the ESP32 board over the central divider (trench) of the breadboard so that its pins fit into column **e** on one side and column **f** on the other side, starting at row 1.

2. **LED Placement:**
   - Locate an unused section of the breadboard (e.g., row 20 and row 21).
   - Insert the **longer positive leg (anode)** of the LED into **row 20, column e**.
   - Insert the **shorter negative leg (cathode)** of the LED into **row 21, column e**. 
   - *Ensure both legs are placed in separate rows to prevent a short circuit.*

3. **Resistor Placement:**
   - Insert one terminal of the 220Ω resistor into **row 21, column d** (in the same row as the LED cathode).
   - Insert the other terminal of the resistor directly into the **ground (-) rail** on the side of the breadboard.

4. **IR Receiver Module Placement:**
   - Insert the 3-pin IR Receiver Module into the breadboard so that its pins land on **row 25, 26, and 27** in column **e**:
     - **OUT Pin (Signal):** Row 25, Column e
     - **GND Pin:** Row 26, Column e
     - **VCC Pin (Power):** Row 27, Column e

---

## Wiring Instructions

1. **Common Ground (GND):**
   - Connect a jumper wire from the **GND** pin of the ESP32 (e.g., row 14, column a) to the **ground (-) rail** of the breadboard.

2. **IR Receiver Power (VCC):**
   - Connect a jumper wire from the **5V / VIN** pin of the ESP32 (e.g., row 1, column a) to **row 27, column a** (connected to the VCC pin of the IR Receiver).

3. **IR Receiver Signal Wire:**
   - Connect a jumper wire from **GPIO 2** of the ESP32 (e.g., row 4, column j) to **row 25, column a** (connected to the OUT pin of the IR Receiver).

4. **IR Receiver Ground:**
   - Connect a jumper wire from **row 26, column a** (connected to the GND pin of the IR Receiver) to the **ground (-) rail** of the breadboard.

5. **LED Control Wire:**
   - Connect a jumper wire from **GPIO 22** of the ESP32 (e.g., row 11, column j) to **row 20, column a** (connected to the positive anode of the LED).

## Programming

### Step 1: Library Declarations and Global Variables

```cpp
// Required Library: IRremote
#include <IRremote.h>

// IR receiver pin connected to GPIO 2
const int receiverPin = 2;

// LED pin connected to GPIO 22
const int ledPin = 22;

// Create receiver object
IRrecv irrecv(receiverPin);

// Variable to store decoded IR data
decode_results results;
```

*Explanation:* 
This section includes the `IRremote.h` library required to decode signals sent from the IR remote. It defines `receiverPin` as GPIO pin 2 and `ledPin` as GPIO pin 22. An instance of the IR receiver (`irrecv`) is initialized using the designated receiver pin, and a `decode_results` object named `results` is created to hold the incoming data signals from the remote control.

---

### Step 2: Setup Function

```cpp
void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
  
  // Start the IR receiver
  irrecv.enableIRIn();
}
```

*Explanation:* 
In the `setup()` function, the LED pin is configured as an `OUTPUT` using `pinMode()`. Serial communication is initialized at a baud rate of 9600 to allow monitoring hex values received from the IR remote. Finally, `irrecv.enableIRIn()` starts listening for infrared signals from the remote control.

---

### Step 3: Main Control Loop

```cpp
void loop() {
  // Check if a signal from the IR remote has been received
  if (irrecv.decode(&results)) {
    // Print the received code in Hexadecimal format to Serial Monitor
    Serial.println(results.value, HEX);
    
    // Turn LED ON if specific 'ON' button code is received
    if(results.value == 0xFFA25D) {
      digitalWrite(ledPin, HIGH);
    }
    
    // Turn LED OFF if specific 'OFF' button code is received
    if(results.value == 0xFFE21D) {
      digitalWrite(ledPin, LOW);
    }
    
    // Prepare the IR receiver to capture the next value
    irrecv.resume();
  }
}
```

*Explanation:* 
The `loop()` function checks continuously if an IR signal has been detected and decoded using `irrecv.decode(&results)`. When a signal is caught, its hexadecimal value is printed to the Serial Monitor. If the code matches `0xFFA25D` (a designated remote button), `digitalWrite()` turns the LED `HIGH` (ON). If the code matches `0xFFE21D`, the LED is turned `LOW` (OFF). `irrecv.resume()` resets the receiver so it can receive the next button press.
