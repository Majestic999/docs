## Mounting Instructions

1. **ESP32 Microcontroller Placement**:
   - Align the ESP32 board so that it straddles the central divider (the trench) of the breadboard.
   - Insert the left pin header into **Column E (Rows 1 to 15)** and the right pin header into **Column F (Rows 1 to 15)**.
   - Press down gently and evenly until the pins are firmly seated into the breadboard.

2. **Joystick Module Placement**:
   - Locate an open area on the breadboard (e.g., **Rows 20 to 24**).
   - Insert the 5-pin header of the Joystick module into **Column E, Rows 20 to 24**:
     - Pin 1 (GND): **Row 20, Column E**
     - Pin 2 (+5V/VCC): **Row 21, Column E**
     - Pin 3 (VRx): **Row 22, Column E**
     - Pin 4 (VRy): **Row 23, Column E**
     - Pin 5 (SW): **Row 24, Column E**

3. **4-Digit Display Module (TM1637) Placement**:
   - Insert the 4-pin header of the 4-Digit Display module into **Column E, Rows 28 to 31**:
     - Pin 1 (CLK): **Row 28, Column E**
     - Pin 2 (DIO): **Row 29, Column E**
     - Pin 3 (VCC): **Row 30, Column E**
     - Pin 4 (GND): **Row 31, Column E**

---

## Wiring Instructions

Connect the jumper wires step-by-step according to the breadboard layout:

1. **Power & Ground Rails Setup**:
   - Connect a male-to-male jumper wire from the ESP32 **5V pin** (Row 1, Column B) to the positive power rail (**+**) of the breadboard.
   - Connect a male-to-male jumper wire from the ESP32 **GND pin** (Row 2, Column B) to the negative ground rail (**-**) of the breadboard.

2. **Joystick Power & Signal Connections**:
   - Connect a jumper wire from **Row 20 (Joystick GND)** to the ground rail (**-**).
   - Connect a jumper wire from **Row 21 (Joystick VCC)** to the power rail (**+**).
   - Connect a jumper wire from **Row 22 (Joystick VRx)** to **ESP32 GPIO 36 / VP** (Row 3, Column A).
   - Connect a jumper wire from **Row 23 (Joystick VRy)** to **ESP32 GPIO 39 / VN** (Row 4, Column A).
   - Connect a jumper wire from **Row 24 (Joystick SW)** to **ESP32 GPIO 2** (Row 11, Column J).

3. **4-Digit Display Connections**:
   - Connect a jumper wire from **Row 28 (Display CLK)** to **ESP32 GPIO 4** (Row 10, Column J).
   - Connect a jumper wire from **Row 29 (Display DIO)** to **ESP32 GPIO 5** (Row 9, Column J).
   - Connect a jumper wire from **Row 30 (Display VCC)** to the power rail (**+**).
   - Connect a jumper wire from **Row 31 (Display GND)** to the ground rail (**-**).

4. **Final Check**:
   - Verify that no wires bridge power and ground directly.
   - Attach the Micro USB cable to the ESP32 board and connect it to your computer.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Review and write the program logic broken down below.

### 1. Header & Pin Declarations
```cpp
#include <TM1637Display.h>

// Pin Definitions for 4-Digit Display Tube
#define CLK_PIN 4
#define DIO_PIN 5

// Initialize TM1637 Display Object
TM1637Display display(CLK_PIN, DIO_PIN);

// Define Joystick Input Pins
const int pinVRx = 36;
const int pinVRy = 39;
const int pinSW  = 2;
```
*Explanation:* This section includes the TM1637 display library and defines which ESP32 pins control the display module (CLK on GPIO 4, DIO on GPIO 5). It creates the `display` object and declares the joystick pin assignments for X-axis (GPIO 36), Y-axis (GPIO 39), and Pushbutton Switch (GPIO 2).

---

### 2. Setup Function
```cpp
void setup() {
  Serial.begin(9600);
  
  // Set display brightness (0 = lowest, 7 = highest)
  display.setBrightness(7);
  
  // Enable internal pull-up resistor for the Joystick switch pin
  pinMode(pinSW, INPUT_PULLUP);
}
```
*Explanation:* The `setup()` function runs once when the board powers on. It starts serial communication at a baud rate of 9600 for debugging purposes, sets the 4-digit display to maximum brightness, and configures the joystick switch pin with an internal pull-up resistor to ensure stable digital reads.

---

### 3. Main Loop Function
```cpp
void loop() {
  // Read analog values from Joystick X and Y axes (0 to 4095)
  int xValue = analogRead(pinVRx);
  int yValue = analogRead(pinVRy);
  
  // Read digital state from Joystick push button (0 = pressed, 1 = unpressed)
  int swValue = digitalRead(pinSW);

  // Print all values to Serial Monitor for testing
  Serial.print("X: "); 
  Serial.print(xValue);
  Serial.print(" | Y: "); 
  Serial.print(yValue);
  Serial.print(" | SW: "); 
  Serial.println(swValue);

  // Display the X-axis value on the 4-Digit Display
  display.showNumberDec(xValue);
  
  delay(500);
}
```
*Explanation:* The `loop()` function continuously samples the analog positions of the joystick's X and Y axes along with the digital button state. It formats and outputs these raw values to the Serial Monitor and updates the 4-digit display to reflect the current X-axis position. It delays for 500 milliseconds before repeating.
