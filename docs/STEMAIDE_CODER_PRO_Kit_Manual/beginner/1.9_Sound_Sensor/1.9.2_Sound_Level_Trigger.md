## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Sound Sensor:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the sound sensor module on the breadboard, ensuring the pins are firmly placed in separate adjacent rows (e.g., Rows 20 to 23, Column A).

![Component on breadboard](../../../assets/coder_pro/beginner/Sound_Trigger/circuit_2.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Connect Power and Ground

- Connect a jumper wire to the **VCC** / positive pin (+) of the sound sensor and the other end to **5V** or **3V3** on the ESP32 board. (3.3V is recommended for analog sensing on ESP32).

- Connect a jumper wire to the **GND** / negative pin (-) of the sound sensor and the other end to a **GND pin** on the ESP32 board.

**Step 2:** Connect the Signal Wire

- Connect a jumper wire to the **AO** (Analog Output) pin of the sound sensor and the other end to **GPIO 36** (also labeled VP) on the ESP32 board.

![Wiring diagram](../../../assets/coder_pro/beginner/Sound_Trigger/circuit_4.png)

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int soundPin = 36;
int threshold = 600;
int soundValue = 0;
```
*Explanation:* We declare `soundPin` as 36 for the analog reading. The `threshold` is set to 600—if the analog sound level crosses this number, it means a loud noise was detected (you may need to tweak this depending on your environment). `soundValue` will temporarily store the sensor's current reading.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
}
```
*Explanation:* We initialize the Serial Monitor at 9600 baud rate so we can send output messages to the computer screen.

---

### 3. Loop Function

```cpp
void loop() {
  // Read sound sensor value
  soundValue = analogRead(soundPin);
  
  // Print current sound level
  Serial.print("Sound: ");
  Serial.println(soundValue);
  
  // Check if threshold exceeded
  if (soundValue > threshold) {
    Serial.println("NOISE DETECTED!");
    delay(200); // Cooldown to prevent repeated triggers
  }
  
  delay(50);
}
```
*Explanation:* `analogRead(soundPin)` reads a value proportional to the sound amplitude in the room. The `if` statement checks if that reading is greater than our `threshold`. When a loud sound occurs, the value spikes above 600, triggering the "NOISE DETECTED!" alert message and adding a 200ms delay to prevent the screen from being flooded with the same alert instantly.
