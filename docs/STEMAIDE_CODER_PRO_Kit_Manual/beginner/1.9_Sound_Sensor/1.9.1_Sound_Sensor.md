## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Sound Sensor:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Insert the 4-pin sound sensor module into the breadboard (typically pins are VCC, GND, DO, AO), ensuring the pins are firmly placed in separate adjacent rows (e.g., Rows 20 to 23, Column A).

![Mount the Sound Sensor on the Breadboard](../../../assets/coder_pro/beginner/Sound_Sensor/circuit_1.png)

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Connect Power and Ground

- Connect a jumper wire from **VCC** (or + pin) on the sound sensor to the **5V** or **3V3** pin on the ESP32 board (depending on your module's required voltage; 3.3V is typically safer for ESP32 analog reads).

- Connect a jumper wire from **GND** (or - pin) on the sound sensor to a **GND pin** on the ESP32 board.

**Step 2:** Connect the Signal Wire

- Connect a jumper wire from the **AO** (Analog Output) pin on the sound sensor to **GPIO 36** (also labeled VP) on the ESP32 board. This allows the ESP32 to read variable sound intensity levels.

![connect signal jumper wire](../../../assets/coder_pro/beginner/Sound_Sensor/circuit_3.png)

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int soundSensorPin = 36;
```
*Explanation:* We declare `soundSensorPin` as 36, mapping to GPIO 36 where our analog output from the sound sensor is connected.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
}
```
*Explanation:* We initialize the Serial Monitor at a 9600 baud rate so the ESP32 can send the sound readings back to our computer for display. (Analog pins do not require `pinMode` to be set to INPUT).

---

### 3. Loop Function

```cpp
void loop() {
  int soundValue = analogRead(soundSensorPin);
  
  Serial.println(soundValue);
  
  delay(50);
}
```
*Explanation:* `analogRead(soundSensorPin)` continuously reads the current sound intensity level as a number from 0 to 4095. `Serial.println(soundValue)` prints this number to a new line on the Serial Monitor. The `delay(50)` introduces a tiny 50-millisecond pause to avoid flooding the screen too fast.
