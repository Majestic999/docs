## Mounting the components on the breadboard and wiring the circuit

### Mounting Instructions

1. **Mounting the ESP32 Board:**
   - Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E (Rows 1 to 15) and its right pins sit in Column F (Rows 1 to 15). 
   - Press down gently until the pins are firmly seated in the breadboard.

2. **Mounting the Ultrasonic Sensor (HC-SR04):**
   - Locate the 4 pins on the Ultrasonic Sensor: `VCC`, `TRIG`, `ECHO`, and `GND`.
   - Insert the sensor into the breadboard in lower rows (e.g., Rows 25 to 28, Column A) ensuring each pin occupies its own separate row:
     - `VCC` pin in **Row 25, Column A**
     - `TRIG` pin in **Row 26, Column A**
     - `ECHO` pin in **Row 27, Column A**
     - `GND` pin in **Row 28, Column A**

3. **Mounting the I2C LCD Display Module:**
   - Locate the 4 pins on the back of the I2C backpack attached to the LCD screen: `GND`, `VCC`, `SDA`, and `SCL`.
   - Insert the LCD module header pins into available rows further down the breadboard (e.g., Rows 32 to 35, Column A) ensuring each pin is on a separate row:
     - `GND` pin in **Row 32, Column A**
     - `VCC` pin in **Row 33, Column A**
     - `SDA` pin in **Row 34, Column A**
     - `SCL` pin in **Row 35, Column A**

### Wiring Instructions

Follow these step-by-step connection details using your jumper wires:

**Step 1: Connect Main Power Rail**

- Connect a jumper wire from the ESP32 5V pin (**Row 1, Column B**) to the Positive (+) Power Rail of the breadboard.

- Connect a jumper wire from the ESP32 GND pin (**Row 2, Column B**) to the Negative (-) Power Rail of the breadboard.

![Components on breadboard](../../assets/coder_pro/beginner/SonicRange_Number_Reporter/circuit_2.png)

**Step 2: Wire Power for the Ultrasonic Sensor**

- Connect a jumper wire from the Ultrasonic Sensor `VCC` (**Row 25, Column B**) to the Positive (+) Power Rail.

- Connect a jumper wire from the Ultrasonic Sensor `GND` (**Row 28, Column B**) to the Negative (-) Power Rail.

![Components on breadboard](../../assets/coder_pro/beginner/SonicRange_Number_Reporter/circuit_3.png)

**Step 3: Connect Ultrasonic Trigger and Echo Pins**

- Connect a jumper wire from the Ultrasonic Sensor `TRIG` pin (**Row 26, Column B**) to **GPIO 23** on the ESP32 board.

- **Wire the Echo Pin Voltage Divider (5V to 3.3V Protection)**:
  - Connect a **1kΩ resistor** from the Ultrasonic Sensor's **ECHO** pin to **GPIO 33** on the ESP32 board.
  - Connect a **2kΩ resistor** from **GPIO 33** to the **GND** rail on the breadboard.
  > **Voltage Safety Notice:** Because the HC-SR04 operates at 5V, its Echo pin outputs a 5V signal. The 1kΩ/2kΩ voltage divider safely steps this down to ~3.33V, protecting the ESP32 GPIO 33 from over-voltage damage.

**Step 4: Wire Power for the I2C LCD Display**

- Connect a jumper wire from the LCD `VCC` pin (**Row 33, Column B**) to the Positive (+) Power Rail.

- Connect a jumper wire from the LCD `GND` pin (**Row 32, Column B**) to the Negative (-) Power Rail.

**Step 5: Connect I2C Signal Pins**

- Connect a jumper wire from the LCD `SDA` pin (**Row 34, Column B**) to **GPIO 21** on the ESP32 board.

- Connect a jumper wire from the LCD `SCL` pin (**Row 35, Column B**) to **GPIO 22** on the ESP32 board.

## PROGRAMMING

### Step 1: Library Inclusions and Variable Declarations

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
int trigPin = 23;
int echoPin = 33;
```
*Explanation:* The code includes the `Wire.h` library for I2C communication and `LiquidCrystal_I2C.h` to control the display. An LCD object named `lcd` is declared with the I2C address `0x27`, specifying a 16-column by 2-row screen size. Integer variables `trigPin` and `echoPin` store the GPIO pin numbers connected to the ultrasonic sensor's Trigger (GPIO 23) and Echo (GPIO 33) pins.

---

### Step 2: Setup Function

```cpp
void setup() {
  Serial.begin(9600);
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Ready");
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}
```
*Explanation:* The `setup()` function executes once when the board powers up. It starts serial communication at a 9600 baud rate. The LCD screen is initialized, and its backlight is enabled. The cursor is set to column 0, row 0 to print the initial text `"Ready"`. The `trigPin` is configured as an `OUTPUT` to emit sound pulses, while `echoPin` is configured as an `INPUT` to listen for returning echo signals.

---

### Step 3: Main Control Loop

```cpp
void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  int value = duration * 0.034 / 2; // distance in cm

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Value:");
  lcd.setCursor(0, 1);
  lcd.print(value);
  delay(500);
}
```
*Explanation:* The `loop()` continuously calculates distance by sending a high 10-microsecond trigger pulse through `trigPin`. The `pulseIn()` function measures the travel time in microseconds taken for the sound wave to return to `echoPin`. This duration is converted to distance in centimeters using the speed of sound formula (`duration * 0.034 / 2`). Finally, the screen is cleared, `"Value:"` is printed on the first line, and the measured distance in centimeters is printed on the second line before waiting 500ms before the next reading.
