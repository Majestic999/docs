## Mounting Instructions

1.

Place the ESP32 board onto the breadboard, straddling the center dividing channel (e.g., spanning across columns e and f).

Ensure pin 1 sits at row 1. Press down firmly until all pins are fully inserted.

2. Identify the pins of your Common Cathode RGB LED:
   - **Pin 1 (Red):** Shortest pin on the outer left side.
   - **Pin 2 (Cathode / GND):** Longest pin second from the left.
   - **Pin 3 (Green):** Third pin from the left.
   - **Pin 4 (Blue):** Outer right pin.

3.

Insert the RGB LED into **Terminal Strip Row 15 to Row 18** in Column **f**:
   - Insert **Pin 1 (Red)** into **Row 15, Column f**.
   - Insert **Pin 2 (Cathode - GND)** into **Row 16, Column f**.
   - Insert **Pin 3 (Green)** into **Row 17, Column f**.
   - Insert **Pin 4 (Blue)** into **Row 18, Column f**.

4. **Important:** Ensure all four legs are inserted into distinct rows (Rows 15, 16, 17, and 18) to prevent short circuits.

---

## Wiring Instructions

Connect the jumper wires from the breadboard rows directly to the corresponding pins on the ESP32:

1. **Red LED Pin:** Connect a jumper wire from **Row 15 (Column g)** to **GPIO 23** on the ESP32.

2. **Ground Pin:** Connect a jumper wire from **Row 16 (Column g)** to a **GND** pin on the ESP32.

3. **Green LED Pin:** Connect a jumper wire from **Row 17 (Column g)** to **GPIO 33** on the ESP32.

4. **Blue LED Pin:** Connect a jumper wire from **Row 18 (Column g)** to **GPIO 25** on the ESP32.

## PROGRAMMING

### Variable Declarations

```cpp
// Define GPIO pins for each color channel of the RGB LED
const int redPin = 23;
const int greenPin = 33;
const int bluePin = 25;
```

*Explanation:* This section defines constant integers to assign specific ESP32 GPIO pins to each pin of the RGB LED. `redPin` controls the red channel via GPIO 23, `greenPin` controls green via GPIO 33, and `bluePin` controls blue via GPIO 25.

---

### Setup Function

```cpp
void setup() {
  // Configure RGB pins as output pins
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
}
```

*Explanation:* The `setup()` function runs once when the ESP32 powers on. The `pinMode()` function configures the three specified GPIO pins as outputs so the microcontroller can send signal voltage levels to power each LED color element.

---

### Helper Function for Color Control

```cpp
void setColor(int redValue, int greenValue, int blueValue) {
  analogWrite(redPin, redValue);
  analogWrite(greenPin, greenValue);
  analogWrite(bluePin, blueValue);
}
```

*Explanation:* This custom helper function takes three values ranging from 0 to 255 representing Red, Green, and Blue intensity. It uses `analogWrite()` to output Pulse Width Modulation (PWM) signals to the respective pins, controlling the overall mixed color output of the RGB LED.

---

### Loop Function (Day/Night Cycle Logic)

```cpp
void loop() {
  // Stage 1: Sunrise (Red-Orange glow)
  setColor(255, 50, 0);
  delay(5000);

  // Stage 2: Daylight (Bright daylight white/yellow)
  setColor(255, 255, 200);
  delay(10000);

  // Stage 3: Sunset (Deep orange to warm purple transition)
  setColor(255, 30, 10);
  delay(5000);

  // Stage 4: Nighttime (Dim blue night light)
  setColor(0, 0, 50);
  delay(10000);
}
```

*Explanation:* The `loop()` function executes continuously. It steps through four distinct lighting phases: Sunrise (5 seconds of red-orange), Daylight (10 seconds of bright warm white), Sunset (5 seconds of warm sunset orange), and Nighttime (10 seconds of dim moonlight blue). This creates a repeating 30-second solar simulation loop.
