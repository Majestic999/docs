## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 board and Buzzer:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the piezo buzzer on the breadboard. The longer pin is the positive (+) pin.
  - Insert the longer positive pin into **Row 20, Column A**.
  - Insert the shorter negative pin into **Row 22, Column A**.

![Component on breadboard](../../../assets/coder_pro/beginner/Piezo_Buzzer/wire_1.png)

_**NB:** Make sure you identify the correct pin connections for the component._

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the Buzzer to the ESP32

- Connect a jumper wire from **Row 20, Column B** (Buzzer positive pin) to **GPIO 4** on the ESP32 board.

**Step 2:** Wire the Ground

- Connect a jumper wire from **Row 22, Column B** (Buzzer negative pin) to a **GND pin** on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
int buzzerPin = 4;
```
*Explanation:* We declare an integer variable `buzzerPin` for GPIO 4, which matches our physical wiring.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(buzzerPin, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures `buzzerPin` as an `OUTPUT` to send electrical signals (frequencies) to the buzzer.

---

### 3. Loop Function

```cpp
void loop() {
  tone(buzzerPin, 1000);
  delay(500);
  
  noTone(buzzerPin);
  delay(500);
  
  tone(buzzerPin, 2000);
  delay(500);
  
  noTone(buzzerPin);
  delay(500);
}
```
*Explanation:* The `loop()` continuously runs. 
First, `tone(buzzerPin, 1000)` sends a 1000 Hz frequency square wave to the buzzer, creating a low-pitch beep for 500 milliseconds.

Then, `noTone(buzzerPin)` stops the sound, creating a 500ms moment of silence. 
Next, `tone(buzzerPin, 2000)` plays a much higher-pitch 2000 Hz beep for 500ms. 
Finally, the sound is stopped again for 500ms before the sequence repeats. This creates a two-tone alarm siren effect.
