## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 board and Buzzer:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the active buzzer on the breadboard. The longer pin is the positive (+) pin, while the shorter pin is the negative (-) pin.
  - Insert the longer positive pin into **Row 20, Column A**.
  - Insert the shorter negative pin into **Row 22, Column A**.

![LED fixed on breadboard](../../../assets/coder_pro/beginner/BUZZER/circuit_1.png)

_**NB:** Make sure you identify where the positive pin (+) and the negative pin (-) is connected to on the breadboard._

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the Buzzer to the ESP32

- Connect a jumper wire from **Row 20, Column B** (Buzzer positive pin) to **GPIO 4** on the ESP32 board.

**Step 2:** Wire the Ground

- Connect a jumper wire from **Row 22, Column B** (Buzzer negative pin) to a **GND pin** on the ESP32 board.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
int buzzer = 4;
```
*Explanation:* We declare an integer variable `buzzer` and set it to 4, mapping to GPIO 4 where the buzzer's positive pin is connected.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(buzzer, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures the `buzzer` pin as an `OUTPUT` so the ESP32 can send electrical signals to activate it.

---

### 3. Loop Function

```cpp
void loop() {
  digitalWrite(buzzer, HIGH);
}
```
*Explanation:* The `loop()` continuously runs. `digitalWrite(buzzer, HIGH)` sends voltage to the buzzer constantly. This causes an active buzzer to produce a continuous, unbroken beep sound.

**NB:** To turn off the buzzer, replace `HIGH` with `LOW` in the code. This change will stop sending a signal to the buzzer, turning it off.
