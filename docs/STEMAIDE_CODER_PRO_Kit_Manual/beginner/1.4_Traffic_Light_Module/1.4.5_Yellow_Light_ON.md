## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 board and Traffic Light Module:

- Align the ESP32 board across the center dividing ridge of the breadboard so that its left pins sit in Column E and its right pins sit in Column F.

- Place the Traffic Light Module on the breadboard. It has 4 pins: `G` (Green), `Y` (Yellow), `R` (Red), and `GND`.

Insert these 4 pins into separate adjacent rows (e.g., Rows 25 to 28, Column A).
  - `G` pin in **Row 25, Column A**
  - `Y` pin in **Row 26, Column A**
  - `R` pin in **Row 27, Column A**
  - `GND` pin in **Row 28, Column A**

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the Yellow Light to the ESP32

- Connect a jumper wire from **Row 26, Column B** (Y pin) to **GPIO 19** on the ESP32 board.

**Step 2:** Wire the common Ground

- Connect a jumper wire from **Row 28, Column B** (GND pin) to a **GND pin** on the ESP32 board.

*Make sure to connect the Micro USB cable securely to the ESP32 board and your computer.*

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Variable Declarations

```cpp
const int yellow = 19;
```
*Explanation:* We declare a constant integer variable `yellow` and set it to 19, mapping to GPIO 19 where the Yellow pin is connected.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(yellow, OUTPUT);
}
```
*Explanation:* The `setup()` function runs once. It configures the `yellow` pin as an `OUTPUT` so the ESP32 can send electrical signals to turn it on.

---

### 3. Loop Function

```cpp
void loop() {
  digitalWrite(yellow, HIGH);
}
```
*Explanation:* The `loop()` continuously runs. `digitalWrite(yellow, HIGH)` sends voltage to the yellow LED continuously, keeping it permanently turned ON.

**NB:** To turn off the yellow light, change `digitalWrite(yellow, HIGH);` into `digitalWrite(yellow, LOW);`.
