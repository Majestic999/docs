# Jumper Wires 65-Piece Set (Male to Male) — Technical Datasheet

## General Description

A 65-piece assortment of flexible, multi-length solderless breadboard jumper wires with machined 0.1" (2.54 mm) male pin terminations. Used across all experiments in the STEMAIDE Coder Pro Kit to connect the **Espressif ESP32-DevKitC V4** header pins into breadboard distribution rails and peripheral sensor modules [E1].

## Specifications

| Parameter | Value | Evidence Tier |
