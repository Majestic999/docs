# Female to Male Dupont Jumper Wires — Technical Datasheet

## General Description

A set of flexible multi-conductor ribbon jumper cables terminated with 0.1" (2.54 mm) Female Dupont sockets on one end and 0.1" Male header pins on the other. Used extensively across the STEMAIDE Coder Pro Kit to connect breakout modules having male header pins directly into breadboard contact holes or ESP32 female expansion headers [E1].

## Specifications

| Parameter | Value | Evidence Tier |
|---|---|---|
| **Connector Configuration** | 0.1" (2.54 mm) Female Dupont Socket to Male Pin | [E1] |
| **Standard Cable Length** | 20 cm (nominal) | [E1] |
| **Conductor Gauge** | 26 AWG to 28 AWG multi-strand copper | [E1] |
| **Contact Material** | Gold-plated or tin-plated phosphor bronze | [E1] |
| **Insulation Material** | Flame-retardant PVC | [E1] |
| **Maximum Voltage Rating**| 30 V DC | [E1] |
| **Maximum Current Rating** | 1.0 A continuous | [E5] |
| **Contact Resistance** | < 20 mΩ per conductor | [E1] |
