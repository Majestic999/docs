## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the IR Receiver Module into the breadboard so its pins are in separate rows, facing outward.

- Insert the LED into the breadboard, making sure its two legs sit in separate rows.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the IR Receiver Module

- Connect the **VCC** pin of the receiver to the positive 5V power rail.

- Connect the **GND** pin of the receiver to the negative ground rail.

- Connect the **OUT (Signal)** pin of the receiver to **GPIO 25** on the ESP32 board.

**Step 3:** Wire the LED Indicator

- Connect the **LED's anode (longer leg)** through a 220Ω resistor to **GPIO 27** on the ESP32 board.

- Connect the **LED's cathode (shorter leg)** to the negative ground rail.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Library Inclusion and Pin Definitions

```cpp
// IR Remote LED Controller
// Requires: IRremote Library (Install through ESP32 board Library Manager)

#include <IRremote.hpp>

// Pin definitions
const int receiverPin = 25;
const int ledPin = 27;

// LED state
bool ledState = false;
```
*Explanation:* We include the `IRremote.hpp` library to handle decoding the infrared flashes. We assign `receiverPin` to GPIO 25, and `ledPin` to GPIO 27. The `ledState` boolean keeps track of whether the LED is currently ON or OFF.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);

  // Start IR receiver
  IrReceiver.begin(receiverPin, ENABLE_LED_FEEDBACK);

  // Configure LED pin
  pinMode(ledPin, OUTPUT);

  // Ensure LED starts OFF
  digitalWrite(ledPin, LOW);

  Serial.println("IR Receiver Ready");
  Serial.println("Press any remote button...");
}
```
*Explanation:* We start the Serial Monitor. `IrReceiver.begin(...)` tells the library to start listening on GPIO 25. The `ENABLE_LED_FEEDBACK` argument optionally flashes the board's built-in LED whenever it receives a signal. We then ensure our external LED starts turned OFF.

---

### 3. Main Loop Function

```cpp
void loop() {
  // Check if an IR signal is received
  if (IrReceiver.decode()) {
    // Read received command
    uint8_t code = IrReceiver.decodedIRData.command;

    Serial.print("IR Code: ");
    Serial.println(code, HEX);

    // Toggle LED state
    ledState = !ledState;
    digitalWrite(ledPin, ledState);

    // Prepare receiver for the next signal
    IrReceiver.resume();
  }
}
```
*Explanation:* `IrReceiver.decode()` returns true when a full IR command has been captured. We read the `command` (a unique number for the button pressed) and print it in HEX format.

Then, we toggle the `ledState` (`true` becomes `false`, `false` becomes `true`) and update the LED. Finally, we call `IrReceiver.resume()` so the module knows it can start listening for the next button press.

## CONCLUSION

When any button on the IR remote is pressed, the system receives the IR signal and toggles the LED between ON and OFF states. Each button press is detected by the IR receiver, and the corresponding hexadecimal code is displayed on the Serial Monitor.

The displayed IR codes can be used to program specific buttons to perform different actions, such as controlling multiple LEDs, activating a buzzer, or switching other connected devices.es.
