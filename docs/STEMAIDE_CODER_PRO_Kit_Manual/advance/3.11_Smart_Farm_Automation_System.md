## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the LM35 Temperature Sensor, LDR Module, Green LED, Red LED, and Buzzer onto the breadboard, making sure their pins sit in separate rows.

- The I2C LCD Display and Soil Moisture Sensor connect via female-to-male jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Soil Moisture Sensor

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **Signal/AO** pin to **GPIO 36** on the ESP32 board.

**Step 3:** Wire the LDR Light Sensor Module

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **AO/Signal** pin to **GPIO 39** on the ESP32 board.

**Step 4:** Wire the LM35 Temperature Sensor

- With the flat side facing you, connect the **Left VCC** pin to the positive power rail.

- Connect the **Right GND** pin to the negative power rail.

- Connect the **Middle VOUT/Signal** pin to **GPIO 34** on the ESP32 board.

**Step 5:** Wire the I2C LCD Display

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **SDA** pin to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin to **GPIO 22** on the ESP32 board.

**Step 6:** Wire the LEDs and Buzzer

- Connect the anode (+, longer leg) of the **Green LED** through a 220Ω resistor to **GPIO 4** on the ESP32 board.

- Connect the anode (+, longer leg) of the **Red LED** through a 220Ω resistor to **GPIO 5** on the ESP32 board.

- Connect the positive (+) terminal of the **Buzzer** to **GPIO 18** on the ESP32 board.

- Connect the negative (shorter) legs of the LEDs and the negative (-) terminal of the Buzzer to the negative ground rail.

### 1. Library Inclusion and Pin Definitions

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Pin definitions
const int soilPin = 36;
const int lightPin = 39;
const int tempPin = 34;

const int greenLED = 4;
const int redLED = 5;
const int buzzerPin = 18;
```
*Explanation:* We include the `Wire` and `LiquidCrystal_I2C` libraries to control the display. We define pins for our sensors and output devices. We fixed the LED and Buzzer pins to avoid overlapping with the I2C LCD communication pins (`21` and `22`).

---

### 2. Setup Function

```cpp
void setup() {
  // Initialize LCD
  lcd.init();
  lcd.backlight();

  // Configure output pins
  pinMode(greenLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buzzerPin, OUTPUT);

  // Ensure outputs are OFF initially
  digitalWrite(greenLED, LOW);
  digitalWrite(redLED, LOW);
  digitalWrite(buzzerPin, LOW);

  // Startup message
  lcd.setCursor(0, 0);
  lcd.print("Smart Farm");
  lcd.setCursor(0, 1);
  lcd.print("Monitoring...");
  delay(1500);
  lcd.clear();
}
```
*Explanation:* In `setup()`, the LCD is initialized and its backlight turned on. The output pins are set up, and we make sure the LEDs and Buzzer are initially turned OFF. A nice startup message greets us on the LCD!

---

### 3. Main Loop Function

```cpp
void loop() {
  // Read sensors
  int soil = analogRead(soilPin);
  int light = analogRead(lightPin);
  int tempReading = analogRead(tempPin);

  // Convert LM35 reading to Celsius (ESP32 has 12-bit ADC and 3.3V reference)
  float voltage = tempReading * (3.3 / 4095.0);
  float temperature = voltage * 100.0;

  // Display soil and light readings
  lcd.setCursor(0, 0);
  lcd.print("S:");
  lcd.print(soil);
  lcd.print(" L:");
  lcd.print(light);
  lcd.print("   "); // Clear trailing characters

  // Determine if an alert is required
  bool alert = false;

  if (soil < 300) { // Too dry
    alert = true;
  }
  if (light < 200) { // Too dark
    alert = true;
  }
  if (temperature > 40.0) { // Too hot
    alert = true;
  }

  // Update outputs
  if (alert) {
    digitalWrite(greenLED, LOW);
    digitalWrite(redLED, HIGH);
    digitalWrite(buzzerPin, HIGH);

    lcd.setCursor(0, 1);
    lcd.print("Check Farm!    ");
  } else {
    digitalWrite(greenLED, HIGH);
    digitalWrite(redLED, LOW);
    digitalWrite(buzzerPin, LOW);

    lcd.setCursor(0, 1);
    lcd.print("Farm Healthy   ");
  }

  delay(500); // Wait half a second
}
```
*Explanation:* 

- The loop continuously reads values from the soil, light, and temperature sensors.

- It displays the Soil and Light values on the first row of the LCD.

- The logic determines if the crops need help: `soil < 300` means it needs water, `light < 200` means it needs sun, or `temperature > 40.0` means it's dangerously hot. Note that the temperature value is converted into Celsius using the ESP32's 12-bit ADC logic.

- If any of these are true, the alarm triggers (Red LED on, Buzzer on, "Check Farm!" on LCD). Otherwise, the Farm is Healthy (Green LED on).

## CONCLUSION

When the program is running, the Smart Farm Automation System continuously monitors the soil moisture, light intensity, and temperature. The LCD displays the current sensor readings, while the green LED indicates that environmental conditions are suitable. If the soil becomes too dry, the light level is too low, or the temperature exceeds the preset threshold, the red LED lights up, the buzzer sounds, and the LCD displays a warning message, providing immediate visual and audible feedback that the farm requires attention.
