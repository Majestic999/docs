## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the LM35 Temperature Sensor onto the breadboard, making sure its pins sit in separate rows.

- Insert the Green and Red LEDs onto the breadboard in separate rows.

- Insert the Buzzer onto the breadboard.

- Place the LCD Display near the breadboard (connect it via female-to-male jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires and resistors:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the LM35 Temperature Sensor

- Connect the **VCC** pin of the LM35 to the positive 5V power rail.

- Connect the **GND** pin of the LM35 to the negative ground rail.

- Connect the **OUT** pin of the LM35 to **GPIO 36** on the ESP32 board.

**Step 3:** Wire the I2C LCD Display

- Connect the **VCC** pin of the LCD to the positive 5V power rail.

- Connect the **GND** pin of the LCD to the negative ground rail.

- Connect the **SDA** pin of the LCD to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin of the LCD to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the LEDs and Buzzer

- Connect the anode (+, longer leg) of the **Green LED** to **GPIO 19** on the ESP32 board.

- Connect the anode (+, longer leg) of the **Red LED** to **GPIO 18** on the ESP32 board. *(Do not use 21, it is needed for the LCD!)*

- Connect the cathode (-, shorter leg) of both LEDs through a **220Ω resistor** to the negative ground rail.

- Connect the positive (+) pin of the Buzzer to **GPIO 5** on the ESP32 board. *(Do not use 22, it is needed for the LCD!)*

- Connect the negative (-) pin of the Buzzer to the negative ground rail.

### 1. Library Inclusion and Setup

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

const int tempPin = 36;
const int greenLED = 19;
const int redLED = 18;
const int buzzerPin = 5;

void setup() {
  lcd.init();
  lcd.backlight();

  pinMode(greenLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
}
```
*Explanation:* We include the I2C LCD library and instantiate our `lcd` object. We define the pins for our temperature sensor, LEDs, and buzzer, ensuring we avoid the I2C pins. In `setup()`, we initialize the LCD and configure our LED and buzzer pins as `OUTPUT`.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read LM35 sensor (ESP32 ADC goes up to 4095)
  int sensorValue = analogRead(tempPin);

  // Convert to voltage (ESP32 uses a 3.3V reference for its 12-bit ADC)
  float voltage = sensorValue * (3.3 / 4095.0);

  // Convert voltage to temperature (°C)
  // LM35 outputs 10mV per degree Celsius -> 100 degrees per Volt
  float temperature = voltage * 100.0;

  // Display temperature
  lcd.setCursor(0, 0);
  lcd.print("Temp: ");
  lcd.print(temperature, 1);
  lcd.print((char)223); // Degree symbol
  lcd.print("C  "); // Clear trailing chars

  // Check temperature threshold
  if (temperature < 37.5) {
    digitalWrite(greenLED, HIGH);
    digitalWrite(redLED, LOW);
    digitalWrite(buzzerPin, LOW);

    lcd.setCursor(0, 1);
    lcd.print("Normal        ");
  }
  else {
    digitalWrite(greenLED, LOW);
    digitalWrite(redLED, HIGH);
    digitalWrite(buzzerPin, HIGH);

    lcd.setCursor(0, 1);
    lcd.print("High Temp!    ");
  }

  delay(500);
}
```
*Explanation:* The `loop()` continuously reads the analog value from the LM35 sensor. Because the ESP32 uses a 3.3V reference and a 12-bit ADC (which means values go up to 4095), we multiply the reading by `3.3 / 4095.0` to find the voltage. Since the LM35 outputs 10mV (0.01V) per degree, we multiply the voltage by 100 to get degrees Celsius. If the temperature is below 37.5°C, the green LED indicates everything is normal. If it exceeds 37.5°C, the system raises a "High Temp!" alarm with the red LED and buzzer.

## CONCLUSION

When the program is running, the Smart Hospital Patient Monitoring System continuously measures the patient's temperature and displays the reading on the LCD. If the temperature remains within the normal range, the green LED stays on and the buzzer remains off.
