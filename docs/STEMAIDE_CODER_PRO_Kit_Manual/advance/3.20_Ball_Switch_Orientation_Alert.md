## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Ball Switch (Tilt Sensor) onto the breadboard, making sure its pins sit in separate rows.

- Insert the Buzzer and LED onto the breadboard, taking care to place their legs in separate rows.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Ball Switch

- Connect **Pin 1** of the Ball Switch to **GPIO 2** on the ESP32 board.

- Connect **Pin 2** of the Ball Switch to the negative ground rail.

- Add a **10kΩ pull-up resistor** connecting **GPIO 2** to the positive 5V power rail. (This keeps the signal stable when the switch is open).

**Step 3:** Wire the Alerts (Buzzer and LED)

- Connect the **Buzzer's Positive (+)** pin to **GPIO 22** on the ESP32 board.

- Connect the **Buzzer's Negative (-)** pin to the negative ground rail.

- Connect the **LED's anode (longer leg)** through a 220Ω resistor to **GPIO 27** on the ESP32 board.

- Connect the **LED's cathode (shorter leg)** to the negative ground rail.

### 1. Pin Definitions and Setup

```cpp
// Ball Switch Orientation Alert

// Pin definitions
const int tiltPin = 2;
const int buzzerPin = 22;
const int ledPin = 27;

void setup() {
  Serial.begin(9600);

  // Configure pins
  pinMode(tiltPin, INPUT_PULLUP);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);

  // Initial output state
  digitalWrite(buzzerPin, LOW);
  digitalWrite(ledPin, LOW);

  Serial.println("Orientation Alert Ready");
}
```
*Explanation:* We define pins for the tilt sensor, buzzer, and LED. In `setup()`, we use `INPUT_PULLUP` for the `tiltPin` to utilize the ESP32's internal resistor (though we also added an external 10kΩ one for extra stability). We ensure both the buzzer and LED start turned `LOW` (OFF).

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read the ball switch
  int tiltState = digitalRead(tiltPin);

  // Ball switch closed (tilted)
  if (tiltState == LOW) {
    digitalWrite(buzzerPin, HIGH);
    digitalWrite(ledPin, HIGH);

    Serial.println("ALERT: Tilt detected!");
  }
  // Ball switch open (upright)
  else {
    digitalWrite(buzzerPin, LOW);
    digitalWrite(ledPin, LOW);

    Serial.println("Normal: Upright position.");
  }

  delay(200); // Check repeatedly with a slight delay
}
```
*Explanation:* In the `loop()`, we check the state of the tilt switch. Because it connects to ground, when the conductive ball completes the circuit, the reading is `LOW`. If `tiltState` is `LOW`, we know the sensor is tilted, so we turn ON the LED and Buzzer. If it reads `HIGH` (pulled up by our resistor), it's upright, so we turn them OFF.

## CONCLUSION

When the ball switch is held upright, the switch remains open, causing the LED to stay OFF and the buzzer to remain silent. The Serial Monitor continuously displays the message "Normal: Upright position." to indicate that no tilt has been detected.

When the ball switch is tilted or inverted, the switch closes, causing the LED to turn ON and the buzzer to activate. At the same time, the Serial Monitor displays the message "ALERT: Tilt detected!" to notify the user that the sensor has detected a change in orientation.
