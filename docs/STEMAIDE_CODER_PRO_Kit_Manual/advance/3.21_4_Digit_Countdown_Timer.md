## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the TM1637 4-Digit Display Module onto the breadboard, making sure its 4 pins sit in separate rows.

- Insert the Buzzer onto the breadboard, taking care to place its legs in separate rows.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the TM1637 Display Module

- Connect the **VCC** pin of the display to the positive 5V power rail.

- Connect the **GND** pin of the display to the negative ground rail.

- Connect the **CLK** (clock) pin to **GPIO 19** on the ESP32 board.

- Connect the **DIO** (data) pin to **GPIO 21** on the ESP32 board.
_Note: The TM1637 4-digit display communicates with the ESP32 board using only two signal pins (CLK and DIO), making it a simple and efficient way to display numbers!_

**Step 3:** Wire the Buzzer

- Connect the **Buzzer's Positive (+)** pin to **GPIO 22** on the ESP32 board.

- Connect the **Buzzer's Negative (-)** pin to the negative ground rail.

### 1. Library Inclusion and Pin Definitions

```cpp
// 4-Digit Countdown Timer
// Requires: TM1637Display library

#include <TM1637Display.h>

// Pin definitions
const int clkPin = 19;
const int dioPin = 21;
const int buzzerPin = 22;

// Create display object
TM1637Display display(clkPin, dioPin);

// Starting countdown value
int countdown = 9999;
```
*Explanation:* We include the `TM1637Display.h` library to handle multiplexing the 4-digit screen. We define `clkPin`, `dioPin`, and `buzzerPin`, then initialize the `display` object. The `countdown` variable is set to 9999 to start.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);

  // Set display brightness (0–7)
  display.setBrightness(7);

  // Configure buzzer pin
  pinMode(buzzerPin, OUTPUT);
  digitalWrite(buzzerPin, LOW);

  Serial.println("Countdown Timer Started");
}
```
*Explanation:* We set the display brightness to maximum (7) so it's clearly visible. The buzzer is set as an `OUTPUT` and initially turned `LOW` (OFF).

---

### 3. Main Loop Function

```cpp
void loop() {
  // Continue counting down
  if (countdown >= 0) {
    // Display current value with leading zeros (true)
    display.showNumberDecEx(countdown, 0, true);

    // Print value to Serial Monitor
    Serial.println(countdown);

    countdown--; // Subtract 1 from countdown
    delay(1000); // Wait 1 full second
  }
  // Countdown finished
  else {
    // Sound buzzer three times
    for (int i = 0; i < 3; i++) {
      digitalWrite(buzzerPin, HIGH);
      delay(300);
      digitalWrite(buzzerPin, LOW);
      delay(300);
    }

    // Display 0000
    display.showNumberDecEx(0, 0, true);
    delay(5000); // Wait 5 seconds

    // Restart countdown
    countdown = 9999;
  }
}
```
*Explanation:* 

- The `loop()` continuously checks if `countdown` is greater than or equal to 0. 

- If it is, it shows the number on the display (`showNumberDecEx`), prints it to the Serial Monitor, decrements it by 1, and waits 1 second. 

- When it reaches less than 0, the countdown is over! It loops three times to beep the buzzer, shows `0000` for 5 seconds, and then resets the countdown to `9999`.

## CONCLUSION

When the program starts, the TM1637 4-digit display shows 9999 and begins counting down by one every second. The current countdown value is also displayed in the Serial Monitor.

When the countdown reaches 0000, the active buzzer sounds three short beeps to indicate that the timer has finished. After a brief pause, the countdown automatically resets to 9999 and begins counting down again, repeating the cycle continuously.
