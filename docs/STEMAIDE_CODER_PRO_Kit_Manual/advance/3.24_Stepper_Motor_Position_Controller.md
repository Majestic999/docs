## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Mount the ULN2003 Stepper Motor Driver Board onto the breadboard (or position it closely so you can wire it easily).

- Connect the white plastic connector of the 28BYJ-48 stepper motor directly into the matching socket on the ULN2003 driver board.

Ensure the connector is fully inserted and aligned.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the ULN2003 Driver Board

_Note: The ULN2003 driver board requires 4 signal pins from the ESP32 to pulse the motor's coils in a specific sequence._

- Connect **IN1** on the driver board to **GPIO 22** on the ESP32 board.

- Connect **IN2** on the driver board to **GPIO 23** on the ESP32 board.

- Connect **IN3** on the driver board to **GPIO 33** on the ESP32 board.

- Connect **IN4** on the driver board to **GPIO 25** on the ESP32 board.

- Connect the **VCC** (or +5V) pin of the driver board to the positive 5V power rail.

- Connect the **GND** (or -) pin of the driver board to the negative ground rail.

### 1. Library Inclusion and Motor Configuration

```cpp
// Stepper Motor Position Controller
// Uses a 28BYJ-48 Stepper Motor with ULN2003 Driver Board

#include <Stepper.h>

// Number of steps per revolution for the 28BYJ-48
const int STEPS_PER_REV = 2048;

// Motor speed (RPM)
const int MOTOR_SPEED = 10;

// Create stepper motor object
// Pin order for 28BYJ-48 with ULN2003 is IN1, IN3, IN2, IN4
Stepper myStepper(STEPS_PER_REV, 22, 33, 23, 25);
```
*Explanation:* We include the built-in `Stepper.h` library. We define that our motor takes `2048` steps for a full revolution, and set a safe speed of `10` RPM. We then initialize our `myStepper` object with the 4 control pins, mapping them in the `IN1, IN3, IN2, IN4` order required by the library.

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);

  // Set motor speed
  myStepper.setSpeed(MOTOR_SPEED);

  Serial.println("Stepper Motor Ready");
}
```
*Explanation:* In `setup()`, we initialize the Serial Monitor for debugging and tell the `myStepper` object what speed to operate at using `.setSpeed()`.

---

### 3. Main Loop Function

```cpp
void loop() {
  // Rotate clockwise 1 full revolution
  Serial.println("Rotating clockwise...");
  myStepper.step(STEPS_PER_REV);
  
  delay(1000); // Pause for 1 second

  // Rotate counterclockwise 1 full revolution
  Serial.println("Rotating counterclockwise...");
  myStepper.step(-STEPS_PER_REV);
  
  delay(1000); // Pause for 1 second
}
```
*Explanation:* The `loop()` commands the motor to take `2048` steps forward (one full clockwise revolution) using `.step()`. It waits 1 second, and then steps `-2048` steps backward (one full counterclockwise revolution). The cycle repeats continuously.

## CONCLUSION

When the program starts, the 28BYJ-48 stepper motor rotates one complete revolution clockwise, pauses for 1 second, then rotates one complete revolution counterclockwise before pausing again. This sequence repeats continuously.

The Serial Monitor displays messages indicating the current direction of rotation, such as "Rotating clockwise..." and "Rotating counterclockwise...".

The stepper motor moves smoothly and precisely, stopping at the exact position specified by the program. Unlike a standard DC motor, the stepper motor provides accurate positional control, making it suitable for applications that require precise movement.
