## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Ultrasonic Sensor, RGB Module, and Buzzer onto the breadboard, making sure their pins sit in separate rows.

- Place the Servo Motor nearby, connecting its wires using jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Ultrasonic Sensor

- Connect **VCC** of the Ultrasonic Sensor to the positive power rail.

- Connect **GND** of the Ultrasonic Sensor to the negative power rail.

- Connect the **TRIG** pin to **GPIO 23** on the ESP32 board.

- Connect the **ECHO** pin to **GPIO 33** on the ESP32 board.

**Step 3:** Wire the RGB LED

- Connect the **Red** pin to **GPIO 4** on the ESP32 board.

- Connect the **Green** pin to **GPIO 18** on the ESP32 board.

- Connect the **Blue** pin to **GPIO 25** on the ESP32 board.

- Connect the **GND (-)** pin to the negative power rail.

**Step 4:** Wire the Servo Motor

- Connect **VCC (Red/Brown)** of the Servo Motor to the positive power rail.

- Connect **GND (Black/Brown)** of the Servo Motor to the negative power rail.

- Connect **Signal (Yellow/Orange)** of the Servo Motor to **GPIO 19** on the ESP32 board.

**Step 5:** Wire the Buzzer

- Connect the **Positive (+)** pin of the Buzzer to **GPIO 22** on the ESP32 board.

- Connect the **Negative (-)** pin of the Buzzer to the negative ground rail.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

### 1. Library Inclusion and Pin Definitions

```cpp
#include <ESP32Servo.h>

// Pin Definitions
const int trigPin = 23;
const int echoPin = 33;
const int servoPin = 19;
const int red = 4;
const int green = 18;
const int blue = 25;
const int buzzerPin = 22;

// Objects and Variables
Servo gateServo;
long duration;
int distance;
bool gateOpen = false;
```
*Explanation:* We include the `ESP32Servo` library and define pins for our ultrasonic sensor, RGB LED, servo motor, and buzzer based on the wiring.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(red, OUTPUT);
  pinMode(green, OUTPUT);
  pinMode(blue, OUTPUT);
  pinMode(buzzerPin, OUTPUT);

  gateServo.attach(servoPin);
  gateServo.write(90); // Start with gate closed (horizontal)

  Serial.begin(9600);
}
```
*Explanation:* We initialize the pins as inputs or outputs. The servo is attached and positioned at 90 degrees, which we'll define as the "closed" position for our gate.

---

### 3. Custom Functions

```cpp
int getDistance() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duration = pulseIn(echoPin, HIGH);
  return duration * 0.034 / 2; // Distance in cm
}

void setRGB(int r, int g, int b) {
  analogWrite(red, r);
  analogWrite(green, g);
  analogWrite(blue, b);
}

void soundAlarm(int beeps) {
  for (int i = 0; i < beeps; i++) {
    digitalWrite(buzzerPin, HIGH);
    delay(100);
    digitalWrite(buzzerPin, LOW);
    delay(100);
  }
}
```
*Explanation:* 

- `getDistance()` measures the ultrasonic echo to return a distance in cm.

- `setRGB()` quickly changes the color of the RGB module.

- `soundAlarm(int beeps)` takes a number as input and beeps the buzzer that many times rapidly, useful for warnings!

---

### 4. Main Loop Function

```cpp
void loop() {
  distance = getDistance();

  if (distance > 0 && distance < 20) { 
    // Object detected close to the gate
    if (!gateOpen) {
      gateOpen = true;
      setRGB(255, 255, 0); // Yellow for opening
      soundAlarm(3);       // Warning beeps
      gateServo.write(0);  // Open gate
      setRGB(0, 255, 0);   // Green when fully open
    }
  } else {
    // No object detected
    if (gateOpen) {
      delay(3000); // Wait 3 seconds before closing
      
      setRGB(255, 255, 0); // Yellow for closing
      soundAlarm(3);       // Warning beeps
      gateServo.write(90); // Close gate
      
      gateOpen = false;
    }
    setRGB(255, 0, 0); // Red when fully closed
  }

  delay(200); // Small loop delay
}
```
*Explanation:* 

- The loop constantly checks for objects within 20cm.

- If something approaches, it warns the surroundings (Yellow light + 3 Beeps), opens the gate, and turns the light Green.

- When the object leaves, it waits 3 seconds to be sure, warns the surroundings again (Yellow + 3 Beeps), closes the gate, and turns the light Red.

## OBSERVATION

- Red RGB LED indicates the gate is closed (standby).

- Yellow RGB LED and audible beeps indicate the gate is moving.

- Green RGB LED indicates the gate is open.

- The gate opens automatically when an object approaches. 

- The gate closes automatically after the object leaves.
