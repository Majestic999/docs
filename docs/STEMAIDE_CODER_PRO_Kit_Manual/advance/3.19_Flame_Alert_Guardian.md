# 3.19. Flame Alert Guardian

| **Description** | In this project, learners will build a flame detection system that activates a buzzer and an LED alert when fire or a strong infrared light source is detected. The flame sensor module detects infrared radiation emitted by flames in a detection range of approximately 60 cm. This project introduces environmental safety sensing and threshold-based alerting, which are foundational concepts in fire alarm systems and industrial safety automation.|
|------------------|----------------------------------------------------------------|
| **Use case**     |This project is connected to real-world uses such as: Flame sensors detect infrared radiation from fire. Combined with a buzzer and alarm system, they form the core of fire detection systems used in homes, kitchens, server rooms, and factories.|

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Flame Sensor Module onto the breadboard, making sure its pins sit in separate rows.

- Insert the Buzzer and LED onto the breadboard, taking care to place their legs in separate rows.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Flame Sensor Module

- Connect the **VCC** pin of the Flame Sensor to the 3.3V pin on the ESP32 board (or 3.3V power rail).

- Connect the **GND** pin of the Flame Sensor to the negative ground rail.

- Connect the **A0 (Analog)** pin of the Flame Sensor to **GPIO 36** on the ESP32 board.

- Connect the **D0 (Digital)** pin of the Flame Sensor to **GPIO 21** on the ESP32 board.

**Step 3:** Wire the Alerts (Buzzer and LED)

- Connect the **Buzzer's Positive (+)** pin to **GPIO 22** on the ESP32 board.

- Connect the **Buzzer's Negative (-)** pin to the negative ground rail.

- Connect the **LED's anode (longer leg)** through a 220Ω resistor to **GPIO 27** on the ESP32 board.

- Connect the **LED's cathode (shorter leg)** to the negative ground rail.

### 1. Pin Definitions and Setup

```cpp
// Flame Alert Guardian
const int flameSensorAnalog = 36;
const int flameSensorDigital = 21;
const int buzzerPin = 22;
const int ledPin = 27;

void setup() {
  Serial.begin(9600);
  
  pinMode(flameSensorDigital, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  
  Serial.println("Flame Alert Guardian Ready");
}
```
*Explanation:* We declare our pins: analog/digital for the flame sensor, and outputs for the buzzer and LED. In `setup()`, we initialize the Serial Monitor for debugging and set our input/output pin modes accordingly.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read both analog and digital values from the Flame Sensor
  int analogValue = analogRead(flameSensorAnalog);
  int digitalValue = digitalRead(flameSensorDigital);

  // Print values to Serial Monitor for debugging
  Serial.print("Flame Intensity: ");
  Serial.print(analogValue);
  Serial.print(" | Digital: ");
  Serial.println(digitalValue);

  // The digital pin goes LOW when a flame is detected
  if (digitalValue == LOW) {
    digitalWrite(buzzerPin, HIGH);
    digitalWrite(ledPin, HIGH);
    Serial.println("WARNING: FLAME DETECTED!");
  } else {
    digitalWrite(buzzerPin, LOW);
    digitalWrite(ledPin, LOW);
  }
  
  delay(200); // Check repeatedly with a slight delay
}
```
*Explanation:* In the `loop()`, we read both the exact intensity (analog) and a simple YES/NO threshold (digital). The Flame Sensor outputs a `LOW` logic signal on its D0 pin when it detects fire. If it goes `LOW`, we activate the LED and buzzer and print a warning message. Otherwise, the alerts remain `LOW` (OFF).

## CONCLUSION

Under normal conditions, when no flame is present, the buzzer remains silent and the LED stays OFF. The Serial Monitor continuously displays a high analog value (typically close to 1023), indicating that no flame has been detected.

When a flame, such as from a lighter, is brought close to the sensor, the buzzer activates and the LED turns ON to provide an audible and visual warning. At the same time, the Serial Monitor displays a lower analog value along with the message "WARNING: FLAME DETECTED!", indicating that the sensor has detected the presence of a flame.
