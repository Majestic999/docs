## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Ultrasonic Sensor, Green LED, Yellow LED, Red LED, and Buzzer onto the breadboard, making sure their pins sit in separate rows.

- The I2C LCD Display connects via jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Ultrasonic Sensor

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **Trig** pin to **GPIO 23** on the ESP32 board.

- Connect the **Echo** pin to **GPIO 33** on the ESP32 board.

**Step 3:** Wire the I2C LCD Display

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **SDA** pin to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the LEDs and Buzzer

- Connect the **Green LED's** anode (long leg) through a 220Ω resistor to **GPIO 4** on the ESP32 board.

- Connect the **Yellow LED's** anode (long leg) through a 220Ω resistor to **GPIO 5** on the ESP32 board.

- Connect the **Red LED's** anode (long leg) through a 220Ω resistor to **GPIO 18** on the ESP32 board.

- Connect the **Buzzer's Positive (+)** pin to **GPIO 19** on the ESP32 board.

- Connect the negative (short) legs of the LEDs and the negative (-) pin of the Buzzer to the negative ground rail.

### 1. Library Inclusion and Pin Definitions

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Pin definitions
const int trigPin = 23;
const int echoPin = 33;

const int greenLED = 4;
const int yellowLED = 5;
const int redLED = 18;

const int buzzerPin = 19;
```
*Explanation:* We include the `Wire` and `LiquidCrystal_I2C` libraries to control the display. We initialize the LCD object, and set up our pins for the ultrasonic sensor, the traffic lights (LEDs), and the alarm buzzer. We updated the LED/Buzzer pins to avoid conflict with the I2C pins.

---

### 2. Setup Function

```cpp
void setup() {
  // Initialize LCD
  lcd.init();
  lcd.backlight();

  // Configure pins
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);

  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buzzerPin, OUTPUT);

  // Ensure outputs are OFF initially
  digitalWrite(greenLED, LOW);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  digitalWrite(buzzerPin, LOW);

  // Startup message
  lcd.setCursor(0, 0);
  lcd.print("Traffic System");
  lcd.setCursor(0, 1);
  lcd.print("Starting...");
  delay(1500);
  lcd.clear();
}
```
*Explanation:* In `setup()`, the LCD is initialized and its backlight is turned on. We set the trigger as `OUTPUT`, echo as `INPUT`, and all our LEDs and the buzzer as `OUTPUT`s. We start everything in the `LOW` (off) state.

---

### 3. Main Loop Function

```cpp
void loop() {
  // Send ultrasonic pulse
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Measure echo duration
  long duration = pulseIn(echoPin, HIGH);

  // No object detected
  if (duration == 0) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, LOW);
    digitalWrite(buzzerPin, LOW);

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("No Object");
    lcd.setCursor(0, 1);
    lcd.print("Detected");
    delay(300);
    return; // restart the loop
  }

  // Calculate distance (cm)
  int distance = duration * 0.034 / 2;

  // Display distance
  lcd.setCursor(0, 0);
  lcd.print("Traffic:");
  lcd.print(distance);
  lcd.print("cm   ");

  // Traffic conditions
  if (distance > 30) {
    // Free flow
    digitalWrite(greenLED, HIGH);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, LOW);
    digitalWrite(buzzerPin, LOW);
    
    lcd.setCursor(0, 1);
    lcd.print("Free Flow      ");
  }
  else if (distance > 15) {
    // Moderate congestion
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, HIGH);
    digitalWrite(redLED, LOW);
    digitalWrite(buzzerPin, LOW);
    
    lcd.setCursor(0, 1);
    lcd.print("Moderate       ");
  }
  else {
    // Heavy congestion!
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, HIGH);
    digitalWrite(buzzerPin, HIGH);
    
    lcd.setCursor(0, 1);
    lcd.print("Congestion!    ");
  }

  delay(300);
}
```
*Explanation:* 

- The loop triggers the ultrasonic sensor and measures the echo time.

- If it detects an object, it calculates the distance in cm.

- **Distance > 30cm**: "Free Flow". Green LED turns on.

- **Distance between 15cm and 30cm**: "Moderate". Yellow LED turns on.

- **Distance < 15cm**: "Congestion!". Red LED turns on and the Buzzer sounds an alarm!
