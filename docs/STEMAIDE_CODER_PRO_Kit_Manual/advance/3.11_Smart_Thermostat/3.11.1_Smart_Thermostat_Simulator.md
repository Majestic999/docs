# Project 3.11.1: Smart Thermostat Simulator

| **Description** | Learn how to simulate a smart thermostat using an LDR module, servo motor, RGB LED, and push button. The LDR estimates a heat index based on light intensity, automatically controlling a ventilation flap while the push button provides manual override. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be applied in smart home ventilation systems, automated greenhouse climate control, HVAC demonstrations, classroom simulations, and intelligent environmental monitoring. |

## WIRING THE CIRCUIT

**Step 2:**onnect the 5V pin on the ESP32 board to the positive (+) power rail on the breadboard and the GND pin to the negative (-) power rail. This provides a common power supply for all the components connected to the breadboard.

![Wiring diagram](../../../assets/3.0/Smart_Thermostat/circuit_2.png)

**Step 3:** Connect the LDR Module to the ESP32 board by connecting the VCC pin to the positive (+) power rail on the breadboard, the GND pin to the negative (-) power rail, and the OUT pin to Analog GPIO 36 on the ESP32 board.

![Wiring diagram](../../../assets/3.0/Smart_Thermostat/circuit_3.png)

**Step 4:** Connect the Push Button to the ESP32 board by connecting one terminal of the button to Digital GPIO 2 and the opposite terminal to the GND rail on the breadboard.

![Wiring diagram](../../../assets/3.0/Smart_Thermostat/circuit_4.png)

**Step 5:**Connect the Servo Motor to the ESP32 board by connecting the Red (VCC) wire to the positive (+) power rail on the breadboard, the Brown/Black (GND) wire to the negative (-) power rail, and the Orange/Yellow (Signal) wire to Digital GPIO 23 on the ESP32 board

_Note: If the servo behaves erratically, use an external regulated 5V power supply and connect its ground to the ESP32 board GND._

![Wiring diagram](../../../assets/3.0/Smart_Thermostat/circuit_5.png)

**Step 6:** Connect the RGB LED Module to the ESP32 board by connecting the GND pin to the negative (-) power rail on the breadboard, the Red signal pin to Digital GPIO 4, the Green signal pin to Digital GPIO 18, and the Blue signal pin to Digital GPIO 19.

![Wiring diagram](../../../assets/3.0/Smart_Thermostat/circuit_6.png)

_Make sure to connect the Micro USB cable to the ESP32 board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp

#include <ESP32Servo.h>

Servo ventServo;

// Pin Definitions
const int ldrPin = 36;
const int buttonPin = 2;

const int redPin = 4;
const int greenPin = 18;
const int bluePin = 19;

const int servoPin = 23;

bool manualOverride = false;
bool lastButtonState = HIGH;

void setup() {

  pinMode(buttonPin, INPUT_PULLUP);

  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);

  ventServo.attach(servoPin);

  ventServo.write(0);

  Serial.begin(9600);
}

void loop() {

  bool buttonState = digitalRead(buttonPin);

  // Toggle manual override
  if (lastButtonState == HIGH && buttonState == LOW) {

    manualOverride = !manualOverride;
    delay(200);

  }

  lastButtonState = buttonState;

  if (manualOverride) {

    // Vent fully open
    ventServo.write(90);

    // Purple (Override)
    digitalWrite(redPin, HIGH);
    digitalWrite(greenPin, LOW);
    digitalWrite(bluePin, HIGH);

    Serial.println("Manual Override");

  }
  else {

    int ldrValue = analogRead(ldrPin);

    // Map LDR reading to servo angle
    int servoAngle = map(ldrValue, 0, 4095, 0, 90);

    ventServo.write(servoAngle);

    Serial.print("LDR: ");
    Serial.print(ldrValue);
    Serial.print("  Servo: ");
    Serial.println(servoAngle);

    // Temperature Status

    if (ldrValue < 1400) {

      // Cool
      digitalWrite(redPin, LOW);
      digitalWrite(greenPin, LOW);
      digitalWrite(bluePin, HIGH);

    }
    else if (ldrValue < 2800) {

      // Moderate
      digitalWrite(redPin, LOW);
      digitalWrite(greenPin, HIGH);
      digitalWrite(bluePin, LOW);

    }
    else {

      // Hot
      digitalWrite(redPin, HIGH);
      digitalWrite(greenPin, LOW);
      digitalWrite(bluePin, LOW);

    }

  }

  delay(100);
}
```

## CONCLUSION

This project demonstrates how sensor inputs, actuator control, and manual user interaction can be combined to create a simple smart thermostat simulator.
