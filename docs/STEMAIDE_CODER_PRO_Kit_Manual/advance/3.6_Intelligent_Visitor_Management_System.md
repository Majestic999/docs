## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the MFRC522 RFID Reader and the PIR Motion Sensor onto the breadboard, making sure their pins sit in separate rows.

- Insert the Buzzer onto the breadboard.

- Place the LCD Display near the breadboard (connect it via female-to-male jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the PIR Motion Sensor & Buzzer

- Connect the **VCC** pin of the PIR Motion Sensor to the positive 5V power rail.

- Connect the **GND** pin of the PIR Motion Sensor to the negative ground rail.

- Connect the **OUT** pin of the PIR Motion Sensor to **GPIO 2** on the ESP32 board.

- Connect the positive (+) pin of the Buzzer to **GPIO 13** on the ESP32 board.

- Connect the negative (-) pin of the Buzzer to the negative ground rail.

**Step 3:** Wire the LCD Display

- Connect the **VCC** pin of the LCD to the positive 5V power rail.

- Connect the **GND** pin of the LCD to the negative ground rail.

- Connect the **SDA** pin of the LCD to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin of the LCD to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the MFRC522 RFID Reader (SPI)

_Note: The RFID Reader communicates using the SPI protocol, so it must connect to the ESP32's default VSPI pins. It runs on 3.3V, DO NOT plug it into 5V!_

- Connect the **3.3V** pin of the RFID reader to the **3.3V** pin on the ESP32 board.

- Connect the **GND** pin of the RFID reader to the negative ground rail.

- Connect the **RST** pin of the RFID reader to **GPIO 4**.

- Connect the **SDA (SS)** pin of the RFID reader to **GPIO 5**.

- Connect the **MOSI** pin of the RFID reader to **GPIO 23**.

- Connect the **MISO** pin of the RFID reader to **GPIO 19**.

- Connect the **SCK** pin of the RFID reader to **GPIO 18**.

### 1. Library Inclusion and Setup

```cpp
#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// --- Pin Definitions based on Step-by-Step Wiring ---
const int PIR_PIN = 2;       // PIR Motion Sensor
const int BUZZER_PIN = 13;   // Buzzer

// MFRC522 RFID SPI Pin Definitions (Standard ESP32 VSPI)
#define SS_PIN 5
#define RST_PIN 4
// SCK=18, MISO=19, MOSI=23 are handled automatically by SPI.begin()

// --- Component Initialization ---
MFRC522 rfid(SS_PIN, RST_PIN);
LiquidCrystal_I2C lcd(0x27, 16, 2); 

// Registered/Authorized RFID Card UID (Replace with your card's UID!)
byte authorizedUID[4] = {0xDE, 0xAD, 0xBE, 0xEF};

void setup() {
  Serial.begin(9600);
  
  // Pin Modes
  pinMode(PIR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  digitalWrite(BUZZER_PIN, LOW);

  // Initialize I2C LCD
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("System Ready");
  
  // Initialize SPI Bus & MFRC522 RFID Reader
  SPI.begin();
  rfid.PCD_Init();

  delay(2000);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Scan Card/Motion");
}
```
*Explanation:* We include libraries for both SPI (RFID) and I2C (LCD). We define our component pins carefully, noting that the RFID reader relies on standard VSPI hardware pins. Inside `setup()`, we initialize the LCD, the SPI bus, and the RFID reader, and we set our buzzer and motion pins to the appropriate modes. You can replace the `authorizedUID` array with your specific card's UID.

### 2. Main Loop and Helper Function

```cpp
void loop() {
  // --- 1. Motion Detection (PIR Sensor) ---
  int motionDetected = digitalRead(PIR_PIN);
  if (motionDetected == HIGH) {
    lcd.setCursor(0, 1);
    lcd.print("Motion Detected!");
  } else {
    lcd.setCursor(0, 1);
    lcd.print("               "); // Clear line
  }

  // --- 2. RFID Reader Check ---
  if (rfid.PICC_IsNewCardPresent() && rfid.PICC_ReadCardSerial()) {
    lcd.clear();
    
    // Compare scanned card UID with authorized UID
    if (isAuthorized(rfid.uid.uidByte, rfid.uid.size)) {
      // Access Granted
      lcd.setCursor(0, 0);
      lcd.print("Visitor Approved");
      lcd.setCursor(0, 1);
      lcd.print("Welcome");
      
      // Short high pitch tone for approval
      tone(BUZZER_PIN, 1000, 200); 
    } else {
      // Access Denied
      lcd.setCursor(0, 0);
      lcd.print("Unauthorized");
      lcd.setCursor(0, 1);
      lcd.print("Alert Active");
      
      // Alarm tone for unauthorized access
      for (int i = 0; i < 3; i++) {
        digitalWrite(BUZZER_PIN, HIGH);
        delay(150);
        digitalWrite(BUZZER_PIN, LOW);
        delay(150);
      }
    }

    // Halt PICC & Stop Encryption on PCD
    rfid.PICC_HaltA();
    rfid.PCD_StopCrypto1();

    delay(2500); // Give the user time to read the screen
    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Scan Card/Motion");
  }

  delay(100);
}

// Helper function to match UID
bool isAuthorized(byte *scannedUID, byte size) {
  if (size != 4) return false;
  for (byte i = 0; i < size; i++) {
    if (scannedUID[i] != authorizedUID[i]) {
      return false; // Mismatch found
    }
  }
  return true; // Fully matched
}
```
*Explanation:* In the `loop()`, we continuously check if the PIR sensor detects movement, alerting the user on the second line of the LCD. We also check if a new RFID card is presented. If one is, we read it and pass the data to our `isAuthorized()` helper function. If it matches our secret UID, we grant access and sound a brief tone. If not, we print "Unauthorized" and trigger an alarm loop with the buzzer.
