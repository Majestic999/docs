# Project 3.2.1: SMART CAR PARKING SYSTEM 

| **Description** | This project demonstrates a smart car parking system using an ultrasonic sensor, RGB, a servo motor, and an ESP32 board. The ultrasonic sensor detects approaching vehicles and checks parking space availability, the LEDs indicate the parking status, and the servo motor automatically controls the opening and closing of the parking gate.  |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project can be used in automated parking lots where the system detects incoming vehicles, shows available parking spaces using RGB, and automatically opens or closes the gate using a servo motor for controlled access. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Ultrasonic Sensor into the breadboard. 

- Place the RGB light module beside it, ensuring all the pins are properly inserted and firmly connected.

- Place the Servo Motor nearby, connecting its wires using jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the RGB Module

- Connect the **Red** pin to **GPIO 23** on the ESP32 board.

- Connect the **Green** pin to **GPIO 33** on the ESP32 board.

- Connect the **Blue** pin to **GPIO 25** on the ESP32 board.

- Connect the **GND (-)** pin to the negative power rail.

**Step 3:** Wire the Servo Motor

- Connect **VCC (Red/Brown)** of the Servo Motor to the positive power rail.

- Connect **GND (Black/Brown)** of the Servo Motor to the negative power rail.

- Connect **Signal (Yellow/Orange)** of the Servo Motor to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the Ultrasonic Sensor

- Connect **VCC** of the Ultrasonic Sensor to the positive power rail.

- Connect **GND** of the Ultrasonic Sensor to the negative power rail.

- Connect **TRIG** of the Ultrasonic Sensor to **GPIO 19** on the ESP32 board.

- Connect **ECHO** of the Ultrasonic Sensor to **GPIO 21** on the ESP32 board.

## PROGRAMMING

### 1. Library Inclusion and Pin Definitions

```cpp
#include <ESP32Servo.h>

// Pin Definitions
const int trigPin = 19;
const int echoPin = 21;
const int servoPin = 22;
const int red = 23;
const int green = 33;
const int blue = 25;

// Objects and Variables
Servo barrierServo;
long duration;
int distance;
bool parkingAvailable = true;
```
*Explanation:* We include the `ESP32Servo` library and define pins for the ultrasonic sensor, servo, and RGB LED. We also create tracking variables like `parkingAvailable` to store the state of the parking spot.

---

### 2. Setup Function

```cpp
void setup() {
  // Pin Modes
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(red, OUTPUT);
  pinMode(green, OUTPUT);
  pinMode(blue, OUTPUT);

  // Initialize Servo
  barrierServo.attach(servoPin);
  barrierServo.write(90); // Barrier closed position

  Serial.begin(9600); // For debugging
}
```
*Explanation:* Initializes the ultrasonic trigger as an output and echo as an input. The RGB pins are outputs. The servo is attached and moved to its default closed position of 90 degrees.

---

### 3. Custom Functions

```cpp
// Function to get distance from ultrasonic sensor
int getDistance() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duration = pulseIn(echoPin, HIGH);
  return duration * 0.034 / 2; // Convert to cm
}

// Function to signal parking status
void signalParkingStatus(bool available) {
  if (available) {
    // Green LED for available parking
    analogWrite(red, 0);
    analogWrite(green, 255);
    analogWrite(blue, 0);
  } else {
    // Red LED for occupied parking
    analogWrite(red, 255);
    analogWrite(green, 0);
    analogWrite(blue, 0);
  }
}
```
*Explanation:* `getDistance()` sends an ultrasonic pulse and calculates the distance to the nearest object in centimeters. `signalParkingStatus()` sets the RGB color: green if parking is available, and red if it's occupied.

---

### 4. Main Loop Function

```cpp
void loop() {
  // Get distance from ultrasonic sensor
  distance = getDistance();

  if (parkingAvailable) {
    if (distance > 0 && distance < 20) { // Car detected close to the gate
      parkingAvailable = false;
      signalParkingStatus(false);
      barrierServo.write(0); // Open barrier
      
      delay(5000); // Wait for the car to park
      
      barrierServo.write(90); // Close barrier
    } else {
      signalParkingStatus(true);
    }
  } else {
    signalParkingStatus(false);
  }

  delay(200); // Loop delay
}
```
*Explanation:* 

- The loop constantly measures distance.

- If parking is available and a car approaches (distance < 20cm), it marks the spot as occupied (`parkingAvailable = false`), turns the light red, opens the gate, waits 5 seconds for the car to enter, and closes the gate.

- *Note:* In a real system, there would be another sensor inside the parking spot to detect when the car leaves, resetting `parkingAvailable` to true!
