# 3.29. Colour Sensor Object Identifier

| **Description** | In this project, learners will use a TCS34725 colour sensor module to detect and identify the colour of objects placed in front of it. The sensor reads the red, green, and blue components of reflected light and reports them as frequency values, which the ESP32 board converts into RGB colour data. This project introduces optical colour sensing — used in industrial quality control, paint mixing machines, food sorting systems, and colour-guided robots.|
|------------------|----------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as: Colour sensors are used in industrial sorting lines, paint mixing systems, quality inspection equipment, and colour-tracking robots. Calibration against known colour targets improves accuracy significantly.|

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the TCS34725 Colour Sensor Module onto the breadboard, making sure its pins sit in separate rows. (Alternatively, connect it directly using female-to-male jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **3.3V** pin on the ESP32 board to the positive (red) rail on the breadboard (The TCS34725 runs on 3.3V logic!).

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the TCS34725 Colour Sensor

_Note: The TCS34725 communicates using the standard I2C protocol, so we will use the ESP32's default I2C pins._

- Connect the **VIN** pin of the sensor to the positive 3.3V power rail.

- Connect the **GND** pin of the sensor to the negative ground rail.

- Connect the **SDA** (Data) pin of the sensor to **GPIO 21** on the ESP32 board.

- Connect the **SCL** (Clock) pin of the sensor to **GPIO 22** on the ESP32 board.

### 1. Library Inclusion and Setup

```cpp
// TCS34725 Colour Sensor
// Requires: Adafruit TCS34725 library

#include <Wire.h>
#include "Adafruit_TCS34725.h"

// Create TCS34725 sensor object
Adafruit_TCS34725 tcs(
  TCS34725_INTEGRATIONTIME_50MS,
  TCS34725_GAIN_4X
);

void setup() {
  Serial.begin(9600);
  Serial.println("TCS34725 Colour Sensor");
  Serial.println("----------------------");

  // Initialize the colour sensor
  if (tcs.begin()) {
    Serial.println("Colour sensor detected successfully.");
  } else {
    Serial.println("ERROR: TCS34725 not found.");
    Serial.println("Check the SDA, SCL, VIN and GND connections.");
    while (1); // Stop the program if the sensor is not detected
  }
}
```
*Explanation:* We include the `Adafruit_TCS34725` library and create a sensor object `tcs`. We configure it with an integration time of 50ms and a gain of 4x to capture enough light. In `setup()`, we start the sensor using `tcs.begin()`.

---

### 2. Main Loop Function

```cpp
void loop() {
  uint16_t red, green, blue, clear;

  // Read raw colour data
  tcs.getRawData(&red, &green, &blue, &clear);

  // Display the raw readings
  Serial.print("R: "); Serial.print(red);
  Serial.print(" | G: "); Serial.print(green);
  Serial.print(" | B: "); Serial.print(blue);
  Serial.print(" | C: "); Serial.print(clear);
  Serial.print(" ==> ");

  // Very basic color identification logic based on dominant values
  if (clear < 100) {
    Serial.println("Detected: BLACK");
  } 
  else if (clear > 2000) {
    Serial.println("Detected: WHITE");
  } 
  else if (red > green && red > blue) {
    Serial.println("Detected: RED");
  } 
  else if (green > red && green > blue) {
    Serial.println("Detected: GREEN");
  } 
  else if (blue > red && blue > green) {
    Serial.println("Detected: BLUE");
  } 
  else {
    Serial.println("Detected: UNKNOWN");
  }

  delay(500); // Wait half a second before reading again
}
```
*Explanation:* In the `loop()`, we retrieve the red, green, blue, and clear (brightness) values from the sensor. We then print these values and use a basic `if/else` block to determine the most dominant color. If the clear value is very low, it's black; if it's very high, it's white. Otherwise, whichever color channel (R, G, or B) has the highest number is determined to be the detected color!

## CONCLUSION

When a red object is placed in front of the sensor, the red reading is highest and the system displays “Detected: RED.”

When a green object is placed in front of the sensor, the green reading is highest and the system displays “Detected: GREEN.”

When a blue object is placed in front of the sensor, the blue reading is highest and the system displays “Detected: BLUE.”

When a white object is placed in front of the sensor, the RGB readings are high and similar, and the system displays “Detected: WHITE.”

When a black object is placed in front of the sensor, the RGB readings are low, and the system displays “Detected: BLACK.”
