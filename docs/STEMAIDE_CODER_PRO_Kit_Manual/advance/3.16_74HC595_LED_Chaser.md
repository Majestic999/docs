# 3.16. 74HC595 LED Chaser

| **Description** | In this project, learners will use a 74HC595 shift register to control eight LEDs in a chasing sequence using only three ESP32 board pins. This project introduces the concept of serial-to-parallel data output and pin expansion, which is essential when a project requires more output devices than the ESP32 board has available pins. Learners will discover how data is shifted out bit by bit to control all eight LED outputs, and how this technique scales in real embedded systems designs.|
|------------------|----------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as: The 74HC595 shift register allows one ESP32 board to control far more outputs than its physical pins. This technique is used in LED matrices, multiplexed displays, and industrial control panels. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the 74HC595 Shift Register across the center dividing ridge of the breadboard (be careful of the notch, which indicates Pin 1).

- Place all 8 LEDs in a row on the breadboard, making sure their pins sit in separate rows.

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the 74HC595 Control Pins to the ESP32

- Connect **Pin 14 (DS / Serial Data Input)** of the 74HC595 to **GPIO 25** on the ESP32 board.

- Connect **Pin 12 (ST_CP / Latch Clock)** of the 74HC595 to **GPIO 22** on the ESP32 board.

- Connect **Pin 11 (SH_CP / Shift Clock)** of the 74HC595 to **GPIO 26** on the ESP32 board.

**Step 3:** Wire the 74HC595 Power & Config Pins

- Connect **Pin 16 (VCC)** of the 74HC595 to the positive 5V power rail.

- Connect **Pin 8 (GND)** of the 74HC595 to the negative ground rail.

- Connect **Pin 10 (SRCLR / Master Reset)** of the 74HC595 to the positive 5V power rail (keeps the chip active).

- Connect **Pin 13 (OE / Output Enable)** of the 74HC595 to the negative ground rail (enables the output pins).

**Step 4:** Wire the LEDs to the 74HC595 Outputs

- Connect **Pin 15 (Q0)** of the 74HC595 through a 220Ω resistor to the **1st LED's anode (+)**.

- Connect **Pin 1 (Q1)** through a 220Ω resistor to the **2nd LED's anode (+)**.

- Connect **Pin 2 (Q2)** through a 220Ω resistor to the **3rd LED's anode (+)**.

- Connect **Pin 3 (Q3)** through a 220Ω resistor to the **4th LED's anode (+)**.

- Connect **Pin 4 (Q4)** through a 220Ω resistor to the **5th LED's anode (+)**.

- Connect **Pin 5 (Q5)** through a 220Ω resistor to the **6th LED's anode (+)**.

- Connect **Pin 6 (Q6)** through a 220Ω resistor to the **7th LED's anode (+)**.

- Connect **Pin 7 (Q7)** through a 220Ω resistor to the **8th LED's anode (+)**.

- Connect all LED cathodes (-) to the negative ground rail.

### 1. Pin Definitions and Setup

```cpp
// 74HC595 Shift Register — LED Chaser
int dataPin = 25;   // DS: Serial Data
int latchPin = 22;  // ST_CP: Latch
int clockPin = 26;  // SH_CP: Shift Clock

void setup() {
  // Configure the 3 control pins as outputs
  pinMode(dataPin, OUTPUT);
  pinMode(latchPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
}
```
*Explanation:* We define the three pins required to communicate with the shift register: Data (`dataPin`), Latch (`latchPin`), and Clock (`clockPin`). In `setup()`, they are all configured as `OUTPUT`s. The ESP32 will use these 3 pins to push out data that controls 8 LEDs!

---

### 2. Main Loop Function

```cpp
void loop() {
  // Chase from LED 0 to LED 7
  for (int i = 0; i < 8; i++) {
    byte pattern = (1 << i); // Shift 1 bit left
    
    digitalWrite(latchPin, LOW); // Prepare to send data
    shiftOut(dataPin, clockPin, MSBFIRST, pattern); // Send the byte
    digitalWrite(latchPin, HIGH); // Lock the data into the outputs
    
    delay(100);
  }
  
  // Chase from LED 7 back to LED 0
  for (int i = 7; i >= 0; i--) {
    byte pattern = (1 << i);
    
    digitalWrite(latchPin, LOW);
    shiftOut(dataPin, clockPin, MSBFIRST, pattern);
    digitalWrite(latchPin, HIGH);
    
    delay(100);
  }
}
```
*Explanation:* 

- A shift register works by pushing data out serially. `shiftOut()` sends 8 bits of data (`pattern`) to the register, and toggling the `latchPin` from `LOW` to `HIGH` moves that data to the actual output pins.

- The `for` loop cycles `i` from `0` to `7`. `(1 << i)` creates a binary pattern where only one bit is `1` (e.g., `00000001`, `00000010`, `00000100`). This turns on exactly one LED at a time.

- The first loop sweeps the LED from left to right. The second loop sweeps it from right to left!

## CONCLUSION

When the program starts, the 8 LEDs connected through the 74HC595 shift register begin a continuous chasing pattern.

The LEDs illuminate one at a time in sequence from LED 0 to LED 7, creating a moving light effect. After reaching LED 7, the pattern reverses direction and the LEDs light up from LED 7 back to LED 0.
The sequence repeats continuously, creating a back-and-forth LED chasing animation. The speed of the animation can be adjusted by changing the `delay(100)` value in the program. A smaller delay value makes the LED chase faster, while a larger delay value slows down the movement.
