# 3.27. DC Motor Speed Controller

| **Description** | In this project, learners will control the speed and direction of a DC motor using a potentiometer and the L298N motor driver module. The motor speed is set by turning the potentiometer, while two buttons or fixed logic control the direction. This project introduces PWM-based motor speed control and H-bridge motor driver operation — the core of electric vehicle speed controllers, robotic drive systems, and fan speed controllers.|

| **Use case**     | This project is connected to real-world uses such as: PWM-based speed control is used in electric vehicles, drone motors, conveyor belts, and computer cooling fans. The L298N H-bridge allows both speed and direction control from a single driver module.|

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Potentiometer onto the breadboard.

- Place the L298N Motor Driver and DC Motor next to your breadboard (they are too large to mount directly on the breadboard).

- Attach the fan blade securely to the DC motor shaft.

Ensure the motor wires cannot touch the rotating fan blade!

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Wire the Motor to the Driver

- Connect the two wires of the DC Motor to the **Motor A Output** screw terminals on the L298N driver board (labelled `OUT1` and `OUT2` or `A+` and `A-`).

**Step 2:** Wire the Power Supply (9V Battery)

_Note: Motors draw too much current to be powered directly from the ESP32. We must use an external battery._

- Connect the positive (red) wire from the 9V battery snap to the **12V power input** screw terminal on the L298N driver board.

- Connect the negative (black) wire from the 9V battery snap to the **GND** screw terminal on the L298N driver board.

- *CRITICAL:* Connect a jumper wire from the **GND** terminal on the L298N driver board to a **GND** pin on the ESP32 board. They MUST share a common ground!

**Step 3:** Wire the L298N Control Pins to the ESP32

- Connect **IN1** on the L298N driver to **GPIO 21** on the ESP32 board. (Controls direction 1)

- Connect **IN2** on the L298N driver to **GPIO 22** on the ESP32 board. (Controls direction 2)

- Remove the jumper cap from **ENA** on the L298N driver.

Connect **ENA** to **GPIO 23** on the ESP32 board. (This PWM pin will control the speed).

**Step 4:** Wire the Potentiometer

- Connect one outer pin of the Potentiometer to the the **3.3V pin** on the ESP32 board or **VIN** pin on the ESP32.

- Connect the other outer pin of the Potentiometer to a **GND** pin on the ESP32.

- Connect the middle pin (wiper) of the Potentiometer to **GPIO 36**.

### 1. Pin Definitions and Setup

```cpp
// DC Motor Speed Controller
// Uses a potentiometer to control the motor speed
// through an L298N motor driver.

const int enablePin = 23;  // ENA - PWM speed control
const int in1Pin = 21;     // IN1 - Direction control
const int in2Pin = 22;     // IN2 - Direction control
const int potPin = 36;     // Potentiometer wiper

void setup() {
  Serial.begin(9600);

  // Configure motor control pins
  pinMode(enablePin, OUTPUT);
  pinMode(in1Pin, OUTPUT);
  pinMode(in2Pin, OUTPUT);

  // Set the motor direction to forward
  // (Setting IN1 to HIGH and IN2 to LOW moves it one way)
  digitalWrite(in1Pin, HIGH);
  digitalWrite(in2Pin, LOW);

  // Start with the motor stopped (0 speed)
  analogWrite(enablePin, 0);

  Serial.println("DC Motor Speed Controller Ready");
  Serial.println("Turn the potentiometer to control motor speed.");
}
```
*Explanation:* We declare our three motor driver control pins (ENA, IN1, IN2) and the potentiometer input pin. In `setup()`, we set the control pins as outputs. By writing `HIGH` to IN1 and `LOW` to IN2, we set a fixed forward direction. We then initialize the motor speed to 0.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read the potentiometer
  // ESP32 analogRead returns a value from 0 to 4095
  int potValue = analogRead(potPin);

  // Convert the 0-4095 analog reading to the 0-255 PWM range
  int motorSpeed = map(potValue, 0, 4095, 0, 255);

  // Apply the PWM speed to the L298N ENA pin
  analogWrite(enablePin, motorSpeed);

  // Display values in Serial Monitor
  Serial.print("Potentiometer: ");
  Serial.print(potValue);
  Serial.print(" | Motor PWM: ");
  Serial.println(motorSpeed);

  delay(100);
}
```
*Explanation:* The `loop()` continuously reads the potentiometer value. The ESP32 gives a reading between `0` and `4095`. However, the `analogWrite` command expects a speed value between `0` and `255`. We use the `map()` function to convert the scale perfectly! We then write that new speed to the `enablePin` (ENA).

## CONCLUSION

When the potentiometer is turned to the left, the DC motor gradually slows down. As the potentiometer is turned to the right, the motor gradually increases its speed.

At the minimum potentiometer position, the motor stops completely. At the maximum position, the motor runs at full speed.

The Serial Monitor continuously displays the potentiometer reading and its corresponding PWM speed value, allowing the user to observe how the potentiometer controls the motor speed.
