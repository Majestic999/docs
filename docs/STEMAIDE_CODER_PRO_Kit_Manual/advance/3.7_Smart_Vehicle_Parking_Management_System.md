## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Ultrasonic Sensor onto the breadboard, making sure its pins sit in separate rows.

- Insert the Buzzer onto the breadboard.

- Place the LCD Display and Servo Motor near the breadboard (connect them via jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the I2C LCD Display

- Connect the **VCC** pin of the LCD to the positive 5V power rail.

- Connect the **GND** pin of the LCD to the negative ground rail.

- Connect the **SDA** pin of the LCD to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin of the LCD to **GPIO 22** on the ESP32 board.

**Step 3:** Wire the Ultrasonic Sensor

- Connect the **VCC** pin of the Ultrasonic Sensor to the positive 5V power rail.

- Connect the **GND** pin of the Ultrasonic Sensor to the negative ground rail.

- Connect the **Trig** pin of the Ultrasonic Sensor to **GPIO 23** on the ESP32 board.

- Connect the **Echo** pin of the Ultrasonic Sensor to **GPIO 33** on the ESP32 board.

**Step 4:** Wire the Servo Motor & Buzzer

- Connect the **VCC** (Red) wire of the Servo to the positive 5V power rail.

- Connect the **GND** (Brown/Black) wire of the Servo to the negative ground rail.

- Connect the **Signal** (Orange/Yellow) wire of the Servo to **GPIO 19** on the ESP32 board.

- Connect the positive (+) pin of the Buzzer to **GPIO 18** on the ESP32 board. *(Do not use 22, it is needed for the LCD!)*

- Connect the negative (-) pin of the Buzzer to the negative ground rail.

### 1. Library Inclusion and Setup

```cpp
#include <ESP32Servo.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Create servo object
Servo gateServo;

// Pin definitions
const int trigPin = 23;
const int echoPin = 33;
const int buzzerPin = 18;
const int servoPin = 19;

void setup() {
  // Initialize LCD
  lcd.init();
  lcd.backlight();
  
  // Configure pins
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  
  // Attach servo to GPIO 19
  gateServo.attach(servoPin);
  
  // Keep gate closed initially
  gateServo.write(0);
}
```
*Explanation:* We include libraries for the Servo and the I2C LCD. After defining our pins, we use `setup()` to configure our input and output modes. We attach our `gateServo` object to `servoPin` (GPIO 19) and instruct it to start at 0 degrees (gate closed).

---

### 2. Main Loop Function

```cpp
void loop() {
  // 1. Generate ultrasonic pulse
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 2. Read distance
  long duration = pulseIn(echoPin, HIGH);
  int distance = duration * 0.034 / 2;
  
  // 3. Display distance
  lcd.setCursor(0, 0);
  lcd.print("Vehicle: ");
  lcd.print(distance);
  lcd.print("cm   "); // Clear trailing characters

  // 4. Vehicle detected logic
  if (distance < 15) {
    lcd.setCursor(0, 1);
    lcd.print("Gate Opening    ");
    
    // Open gate
    gateServo.write(90);
    delay(3000); // Keep gate open for 3 seconds
    
    // Close gate
    gateServo.write(0);
  } 
  else {
    lcd.setCursor(0, 1);
    lcd.print("Waiting...      ");
  }
  
  delay(200);
}
```
*Explanation:* The `loop()` repeatedly pulses the ultrasonic sensor to check if a vehicle has arrived. It displays the detected distance on the LCD. If a vehicle approaches within 15 cm, the LCD updates to "Gate Opening", and the servo moves to 90 degrees to lift the parking gate! It waits for 3 seconds before automatically dropping the gate back to 0 degrees.
