## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the HC-05 Bluetooth Module onto the breadboard, making sure its pins sit in separate rows.

- Insert the LED onto the breadboard.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires and resistors:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the LED

- Connect the anode (+, longer leg) of the LED through a **220Ω resistor** to **GPIO 27** on the ESP32 board.

- Connect the cathode (-, shorter leg) of the LED to the negative ground rail.

**Step 3:** Wire the HC-05 Bluetooth Module

_Note: The HC-05 RXD pin expects 3.3V logic. Connecting it directly to a 5V signal can damage it, which is why a voltage divider (1kΩ and 2kΩ resistors) is recommended if your board uses 5V logic. (The ESP32 uses 3.3V logic naturally, so you can technically connect it directly, but following the divider is safer if you switch microcontrollers)._

- Connect the **VCC** pin of the HC-05 to the positive 5V power rail.

- Connect the **GND** pin of the HC-05 to the negative ground rail.

- Connect the **TXD** pin of the HC-05 to **GPIO 33** on the ESP32 board (This is our Software RX pin).

- Connect the **RXD** pin of the HC-05 to **GPIO 25** on the ESP32 board (This is our Software TX pin).

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the code in sections as detailed below.

### 1. Library Inclusion and Setup

```cpp
// Bluetooth LED Controller (HC-05)
// Requires: EspSoftwareSerial Library for ESP32

#include <SoftwareSerial.h>

// Initialize SoftwareSerial on GPIO 33 (RX) and GPIO 25 (TX)
SoftwareSerial bluetooth(33, 25); 

int ledPin = 27;

void setup() {
  Serial.begin(9600);     // USB Serial Monitor
  bluetooth.begin(9600);  // HC-05 default baud rate is usually 9600

  pinMode(ledPin, OUTPUT);
  
  Serial.println("Bluetooth LED Controller Ready");
  Serial.println("Send '1' to turn LED ON, '0' to turn LED OFF.");
}
```
*Explanation:* We use the `SoftwareSerial` library to create a secondary serial communication port specifically for the Bluetooth module on pins 33 (RX) and 25 (TX). We initialize both the standard USB Serial (to print messages to our computer) and the Bluetooth serial.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Check if the Bluetooth module has received any data from the phone
  if (bluetooth.available()) {
    
    // Read the incoming character
    char cmd = bluetooth.read();
    
    Serial.print("Received: ");
    Serial.println(cmd);

    // If the phone sent a '1', turn the LED on
    if (cmd == '1') {
      digitalWrite(ledPin, HIGH);
      bluetooth.println("LED ON"); // Send a message back to the phone
      Serial.println("LED ON");    // Send a message to the PC Monitor
    } 
    // If the phone sent a '0', turn the LED off
    else if (cmd == '0') {
      digitalWrite(ledPin, LOW);
      bluetooth.println("LED OFF");
      Serial.println("LED OFF");
    }
  }
}
```
*Explanation:* In the `loop()`, we constantly check if data has arrived from the Bluetooth module using `bluetooth.available()`. If it has, we read the character. If it's a `'1'`, we turn the LED `HIGH`. If it's a `'0'`, we turn the LED `LOW`. We also print a status message back to both the computer and the smartphone!

## CONCLUSION

After pairing the smartphone with the HC-05 Bluetooth module using the default PIN (usually `1234` or `0000`), open a Bluetooth serial terminal application on your phone.

When `1` is sent from the smartphone, the ESP32 board turns the LED ON, and the message “LED ON” is displayed on both your phone and computer. When `0` is sent, the ESP32 board turns the LED OFF, and the message “LED OFF” is displayed.

This demonstrates wireless control of an ESP32 board output using Bluetooth communication.
