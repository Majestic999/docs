## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the LM35 Temperature Sensor, Green LED, Red LED, and Buzzer onto the breadboard, making sure their pins sit in separate rows.

- The I2C LCD Display and Water Level Sensor connect via female-to-male jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Water Level Sensor

- Connect the **VCC (+)** pin to the positive power rail.

- Connect the **GND (-)** pin to the negative power rail.

- Connect the **Signal (S)** pin to **GPIO 36** on the ESP32 board.

**Step 3:** Wire the LM35 Temperature Sensor

- With the flat side facing you, connect the **Left Pin (VCC)** to the positive power rail.

- Connect the **Right Pin (GND)** to the negative power rail.

- Connect the **Middle Pin (VOUT)** to **GPIO 39** on the ESP32 board.

**Step 4:** Wire the I2C LCD Display

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **SDA** pin to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin to **GPIO 22** on the ESP32 board.

**Step 5:** Wire the LEDs and Buzzer

- Connect the anode (+, longer leg) of the **Green LED** through a 220Ω resistor to **GPIO 4** on the ESP32 board.

- Connect the anode (+, longer leg) of the **Red LED** through a 220Ω resistor to **GPIO 5** on the ESP32 board.

- Connect the positive (+) pin of the **Buzzer** to **GPIO 18** on the ESP32 board.

- Connect the negative (shorter) pins of the LEDs and the negative (-) pin of the Buzzer to the negative ground rail.

### 1. Library Inclusion and Pin Definitions

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Sensor pins
const int waterPin = 36;
const int tempPin = 39;

// Output pins
const int greenLED = 4;
const int redLED = 5;
const int buzzerPin = 18;
```
*Explanation:* We include the `Wire` and `LiquidCrystal_I2C` libraries to control the display. We define pins for our sensors and output devices. By placing all pin assignments here, it's easier to change them later if needed.

---

### 2. Setup Function

```cpp
void setup() {
  // Initialize LCD
  lcd.init();
  lcd.backlight();
  
  // Configure output pins
  pinMode(greenLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  
  Serial.begin(9600); // For debugging if needed
}
```
*Explanation:* In `setup()`, the LCD is initialized and its backlight turned on. The LED and buzzer pins are configured as `OUTPUT` so they can receive signals.

---

### 3. Main Loop Function

```cpp
void loop() {
  // Read sensors
  int waterLevel = analogRead(waterPin);
  int sensorValue = analogRead(tempPin);
  
  // Convert temperature to Celsius (ESP32 has 12-bit ADC and 3.3V reference)
  float voltage = sensorValue * (3.3 / 4095.0);
  float temperature = voltage * 100.0;
  
  // Display readings
  lcd.setCursor(0, 0);
  lcd.print("W:");
  lcd.print(waterLevel);
  lcd.print(" T:");
  lcd.print(temperature, 0);
  lcd.print("C  "); // Clear trailing characters
  
  // Check conditions
  if (waterLevel < 600 && temperature < 40) {
    // Safe condition
    digitalWrite(greenLED, HIGH);
    digitalWrite(redLED, LOW);
    digitalWrite(buzzerPin, LOW);
    lcd.setCursor(0, 1);
    lcd.print("Status: SAFE    ");
  } else {
    // Danger condition
    digitalWrite(greenLED, LOW);
    digitalWrite(redLED, HIGH);
    digitalWrite(buzzerPin, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("DANGER ALERT!   ");
  }
  
  delay(500); // Small delay to avoid flickering
}
```
*Explanation:* 

- The loop reads the raw analog value from the water level sensor and the temperature sensor.

- The temperature value is converted into standard Celsius using the ESP32's 12-bit ADC logic.

- The data is printed to the top row of the LCD screen.

- If the water level reaches a dangerous height (>600) OR the temperature becomes dangerously hot (>40°C), a DANGER ALERT is triggered. The red LED lights up and the buzzer sounds.

- Otherwise, the status is SAFE, so the green LED stays on!

## CONCLUSION

When the program is running, the Smart Disaster Early Warning System continuously monitors the water level and temperature. The LCD displays the current sensor readings, while the green LED indicates safe conditions. If the water level or temperature exceeds the predefined threshold, the red LED lights up, the buzzer sounds, and the LCD displays a danger alert, providing an immediate visual and audible warning of potential hazardous conditions.
