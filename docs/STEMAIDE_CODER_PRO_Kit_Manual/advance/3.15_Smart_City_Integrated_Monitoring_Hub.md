## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the LDR Module, PIR Motion Sensor, Green LED, Red LED, and Buzzer onto the breadboard, making sure their pins sit in separate rows.

- The Water Level Sensor and I2C LCD Display connect via jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Water Level Sensor

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **Signal** pin to **GPIO 36** on the ESP32 board.

**Step 3:** Wire the LDR Module

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **Signal/AO** pin to **GPIO 39** on the ESP32 board.

**Step 4:** Wire the PIR Motion Sensor

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **OUT** pin to **GPIO 2** on the ESP32 board.

**Step 5:** Wire the I2C LCD Display

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **SDA** pin to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin to **GPIO 22** on the ESP32 board.

**Step 6:** Wire the LEDs and Buzzer

- Connect the **Green LED's** anode (longer leg) through a 220Ω resistor to **GPIO 4** on the ESP32 board.

- Connect the **Red LED's** anode (longer leg) through a 220Ω resistor to **GPIO 5** on the ESP32 board.

- Connect the **Buzzer's Positive (+)** pin to **GPIO 18** on the ESP32 board.

- Connect the negative (shorter) legs of the LEDs and the negative (-) pin of the Buzzer to the negative ground rail.

### 1. Library Inclusion and Pin Definitions

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Sensor pins
const int waterPin = 36;
const int lightPin = 39;
const int pirPin = 2;

// Output pins
const int greenLED = 4;
const int redLED = 5;
const int buzzerPin = 18;
```
*Explanation:* We include the required libraries for our I2C LCD display. We then declare pins for the water sensor, light sensor, motion sensor, LEDs, and buzzer. We selected the LED/Buzzer pins carefully to avoid conflicts with I2C pins `21` and `22`.

---

### 2. Setup Function

```cpp
void setup() {
  // Initialize LCD
  lcd.init();
  lcd.backlight();

  // Configure pins
  pinMode(pirPin, INPUT);
  pinMode(greenLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buzzerPin, OUTPUT);

  // Initial state
  digitalWrite(greenLED, LOW);
  digitalWrite(redLED, LOW);
  digitalWrite(buzzerPin, LOW);

  // Startup message
  lcd.setCursor(0, 0);
  lcd.print("Safety Monitor");
  lcd.setCursor(0, 1);
  lcd.print("Starting...");
  delay(1500);
  lcd.clear();
}
```
*Explanation:* In `setup()`, we initialize the LCD, set the PIR motion sensor as `INPUT`, and configure our alert components (LEDs and buzzer) as `OUTPUT`s. We make sure all alerts start turned off. A nice "Safety Monitor Starting..." message greets us on the LCD.

---

### 3. Main Loop Function

```cpp
void loop() {
  // Read sensors
  int waterLevel = analogRead(waterPin);
  int lightLevel = analogRead(lightPin);
  int motion = digitalRead(pirPin);

  // Display sensor readings
  lcd.setCursor(0, 0);
  lcd.print("W:");
  lcd.print(waterLevel);
  lcd.print(" L:");
  lcd.print(lightLevel);
  lcd.print("   "); // Clear trailing characters

  bool alert = false;

  // Check warning conditions
  if (waterLevel > 700) {
    alert = true;
  }
  if (motion == HIGH) {
    alert = true;
  }

  // Alert condition
  if (alert) {
    digitalWrite(redLED, HIGH);
    digitalWrite(greenLED, LOW);
    digitalWrite(buzzerPin, HIGH);

    lcd.setCursor(0, 1);
    lcd.print("Alert Active  ");
  }
  // Normal condition
  else {
    digitalWrite(redLED, LOW);
    digitalWrite(greenLED, HIGH);
    digitalWrite(buzzerPin, LOW);

    lcd.setCursor(0, 1);
    lcd.print("System Normal ");
  }

  delay(500); // Wait half a second before looping
}
```
*Explanation:* 

- The loop continuously reads the water level, light level, and motion sensor.

- The LCD's top row displays the Water (`W:`) and Light (`L:`) values.

- It checks for danger: if the water level exceeds 700 (flood!) OR motion is detected (`HIGH`), the `alert` flag is set to true.

- If there is an alert, the Red LED and Buzzer turn ON, and the LCD says "Alert Active". Otherwise, the Green LED shines safely, and the LCD says "System Normal".

## CONCLUSION

During normal operation, the system continuously monitors the environmental conditions. The LCD displays the sensor readings (for example, W:320) and shows "System Normal" to indicate that no danger has been detected. The green LED remains active while the red LED and buzzer stay off.

When an alert condition is detected, such as a high water level or motion detection, the LCD displays the warning message "Alert Active". The red LED illuminates and the buzzer sounds to notify users that immediate attention is required..
