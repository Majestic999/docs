## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the RFID Reader, PIR Motion Sensor, Buzzer, and I2C LCD Display onto the breadboard, making sure their pins sit in separate rows. (The RFID Reader has 8 pins; make sure to leave enough space).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

- Connect the **5V** or **VIN** pin on the ESP32 board to one side of the positive (red) rail for 5V components.

- *(Optional but recommended)* Connect the **3.3V** pin to a different section for 3.3V components (like the RFID).

**Step 2:** Wire the RFID Reader (MFRC522)

_Important: The MFRC522 operates at 3.3V only. Do not connect it to the 5V pin, as this may permanently damage the module._

- Connect **3.3V** to the **3.3V** pin on the ESP32 board.

- Connect **GND** to the negative ground rail.

- Connect **SDA (SS)** to **GPIO 33** on the ESP32 board.

- Connect **SCK** to **GPIO 27** on the ESP32 board.

- Connect **MOSI** to **GPIO 25** on the ESP32 board.

- Connect **MISO** to **GPIO 26** on the ESP32 board.

- Connect **RST** to **GPIO 23** on the ESP32 board.

**Step 3:** Wire the I2C LCD Display

- Connect **VCC** to the 5V power rail.

- Connect **GND** to the negative ground rail.

- Connect **SDA** to **GPIO 21** on the ESP32 board.

- Connect **SCL** to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the PIR Motion Sensor

- Connect **VCC** to the 5V power rail.

- Connect **GND** to the negative ground rail.

- Connect **OUT (Signal)** to **GPIO 2** on the ESP32 board.

**Step 5:** Wire the Buzzer

- Connect the **Buzzer's Positive (+)** pin to **GPIO 18** on the ESP32 board.

- Connect the **Buzzer's Negative (-)** pin to the negative ground rail.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

### 1. Library Inclusion and Pin Definitions

```cpp
// Include required libraries
#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Define pins
#define SS_PIN 33
#define RST_PIN 23
#define PIR_PIN 2
#define BUZZER_PIN 18

// Create objects
MFRC522 rfid(SS_PIN, RST_PIN);
LiquidCrystal_I2C lcd(0x27, 16, 2);
```
*Explanation:* We include libraries for the SPI (RFID), I2C (LCD), and MFRC522 operations. We define `SS_PIN` and `RST_PIN` for the RFID module, `PIR_PIN` for motion, and `BUZZER_PIN` for the alarm. We adjusted the Buzzer to GPIO 18 so it doesn't conflict with the LCD's SCL pin!

---

### 2. Setup Function

```cpp
void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  
  lcd.init();
  lcd.backlight();
  
  pinMode(PIR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  
  lcd.print("System Ready");
}
```
*Explanation:* In `setup()`, we initialize the SPI bus and the `rfid` module. We start the LCD, turn on its backlight, and print a "System Ready" welcome message. We also configure the PIR sensor as an `INPUT` and the Buzzer as an `OUTPUT`.

---

### 3. Main Loop Function

```cpp
void loop() {
  // Read motion sensor
  int motion = digitalRead(PIR_PIN);

  // Check for RFID card
  if (rfid.PICC_IsNewCardPresent() && rfid.PICC_ReadCardSerial()) {
    lcd.clear();
    lcd.print("Access Granted");
    digitalWrite(BUZZER_PIN, LOW); // Turn off alarm
    delay(2000);
    
    lcd.clear();
    lcd.print("System Armed");
    
    rfid.PICC_HaltA();
    rfid.PCD_StopCrypto1();
  } 
  // If motion is detected
  else if (motion == HIGH) {
    lcd.clear();
    lcd.print("Motion Alert");
    digitalWrite(BUZZER_PIN, HIGH);
  }
  // If no motion or valid card
  else {
    digitalWrite(BUZZER_PIN, LOW);
  }
}
```
*Explanation:* The system continually checks for an authorized RFID card. If a card is presented, the system displays "Access Granted", stops the buzzer, and after 2 seconds re-arms itself ("System Armed"). If motion is detected while no card is presented, the system triggers the buzzer and displays "Motion Alert". If everything is quiet, the buzzer remains silent.
