## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Temperature Sensor and the LDR Module onto the breadboard, making sure their pins sit in separate rows.

- Insert the Buzzer onto the breadboard.

- Place the LCD Display near the breadboard (usually it's easier to connect it via female-to-male jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Sensors (Temperature & LDR)

- Connect the **VCC** pins of both the Temperature Sensor and the LDR Module to the positive 5V rail.

- Connect the **GND** pins of both sensors to the negative ground rail.

- Connect the **Signal/Output** pin of the Temperature Sensor to **GPIO 36** on the ESP32 board.

- Connect the **Signal/Output** pin of the LDR Module to **GPIO 39** on the ESP32 board.

**Step 3:** Wire the LCD Display

- Connect the **VCC** pin of the LCD to the positive 5V rail.

- Connect the **GND** pin of the LCD to the negative ground rail.

- Connect the **SDA** pin of the LCD to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin of the LCD to **GPIO 22** on the ESP32 board.

**Step 4:** Wire the Buzzer

- Connect the positive (+) pin of the Buzzer to **GPIO 18** on the ESP32 board. *(Do not use 22, it is needed for the LCD!)*

- Connect the negative (-) pin of the Buzzer to the negative ground rail.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../Getting Started/Arduino_IDE_Setup.md).

### 1. Library Inclusion and Setup

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Sensor pins
const int tempPin = 36;
const int lightPin = 39;

// Alarm pin (avoid 21 and 22, they are for I2C)
const int buzzerPin = 18;

void setup() {
  lcd.init();
  lcd.backlight();
  
  pinMode(buzzerPin, OUTPUT);
}
```
*Explanation:* We include the I2C LCD library and set up our objects. We map the temperature sensor to pin 36, the LDR to pin 39, and the buzzer to pin 18. In `setup()`, we initialize the LCD, turn on its backlight, and set the buzzer pin as an `OUTPUT`.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read sensors (ESP32 ADC goes up to 4095)
  int temp = analogRead(tempPin);
  int light = analogRead(lightPin);

  // Display readings on the first row
  lcd.setCursor(0, 0);
  lcd.print("T:");
  lcd.print(temp);
  lcd.print(" L:");
  lcd.print(light);
  lcd.print("    "); // Clear any trailing characters

  // Check classroom conditions (Using an arbitrary threshold for the 12-bit ADC)
  if (temp > 2500) {
    digitalWrite(buzzerPin, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("Too Hot!        ");
  } 
  else {
    digitalWrite(buzzerPin, LOW);
    lcd.setCursor(0, 1);
    lcd.print("Environment OK  ");
  }

  delay(500); // Wait half a second before reading again
}
```
*Explanation:* The `loop()` continuously reads the analog values from both the temperature sensor and the LDR. It displays the raw `temp` and `light` readings on the first row of the LCD. If the `temp` reading exceeds a preset threshold (e.g. `2500` for ESP32's 0-4095 scale), the buzzer turns on and "Too Hot!" is displayed. Otherwise, the buzzer stays off and it displays "Environment OK".
