## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the Potentiometer onto the breadboard so its three pins sit in separate rows.

- Insert the Green, Yellow, and Red LEDs onto the breadboard in separate rows.

- Place the LCD Display near the breadboard (connect it via female-to-male jumper wires).

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires and resistors:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the Potentiometer

- Connect the left pin of the Potentiometer to the negative ground rail.

- Connect the right pin of the Potentiometer to the positive 5V power rail.

- Connect the middle pin (wiper) to **GPIO 36** on the ESP32 board.

**Step 3:** Wire the LEDs

- Connect the anode (+, longer leg) of the **Green LED** to **GPIO 19** on the ESP32 board.

- Connect the anode (+, longer leg) of the **Yellow LED** to **GPIO 18** on the ESP32 board.

- Connect the anode (+, longer leg) of the **Red LED** to **GPIO 5** on the ESP32 board.

- Connect the cathode (-, shorter leg) of EACH LED through a **220Ω resistor** to the negative ground rail.

**Step 4:** Wire the LCD Display

- Connect the **VCC** pin of the LCD to the positive 5V power rail.

- Connect the **GND** pin of the LCD to the negative ground rail.

- Connect the **SDA** pin of the LCD to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin of the LCD to **GPIO 22** on the ESP32 board.

### 1. Library Inclusion and Setup

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Potentiometer pin (Simulates energy consumption sensor)
const int energyPin = 36;

// LED pins (Avoid 21 and 22 as they are for the LCD)
const int greenLED = 19;
const int yellowLED = 18;
const int redLED = 5;

void setup() {
  lcd.init();
  lcd.backlight();
  
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
}
```
*Explanation:* We include the I2C LCD library and set up our LCD object. We define the pins for our simulated energy sensor (the potentiometer) and our three indicator LEDs. In `setup()`, we start the LCD and set all LED pins to `OUTPUT`.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read energy level (ESP32 ADC goes up to 4095)
  int energyValue = analogRead(energyPin);

  // Display value
  lcd.setCursor(0, 0);
  lcd.print("Energy: ");
  lcd.print(energyValue);
  lcd.print("   "); // Clear trailing characters

  // Low usage
  if (energyValue < 1300) {
    digitalWrite(greenLED, HIGH);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, LOW);
    
    lcd.setCursor(0, 1);
    lcd.print("Low Usage     ");
  }
  // Medium usage
  else if (energyValue < 2600) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, HIGH);
    digitalWrite(redLED, LOW);
    
    lcd.setCursor(0, 1);
    lcd.print("Medium Usage  ");
  }
  // High usage
  else {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, HIGH);
    
    lcd.setCursor(0, 1);
    lcd.print("High Usage    ");
  }

  delay(300); // Wait briefly before the next read
}
```
*Explanation:* The `loop()` continuously reads the potentiometer value (which simulates energy consumption on a scale from 0 to 4095). We display this value on the first line of the LCD. We then use `if/else` statements to categorize the usage:

- Below 1300: **Low Usage** (Green LED on)

- 1300 to 2599: **Medium Usage** (Yellow LED on)

- 2600 and up: **High Usage** (Red LED on)
