| **Description** | In this project, learners will use an XY joystick module to control different LEDs based on the direction the joystick is pushed. ## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the XY Joystick Module onto the breadboard, making sure its pins sit in separate rows. (Alternatively, connect it directly using female-to-male jumper wires).

- Insert the four LEDs onto the breadboard, making sure their legs sit in separate rows.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the XY Joystick Module

- Connect the **VCC** pin of the joystick to the positive 5V power rail.

- Connect the **GND** pin of the joystick to the negative ground rail.

- Connect the **VRX (X-axis)** pin to **36** on the ESP32 board.

- Connect the **VRY (Y-axis)** pin to **39** on the ESP32 board.

- Connect the **SW (Push button)** pin to **2** on the ESP32 board.

**Step 3:** Wire the Direction LEDs

_Note: We will map these LEDs to visually represent UP, DOWN, LEFT, and RIGHT directions._

- Connect the anode (+, longer leg) of the **Up LED** through a 220Ω resistor to **23**.

- Connect the anode (+, longer leg) of the **Down LED** through a 220Ω resistor to **33**.

- Connect the anode (+, longer leg) of the **Left LED** through a 220Ω resistor to **25**.

- Connect the anode (+, longer leg) of the **Right LED** through a 220Ω resistor to **26**.

- Connect the cathode (-, shorter leg) of all four LEDs to the negative ground rail.

### 1. Pin Definitions and Setup

```cpp
// Joystick LED Direction Control

// Joystick pins
const int vrx = 36;
const int vry = 39;
const int sw  = 2;

// LED pins
const int ledUp    = 23;
const int ledDown  = 33;
const int ledLeft  = 25;
const int ledRight = 26;

void setup() {
  Serial.begin(9600);

  // The switch needs an internal pullup to read accurately
  pinMode(sw, INPUT_PULLUP);

  // Set LEDs as outputs
  pinMode(ledUp, OUTPUT);
  pinMode(ledDown, OUTPUT);
  pinMode(ledLeft, OUTPUT);
  pinMode(ledRight, OUTPUT);

  Serial.println("Joystick Direction Control Ready");
}
```
*Explanation:* We map our joystick X and Y axes to analog pins 36 and 39. The joystick switch (`sw`) is mapped to pin 2. We also declare the GPIOs for our four directional LEDs. In `setup()`, the LEDs are initialized as `OUTPUT`, while the switch uses `INPUT_PULLUP` so it defaults to `HIGH` when unpressed.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Read joystick values (Analog values go from 0 to 4095)
  int x = analogRead(vrx);
  int y = analogRead(vry);
  int button = digitalRead(sw);

  // Display raw readings
  Serial.print("X: ");
  Serial.print(x);
  Serial.print(" | Y: ");
  Serial.print(y);
  Serial.print(" | Button: ");
  Serial.println(button);

  // Start by turning off all LEDs
  digitalWrite(ledUp, LOW);
  digitalWrite(ledDown, LOW);
  digitalWrite(ledLeft, LOW);
  digitalWrite(ledRight, LOW);

  // Determine direction based on thresholds
  // 300 and 700 are arbitrary thresholds out of 4095
  if (button == LOW) {
    // Button is pressed (LOW due to pullup)
    Serial.println("Button Pressed: All LEDs OFF");
  }
  else if (y < 300) {
    digitalWrite(ledUp, HIGH);
    Serial.println("Direction: UP");
  }
  else if (y > 3800) { // Changed threshold to be more realistic for ESP32 (4095 max)
    digitalWrite(ledDown, HIGH);
    Serial.println("Direction: DOWN");
  }
  else if (x < 300) {
    digitalWrite(ledLeft, HIGH);
    Serial.println("Direction: LEFT");
  }
  else if (x > 3800) { // Changed threshold to be more realistic for ESP32 (4095 max)
    digitalWrite(ledRight, HIGH);
    Serial.println("Direction: RIGHT");
  }
  else {
    Serial.println("Direction: CENTER");
  }

  delay(100); // Check repeatedly with a slight delay
}
```
*Explanation:* The `loop()` repeatedly reads the horizontal (`x`) and vertical (`y`) positions of the joystick as well as the push button. Because the ESP32's analog read range goes up to 4095, we check if the joystick is pushed fully to one edge by using thresholds like `< 300` and `> 3800`. If it is pushed, the corresponding LED is lit. If the button is pushed (`LOW`), or the joystick is in the middle, all LEDs stay OFF.

## CONCLUSION

When the joystick is moved up, down, left, or right, the corresponding LED illuminates to indicate the direction of movement. Only one direction LED lights at a time, depending on the joystick's position. When the joystick is returned to its center position, all direction LEDs turn OFF.

Pressing the joystick's built-in push button turns all LEDs OFF, regardless of the joystick's position. The Serial Monitor continuously displays the real-time X-axis, Y-axis, and button state values, along with the detected joystick direction. These readings can be used to calibrate the joystick thresholds and verify that the joystick is operating correctly.
