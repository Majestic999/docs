# Project 3.1.1: AUTOMATIC CURTAIN CONTROLLER 

| **Description** | This project automatically opens and closes curtains based on ambient light levels. An LDR detects the surrounding brightness, while a potentiometer allows the user to adjust the light sensitivity threshold. A pushbutton provides manual override, and an RGB LED indicates the current system status.  |
|------------------|----------------------------------------------------------------|
| **Use case**     | Smart homes, automated curtains, energy-saving systems, daylight management. |

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Place the LDR Module, Potentiometer, Push Button, and RGB LED module on the breadboard so their pins sit in separate adjacent rows.

- Place the Servo Motor nearby, connecting its wires using jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the LDR Module

- Connect **VCC** of the LDR Module to the 3.3V pin on the ESP32 board (or 3.3V power rail).

- Connect **GND** of the LDR Module to the negative power rail.

- Connect **AO** (Analog Output) of the LDR Module to **GPIO 36** on the ESP32 board.

**Step 3:** Wire the Potentiometer

- Connect the left pin to the positive power rail.

- Connect the right pin to the negative power rail.

- Connect the middle pin (wiper) to **GPIO 39** on the ESP32 board.

**Step 4:** Wire the Servo Motor

- Connect **VCC (Red/Brown)** of the Servo Motor to the positive power rail.

- Connect **GND (Black/Brown)** of the Servo Motor to the negative power rail.

- Connect **Signal (Yellow/Orange)** of the Servo Motor to **GPIO 23** on the ESP32 board.

**Step 5:** Wire the Push Button

- Connect one leg of the pushbutton to **GPIO 21** on the ESP32 board.

- Connect the other leg to the negative ground rail. *(Internal pull-up resistor will be used in code).*

**Step 6:** Wire the RGB LED

- Connect the **Red** pin to **GPIO 4** on the ESP32 board.

- Connect the **Green** pin to **GPIO 18** on the ESP32 board.

- Connect the **Blue** pin to **GPIO 19** on the ESP32 board.

- Connect the **GND (-) pin** to the negative power rail.

### 1. Library Inclusion and Pin Definitions

```cpp
#include <ESP32Servo.h>

Servo curtainServo;

const int ldrPin = 36;
const int potPin = 39;
const int servoPin = 23;
const int buttonPin = 21;

const int redPin = 4;
const int greenPin = 18;
const int bluePin = 19;

bool manualMode = false;
bool curtainOpen = false;
bool lastButtonState = HIGH;
```
*Explanation:* We include the `ESP32Servo` library and define all our pins. We also create tracking variables to manage whether the system is in automatic or manual mode, and whether the curtain is open or closed.

---

### 2. Setup Function

```cpp
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  
  curtainServo.attach(servoPin);
  curtainServo.write(0); // Start with curtains closed
  
  Serial.begin(9600);
}
```
*Explanation:* Configures the RGB pins as outputs and the button pin as `INPUT_PULLUP`. The servo is attached and set to 0 degrees (closed position).

---

### 3. Main Loop and Button Logic

```cpp
void loop() {
  // Read the pushbutton (with simple debounce logic)
  bool buttonState = digitalRead(buttonPin);
  
  if (lastButtonState == HIGH && buttonState == LOW) {
    manualMode = !manualMode; // Toggle manual mode
    if (manualMode) {
      curtainOpen = !curtainOpen; // Toggle curtain if switched to manual
    }
    delay(200); // Debounce
  }
  lastButtonState = buttonState;

  int ldrValue = analogRead(ldrPin);
  int potValue = analogRead(potPin);
```
*Explanation:* The loop begins by checking the pushbutton. If pressed, it toggles `manualMode`. If switching to manual mode, it immediately toggles the curtain state. We also read the current LDR and potentiometer values.

---

### 4. Automatic Curtain Control and Status LED

```cpp
  if (!manualMode) {
    // Automatic control based on light
    if (ldrValue > potValue) { 
      // If it's bright enough (above user threshold)
      curtainOpen = true;
    } else {
      curtainOpen = false;
    }
  }

  // Actuate the servo and update the RGB LED
  if (curtainOpen) {
    curtainServo.write(180); // Open curtains
    if (manualMode) {
      setRGB(0, 0, 255); // Blue for Manual Open
    } else {
      setRGB(0, 255, 0); // Green for Auto Open
    }
  } else {
    curtainServo.write(0); // Close curtains
    if (manualMode) {
      setRGB(0, 0, 255); // Blue for Manual Closed
    } else {
      setRGB(255, 0, 0); // Red for Auto Closed
    }
  }
  
  delay(100);
}
```
*Explanation:* If not in manual mode, the system compares the light level (`ldrValue`) to the chosen threshold (`potValue`) to determine if the curtain should be open. Finally, the servo moves to the required position, and the RGB LED color updates based on the current mode and state.

---

### 5. Custom LED Function

```cpp
void setRGB(int r, int g, int b) {
  analogWrite(redPin, r);
  analogWrite(greenPin, g);
  analogWrite(bluePin, b);
}
```
*Explanation:* A simple helper function to quickly set the color of the RGB LED using PWM values.

## OBSERVATION

- Curtains open automatically when light levels increase beyond the selected threshold. 

- Curtains close automatically when light levels drop below the selected threshold. 

- The potentiometer changes the sensitivity of the system. 

- The RGB LED provides visual status feedback: Green = Curtain Open, Red = Curtain Closed, Blue = Manual Override Mode.

- Pressing the pushbutton toggles manual override mode. 

## CONCLUSION

This project demonstrates automation using light sensing, adjustable threshold control, servo motor actuation, RGB LED status indication, and manual override functionality. It introduces key smart-home concepts including environmental sensing, user calibration, visual feedback, and automatic control systems.
