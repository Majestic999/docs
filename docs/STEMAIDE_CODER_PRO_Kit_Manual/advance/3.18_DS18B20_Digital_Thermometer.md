# 3.18. DS18B20 Digital Thermometer

| **Description** | In this project, learners will build a precise digital thermometer using the DS18B20 one-wire temperature sensor. Unlike simple analog temperature sensors, the DS18B20 communicates digitally and provides accurate readings in degrees Celsius directly. This project introduces the 1-Wire communication protocol and demonstrates how multiple digital sensors can share a single data wire, which is a key technique in professional temperature monitoring systems.|
|------------------|----------------------------------------------------------------|
| **Use case**     |This project is connected to real-world uses such as: The DS18B20 provides highly accurate digital temperature readings. Its 1-Wire protocol allows multiple sensors to share one data line, making it ideal for temperature monitoring in greenhouses, data centres, and food storage systems.|

## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the DS18B20 Temperature Sensor onto the breadboard, making sure its pins sit in separate rows.

- (If using a bare metal TO-92 DS18B20, the flat side should face you. The pins from left to right are GND, DQ, VDD).

- Place the 4.7kΩ resistor connecting the Data (DQ) row to the Power (VDD) row.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the DS18B20 Sensor

- Connect the **VDD** pin (often the right pin or red wire) to the positive 5V power rail.

- Connect the **GND** pin (often the left pin or black wire) to the negative ground rail.

- Connect the **DQ (Data)** pin (middle pin or yellow wire) to **GPIO 2** on the ESP32 board.

**Step 3:** Add the Pull-Up Resistor

- Ensure the **4.7kΩ resistor** bridges the **DQ** (data) pin and the **VDD** (power) pin. This "pull-up" resistor is absolutely required for the 1-Wire communication protocol to work properly.

### 1. Library Inclusion and Setup

```cpp
// DS18B20 Digital Thermometer
// Requires: OneWire and DallasTemperature libraries
#include <OneWire.h>
#include <DallasTemperature.h>

#define ONE_WIRE_BUS 2

// Setup a oneWire instance to communicate with ANY OneWire devices
OneWire oneWire(ONE_WIRE_BUS);
// Pass our oneWire reference to Dallas Temperature sensor
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  
  // Start up the library
  sensors.begin();
  
  Serial.println("DS18B20 Thermometer Ready");
}
```
*Explanation:* We include the `OneWire` and `DallasTemperature` libraries which handle the complex timings of the digital sensor protocol. We assign the sensor pin to `ONE_WIRE_BUS 2` (GPIO 2). In `setup()`, we initialize the Serial Monitor and start the `sensors` object.

---

### 2. Main Loop Function

```cpp
void loop() {
  // Tell the sensor(s) to measure temperature
  sensors.requestTemperatures();
  
  // Read the temperature of the first sensor on the wire (index 0)
  float tempC = sensors.getTempCByIndex(0);

  // Error checking
  if (tempC == DEVICE_DISCONNECTED_C) {
    Serial.println("Error: Sensor not connected!");
  } else {
    Serial.print("Temperature: ");
    Serial.print(tempC);
    Serial.println(" C");
  }
  
  delay(1000); // Wait 1 second before the next reading
}
```
*Explanation:* The `requestTemperatures()` command tells all DS18B20 sensors on the data line to take a measurement. Since we only have one sensor, we use `getTempCByIndex(0)` to read its specific value. If the wiring is loose or broken, the library returns a special disconnected error value, which we catch and print out. Otherwise, it prints the temperature in Celsius.

## CONCLUSION

After the program starts, the Serial Monitor displays the temperature measured by the DS18B20 temperature sensor every second.

When you hold the sensor between your fingers, the measured temperature gradually increases as the sensor detects the warmth from your hand. When you remove your hand and blow cool air across the sensor, the temperature reading gradually decreases within a few seconds as the sensor responds to the lower temperature. This demonstrates the DS18B20's ability to provide accurate, real-time digital temperature measurements.nts.
