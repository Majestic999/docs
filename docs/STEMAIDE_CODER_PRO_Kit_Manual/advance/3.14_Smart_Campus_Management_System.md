## Mounting the components on the breadboard

**Step 1:** Mount the ESP32 and Components:

- Align the ESP32 board across the center dividing ridge of the breadboard.

- Insert the LDR Module, LM35 Temperature Sensor, and Buzzer onto the breadboard, making sure their pins sit in separate rows.

- The I2C LCD Display and MFRC522 RFID Reader connect via jumper wires.

---

## Wiring the circuit

Follow these step-by-step connection details using your jumper wires:

**Step 1:** Create Power and Ground Rails

- Connect the **5V** or **VIN** pin on the ESP32 board to the positive (red) rail on the breadboard.

- Connect a **GND** pin on the ESP32 board to the negative (blue/black) rail on the breadboard.

**Step 2:** Wire the MFRC522 RFID Reader (Standard VSPI)

> **Important:** Connect the MFRC522 RFID Reader to 3.3V only. Connecting it to 5V may damage the module permanently.

- **SDA (SS)** → **GPIO 5**

- **SCK** → **GPIO 18**

- **MOSI** → **GPIO 23**

- **MISO** → **GPIO 19**

- **RST** → **GPIO 4**

- **3.3V** → **3.3V** pin on the ESP32 board

- **GND** → Negative ground rail

**Step 3:** Wire the LDR Light Sensor Module

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **AO/Signal** pin to **GPIO 36** on the ESP32 board.

**Step 4:** Wire the LM35 Temperature Sensor

- With the flat side facing you, connect the **Left VCC** pin to the positive power rail.

- Connect the **Right GND** pin to the negative power rail.

- Connect the **Middle VOUT/Signal** pin to **GPIO 39** on the ESP32 board.

**Step 5:** Wire the I2C LCD Display

- Connect the **VCC** pin to the positive power rail.

- Connect the **GND** pin to the negative power rail.

- Connect the **SDA** pin to **GPIO 21** on the ESP32 board.

- Connect the **SCL** pin to **GPIO 22** on the ESP32 board.

**Step 6:** Wire the Buzzer

- Connect the **Buzzer's Positive (+)** pin to **GPIO 14** on the ESP32 board.

- Connect the negative (-) pin to the negative ground rail.

### 1. Library Inclusion and Pin Definitions

```cpp
#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// RFID pins
#define SS_PIN 5
#define RST_PIN 4

// Create RFID object
MFRC522 rfid(SS_PIN, RST_PIN);

// Create LCD object
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Sensor and output pins
const int lightPin = 36;
const int tempPin = 39;
const int buzzerPin = 14;
```
*Explanation:* We include the `SPI`, `MFRC522`, `Wire`, and `LiquidCrystal_I2C` libraries to control all of our advanced modules. We initialize the RFID and LCD objects, and set up our pins. We use standard VSPI pins for the RFID module and ensure the Buzzer does not conflict with them.

---

### 2. Setup Function

```cpp
void setup() {
  // Initialize RFID
  SPI.begin();
  rfid.PCD_Init();

  // Initialize LCD
  lcd.init();
  lcd.backlight();

  // Initialize buzzer
  pinMode(buzzerPin, OUTPUT);
  digitalWrite(buzzerPin, LOW);

  // Startup message
  lcd.setCursor(0, 0);
  lcd.print("Campus Ready");
  lcd.setCursor(0, 1);
  lcd.print("Scan Card");
  delay(1500);
  lcd.clear();
}
```
*Explanation:* In `setup()`, the RFID reader and the LCD are initialized. We configure the buzzer as an `OUTPUT` and make sure it starts turned OFF. A startup message greets the students on the LCD!

---

### 3. Main Loop Function

```cpp
void loop() {
  // Read classroom conditions
  int lightLevel = analogRead(lightPin);
  int tempReading = analogRead(tempPin);

  // Convert LM35 reading to temperature (ESP32 uses 12-bit ADC and 3.3V reference)
  float voltage = tempReading * (3.3 / 4095.0);
  float temperature = voltage * 100.0;

  // Display environmental conditions
  lcd.setCursor(0, 0);
  lcd.print("L:");
  lcd.print(lightLevel);
  lcd.print(" T:");
  lcd.print(temperature, 1);
  lcd.print("C ");

  // Temperature alert
  if (temperature > 40.0) {
    digitalWrite(buzzerPin, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("High Temp!    ");
  }
  else {
    digitalWrite(buzzerPin, LOW);
    lcd.setCursor(0, 1);
    lcd.print("Scan RFID     ");
  }

  // Check RFID card
  if (rfid.PICC_IsNewCardPresent() && rfid.PICC_ReadCardSerial()) {
    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Attendance");
    lcd.setCursor(0, 1);
    lcd.print("Recorded");
    
    delay(2000); // Wait 2 seconds for message
    lcd.clear();

    // Stop RFID communication
    rfid.PICC_HaltA();
    rfid.PCD_StopCrypto1();
  }

  delay(500); // Wait half a second before looping
}
```
*Explanation:* 

- The loop continuously reads the environmental sensors (light and temperature).

- It displays the Light and Temperature values on the top row of the LCD. Note the temperature calculation specifically accounts for the ESP32's 3.3V and 12-bit ADC.

- If the temperature exceeds 40°C, a safety alarm triggers (Buzzer turns ON, "High Temp!" on LCD). Otherwise, it prompts to "Scan RFID".

- When a valid RFID card is swiped, the system detects it and records attendance by printing "Attendance Recorded" for 2 seconds.

Then it resumes normal operations!

## CONCLUSION

When a registered student scans an RFID card, the system recognizes the card and the LCD displays "Attendance Recorded" to confirm that the attendance entry has been captured.

When the classroom temperature rises above the preset safety limit, the LCD displays "High Temp!" and the buzzer activates to alert users that the classroom environment requires attention.
