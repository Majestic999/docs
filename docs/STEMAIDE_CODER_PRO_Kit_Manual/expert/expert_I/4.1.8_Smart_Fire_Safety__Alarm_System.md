## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Identify the Components

Identify all the modules and components listed in the Required Components table before starting the assembly.

**Step 2:** Connect the Flame Sensor

Connect the DO (Digital Output) pin of the flame sensor to GPIO 2 on the ESP32 board using a jumper wire. This provides the digital flame detection signal.

**Step 3:** Connect the Relay Module

Connect the IN (Signal) pin of the relay module to GPIO 21 on the ESP32 board using a jumper wire. This allows the ESP32 board to control the relay.

**Step 4:** Connect the Buzzer

Connect the positive (+) pin of the buzzer to GPIO 22 on the ESP32 board using a jumper wire. This provides the audio alert signal.

**Step 5:** Connect the LED

Connect the anode (positive leg) of the red LED to GPIO 27 on the ESP32 board through a 220Ω resistor.

Connect the cathode (negative leg) to GND using a jumper wire.

**Step 6:** Check the Power and Ground Connections

Double-check all VCC, 5V, 3.3V, and GND connections to ensure that the polarity is correct and there are no accidental short circuits.

**Step 7:** Connect the USB Cable

After verifying all signal, power, and ground connections, connect the USB programming cable to the ESP32 board and the computer.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Project 63: Smart Fire Safety & Alarm System
const int flamePin = 2;
const int relayPin = 21;
const int buzzerPin = 22;
const int ledPin = 27;

void setup() {
  pinMode(flamePin, INPUT);
  pinMode(relayPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  digitalWrite(relayPin, LOW);
  digitalWrite(buzzerPin, LOW);
  digitalWrite(ledPin, LOW);
}

void loop() {
  if (digitalRead(flamePin) == LOW) {
    digitalWrite(relayPin, HIGH);
    digitalWrite(ledPin, HIGH);
    digitalWrite(buzzerPin, HIGH);
    delay(100);
    digitalWrite(buzzerPin, LOW);
    delay(100);
  } else {
    digitalWrite(relayPin, LOW);
    digitalWrite(ledPin, LOW);
    digitalWrite(buzzerPin, LOW);
    delay(200);
  }
}
```
