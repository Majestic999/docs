## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the Power and Ground Rails

Connect the 5V pin on the ESP32 board to the positive (+) power rail on the breadboard using a jumper wire.

Then, connect a GND pin on the ESP32 board to the negative (−) ground rail.

**Step 2:** Connect the Water Sensor

Connect the VCC pin of the water sensor to the 5V power rail and the GND pin to the ground rail using jumper wires.

Then, connect the Signal (S) pin of the water sensor to Digital GPIO 21 (D7) on the ESP32 board.

**Step 3:** Connect the Active Buzzer

Connect the positive (+) terminal of the active buzzer to Digital GPIO 26 (D12) on the ESP32 board and the negative (−) terminal to the ground rail using jumper wires.

**Step 4:** Connect the I²C LCD Module

Connect the VCC pin of the I²C LCD module to the 5V power rail and the GND pin to the ground rail using jumper wires.

Then, connect the SDA pin to GPIO 21 and the SCL pin to GPIO 22 on the ESP32 board.

**Step 5:** Perform a Final Check

Check all power, signal, ground, and polarity connections against the Circuit Connections table and wiring diagram.

Ensure that all components share a common ground and that there are no loose or misplaced wires.

**Step 6:** Connect the USB Cable

After confirming that all connections are correct, connect the USB cable to the ESP32 board and the computer to power the circuit.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// LCD Address (Change to 0x3F if required)
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Pin Definitions
const int waterSensorPin = 21;     // Digital output from Water Sensor
const int buzzerPin = 26;

// Variables
bool waterDetected = false;

void setup()
{
  pinMode(waterSensorPin, INPUT);
  pinMode(buzzerPin, OUTPUT);

  digitalWrite(buzzerPin, LOW);

  Serial.begin(9600);

  lcd.init();
  lcd.backlight();

  lcd.clear();
  lcd.setCursor(0,0);
  lcd.print("Plant Monitor");
  lcd.setCursor(0,1);
  lcd.print("Initializing");

  delay(2000);
  lcd.clear();

  Serial.println("Project 64 Started...");
}

void loop()
{
  waterDetected = digitalRead(waterSensorPin);

  lcd.clear();

  if (waterDetected == HIGH)
  {
    lcd.setCursor(0,0);
    lcd.print("Water Detected");

    lcd.setCursor(0,1);
    lcd.print("Plant is Wet");

    digitalWrite(buzzerPin, LOW);

    Serial.println("Water Detected");
  }
  else
  {
    lcd.setCursor(0,0);
    lcd.print("No Water!");

    lcd.setCursor(0,1);
    lcd.print("Needs Water");

    digitalWrite(buzzerPin, HIGH);

    Serial.println("No Water Detected");

    delay(300);

    digitalWrite(buzzerPin, LOW);

    delay(300);
  }

  delay(500);
}

```

**Step 3:** Save your code. _See the [Getting Started](../../Getting Started/Arduino_IDE_Setup.md) section_

**Step 4:** Select the ESP32 board and port _See the [Getting Started](../../Getting Started/Arduino_IDE_Setup.md) section:Selecting ESP32 board Type and Uploading your code_.
