## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the Power and Ground Rails

Connect the 5V pin on the ESP32 board to the positive (+) power rail on the breadboard using a jumper wire.

Then, connect a GND pin on the ESP32 board to the negative (−) ground rail.

**Step 2:** Connect the Flame Sensor

Connect the VCC pin of the flame sensor to the 5V power rail and the GND pin to the ground rail using jumper wires.

Then, connect the DO (Digital Output) pin of the flame sensor to GPIO 2 on the ESP32 board.

**Step 3:** Connect the Relay Module

Connect the VCC pin of the relay module to the 5V power rail and the GND pin to the ground rail.

Then, connect the IN (Signal) pin of the relay module to GPIO 21 on the ESP32 board using jumper wires.

**Step 4:**  Connect the Buzzer

Connect the positive (+) pin of the buzzer to GPIO 22 on the ESP32 board and the negative (−) pin to the ground rail using jumper wires.

**Step 5:** Connect the LED

Connect the anode (+) of the LED to GPIO 27 on the ESP32 board through a 220Ω resistor.

Then, connect the cathode (−) to the ground rail using jumper wires.

**Step 6:** Connect the Relay Terminals

Connect the COM, NO, and NC terminals of the relay module to the device being controlled according to the required switching configuration. Make sure the relay terminals are connected correctly before powering the circuit.

**Step 7:** Perform a Final Check

Check all power, signal, ground, and polarity connections against the Circuit Connections table and wiring diagram.

Ensure that all components share a common ground and that there are no loose or misplaced wires.

**Step 8:** Connect the USB Cable

After confirming that all connections are correct, connect the USB cable to the ESP32 board and the computer to power the circuit.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Project 63: Smart Fire Safety & Alarm System
const int flamePin = 2;
const int relayPin = 21;
const int buzzerPin = 22;
const int ledPin = 27;

void setup() {
  pinMode(flamePin, INPUT);
  pinMode(relayPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  digitalWrite(relayPin, LOW);
  digitalWrite(buzzerPin, LOW);
  digitalWrite(ledPin, LOW);
}

void loop() {
  if (digitalRead(flamePin) == LOW) {
    digitalWrite(relayPin, HIGH);
    digitalWrite(ledPin, HIGH);
    digitalWrite(buzzerPin, HIGH);
    delay(100);
    digitalWrite(buzzerPin, LOW);
    delay(100);
  } else {
    digitalWrite(relayPin, LOW);
    digitalWrite(ledPin, LOW);
    digitalWrite(buzzerPin, LOW);
    delay(200);
  }
}

```
