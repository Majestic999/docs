## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Confirm you have the DS3231 RTC, Relay, Water Sensor, and Active Buzzer.

**Step 2:** Connect the DS3231 RTC: SDA to GPIO 21, SCL to GPIO 22, VCC to 3.3V, and GND to GND.

**Step 3:** Connect the actuators: Relay IN to GPIO 25 and Buzzer (+) to GPIO 26.

**Step 4:** Connect the Water sensor: SIG pin to Analog GPIO 36.

**Step 5:** Double-check all VCC, 5V, 3.3V, and GND polarities to prevent electrical shorts.

**Step 6:** Connect USB programming cable only after verifying all signal path wiring.

![Components on breadboard](../../../assets/coder_pro/expert/expert_III/4.3.26_Project_146_Real_Time_Clock_Liquid_Tank_Automated_Pump/image_1.png)

_Make sure to connect the Micro USB cable to the ESP32 board._

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <DS3231.h>

// DS3231 uses default I2C (Wire) on GPIO 21 (SDA) and GPIO 22 (SCL)
#include <Wire.h>

const int relayPin = 21;
const int buzzerPin = 22;
const int waterSensorPin = 36;

void setup() {
  Serial.begin(9600);
  pinMode(relayPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  digitalWrite(relayPin, LOW);

  rtc.begin();
}

void loop() {
  Time t = rtc.getTime();
  int waterLevel = analogRead(waterSensorPin);

  Serial.print("Time: "); Serial.print(t.hour); Serial.print(":"); Serial.println(t.min);
  Serial.print("Water Level: "); Serial.println(waterLevel);

  if (waterLevel < 100) { digitalWrite(relayPin, HIGH); }
  else { digitalWrite(relayPin, LOW); }
  delay(1000);
}
```
