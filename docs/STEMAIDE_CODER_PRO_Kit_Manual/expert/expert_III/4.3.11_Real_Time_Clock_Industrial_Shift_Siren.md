## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <ThreeWire.h>  
#include <RtcDS1302.h>
#include <LedControl.h>

// Pins
ThreeWire myWire(6, 7, 5); 
RtcDS1302<ThreeWire> Rtc(myWire);
LedControl lc = LedControl(11, 13, 10, 1); // DIN, CLK, CS, NumDevices
const int buzzerPin = 22;

void setup() {
  pinMode(buzzerPin, OUTPUT);
  Rtc.Begin();
  lc.shutdown(0, false);
  lc.setIntensity(0, 8);
}

void loop() {
  RtcDateTime now = Rtc.GetDateTime();
  
  // Example: Siren at 08:00:00 (Shift Start)
  if (now.Hour() == 8 && now.Minute() == 0 && now.Second() < 5) {
    digitalWrite(buzzerPin, HIGH); // Siren ON for 5 seconds
  } else {
    digitalWrite(buzzerPin, LOW);
  }

  // Optional: Display "ON" or current hour on Matrix
  // Simplified display logic
  lc.clearDisplay(0);
  // Add your custom font/display logic here
  
  delay(1000);
}
```
