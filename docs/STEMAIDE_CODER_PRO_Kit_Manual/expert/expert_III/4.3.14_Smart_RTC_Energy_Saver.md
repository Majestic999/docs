## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <ThreeWire.h>  
#include <RtcDS1302.h>

const int relayPin = 22;
const int pirPin = 2;

ThreeWire myWire(6, 7, 5); // DAT, CLK, RST
RtcDS1302<ThreeWire> Rtc(myWire);

void setup() {
  pinMode(relayPin, OUTPUT);
  pinMode(pirPin, INPUT);
  digitalWrite(relayPin, HIGH); // Relay OFF (Active-LOW)
  Rtc.Begin();
}

void loop() {
  RtcDateTime now = Rtc.GetDateTime();
  int motion = digitalRead(pirPin);
  
  // Logic: Active between 08:00 and 17:00 (8 AM - 5 PM)
  bool isWorkHours = (now.Hour() >= 8 && now.Hour() < 17);

  if (isWorkHours && motion == HIGH) {
    digitalWrite(relayPin, LOW); // Turn Load ON
  } else {
    digitalWrite(relayPin, HIGH); // Turn Load OFF
  }
  
  delay(500);
}
```
