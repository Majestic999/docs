## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Inventory all modules: ESP32 board, HC-05, MAX7219, and Active Buzzer.

**Step 2:** Connect the HC-05 Bluetooth module: Connect VCC to 5V and GND to GND.

Connect HC-05 TX to ESP32 GPIO 16 (RX2) and HC-05 RX to ESP32 GPIO 17 (TX2).

**Step 3:** Connect the MAX7219 Dot Matrix: Connect VCC to 5V and GND to GND.

Connect DIN to ESP32 GPIO 23 (MOSI), CS to ESP32 GPIO 27, and CLK to ESP32 GPIO 18 (SCK).

**Step 4:** Connect the Active Buzzer: Connect the positive pin (+) to ESP32 GPIO 26 and the negative pin (-) to GND.

**Step 5:** Double-check all VCC and GND polarities to prevent electrical shorts.

**Step 6:** Connect the USB cable to the ESP32 board only after verifying all signal path wiring.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <LedControl.h>
#include <SoftwareSerial.h>

// Pins: DIN=12, CLK=11, CS=10
LedControl lc = LedControl(12, 11, 10, 1);
SoftwareSerial BT(2, 3); // RX, TX
const int buzzerPin = 23;

void setup() {
  Serial.begin(9600);
  BT.begin(9600);
  pinMode(buzzerPin, OUTPUT);
  lc.shutdown(0, false);
  lc.setIntensity(0, 8);
  lc.clearDisplay(0);
  Serial.println("Project 142: Bluetooth Remote Matrix Display Scroller Online");
}

void loop() {
  if (BT.available()) {
    char data = BT.read();
    if (data == '1') {
      tone(buzzerPin, 1000, 200); // Beep on command
    }
  }
}
```
