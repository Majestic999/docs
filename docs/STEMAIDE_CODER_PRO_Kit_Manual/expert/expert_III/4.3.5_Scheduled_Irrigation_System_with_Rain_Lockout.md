## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <ThreeWire.h>  
#include <RtcDS1302.h>

// Pin Definitions
const int relayPin = 22;
const int rainSensorPin = 36;
const int rainThreshold = 500; // Adjust based on your sensor
ThreeWire myWire(6, 7, 5); // DAT, CLK, RST
RtcDS1302<ThreeWire> Rtc(myWire);

void setup() {
  Serial.begin(9600);
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, HIGH); // Relay OFF (Active LOW modules)
  Rtc.Begin();
}

void loop() {
  RtcDateTime now = Rtc.GetDateTime();
  int rainValue = analogRead(rainSensorPin);
  
  // Schedule: Water at 8:00 AM (08:00:00)
  bool isScheduledTime = (now.Hour() == 8 && now.Minute() == 0);
  bool isRaining = (rainValue < rainThreshold);

  if (isScheduledTime && !isRaining) {
    digitalWrite(relayPin, LOW); // Turn Pump ON
    Serial.println("Irrigation Started");
  } else {
    digitalWrite(relayPin, HIGH); // Turn Pump OFF
  }

  delay(1000); // Check every second
}
```
