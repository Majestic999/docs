## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <ThreeWire.h>  
#include <RtcDS1302.h>

// Pins
const int relayPin = 22;
const int ldrPin = 36;
const int darkThreshold = 400; // Calibrate this value

// Setup DS1302 (DAT, CLK, RST)
ThreeWire myWire(6, 7, 5); 
RtcDS1302<ThreeWire> Rtc(myWire);

void setup() {
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, HIGH); // Relay OFF (Active-LOW)
  Rtc.Begin();
}

void loop() {
  RtcDateTime now = Rtc.GetDateTime();
  int ldrValue = analogRead(ldrPin);
  
  // Greenhouse Schedule: 6:00 to 20:00 (6 AM - 8 PM)
  bool isScheduledTime = (now.Hour() >= 6 && now.Hour() < 20);
  bool isDark = (ldrValue < darkThreshold);

  // Turn ON lights if inside schedule AND it is too dark
  if (isScheduledTime && isDark) {
    digitalWrite(relayPin, LOW);  // Turn Lights ON
  } else {
    digitalWrite(relayPin, HIGH); // Turn Lights OFF
  }
  
  delay(2000); 
}
```
