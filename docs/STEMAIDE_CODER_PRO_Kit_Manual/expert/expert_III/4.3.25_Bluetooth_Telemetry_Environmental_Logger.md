## Building the circuit

> **Tip:** Use the [ESP32 Pin Mapping](../../assets/esp32_pin_mapping.png) image to locate the correct GPIO pins on your ESP32 board.


Things Needed:

- ESP32 board Core Board = 1

- HC-05 Bluetooth = 1

- BME280 = 1

- DS18B20 = 1

- USB Cable & Jumper Wires = 1

- Bread Board

- Buzzer


## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Inventory all modules listed in the Required Components table.

**Step 2:** Connect the HC-05 Bluetooth module (TX to GPIO 2, RX to GPIO 4) and the BME280 sensor (SDA to GPIO 21, SCL to GPIO 22).

**Step 3:** Connect the DS18B20 temperature sensor data pin to GPIO 5 and the Active Buzzer to GPIO 21.

**Step 4:** Connect line [Power Rails] to [5V / 3.3V / GND] — (System power and ground rails.).

**Step 5:** Double-check all VCC, 5V, 3.3V, and GND polarities to prevent electrical shorts.

**Step 6:** Connect USB programming cable only after verifying all signal path wiring.

![Components on breadboard](../../../assets/coder_pro/expert/expert_III/4.3.25_Project_145_Bluetooth_Telemetry_Environmental_Logger/image_1.png)

_Make sure to connect the Micro USB cable to the ESP32 board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <SoftwareSerial.h>
#include <Wire.h>
#include <OneWire.h>
#include <DallasTemperature.h>

SoftwareSerial bluetooth(2, 3);
const int buzzerPin = 21;
OneWire oneWire(4);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(9600);
  bluetooth.begin(9600);
  Wire.begin();
  sensors.begin();
  pinMode(buzzerPin, OUTPUT);
  Serial.println("Project 145: System Initialized");
}

void loop() {
  // Wireless telemetry and sensor processing
  delay(1000);
}
```
